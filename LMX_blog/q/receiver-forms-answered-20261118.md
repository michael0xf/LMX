# Формы ресиверов return, length, typeof, send

Дата: 2026-11-18. Задавал исполнитель (сессия fable_pc). Статус: **закрыт ответом автора 2026-11-18**.

## Что записано

Автор, [журнал](../2026-11-18.md#no-count-preference): формы `call` объявляются как обычные `sub` —
`sub: call (@: code)`, `sub: call (@: data; @: code)` — и проверяются общим алгоритмом. Автор,
[журнал](../2026-11-18.md#unwrapped-into-declaration): единственная Structure раскрывается против любого
объявления, и с одним формалом.

Из этого исполнитель вывел ([ответы исполнителя, Р87](fable-self-answers-20261110.md)) и записал в книгу,
[выбор объявления](../../docs/LMX_semantics.ru.md#declaration-selection): `return`, `length`, `typeof`, `send` идут
тем же общим алгоритмом — их формы и оба чтения аргументов.

## Чего не хватает

Форм этих ресиверов нигде нет — ни в книге, ни в коде. Факты кода, проверка вспомогательной сессии opus
(`receipts/opus/one-graph/declaration-selection/RECEIVERS-ONE-ARG.txt`): объявлениями в чистом графе записаны
только формы `call`, `fncall`, `fn`, `sub`. `return`, `typeof`, `length`, `send` — ветки интерпретатора по слову
головы; `parent`, `throw` и члены `sys\` в чистом графе отсутствуют, и ни одна программа `tests/graph` их не пишет.
Пока форм нет, эти ресиверы в выборе объявления не участвуют, и ни одна строка ответа не меняет.

## Программа

```lmx
sub: test (S: ((int: x 9)) )
(
int: n length(S)
)
```

`S` ссылается на Structure с одним безымянным полем; это поле — Structure `(int: x 9)`.

## Вопрос

Как объявляются формы этих ресиверов — имя и вид формала каждого?

Предложение исполнителя, по образцу форм `call`:

- `length`, `typeof`, `parent` — один формал `@: data`: они рассматривают Structure как данные и не исполняют её;
- `send` — один формал `@: message`;
- у `return` своей формы нет: его аргумент сверяется с объявленным результатом той `fn`, в которой он стоит.

Наблюдаемое по этому предложению. В программе выше `length(S)` — ошибка неоднозначности: формалу `data` подходит и
сама `S`, и её единственное безымянное поле. `length(data := S)` отвечает 1. При `S: (int: x 9)` запись
`length(S)` отвечает 1: поле-объявление `x` формалу `data` по имени не подходит, остаётся чтение «как записано».

Другое чтение: эти ресиверы получают то, что записано, и в выборе не участвуют; тогда `length(S)` в программе выше
отвечает 1, а абзац книги о ресиверах возвращается к прежнему виду.

## Что из ответа следует

Редакторское пояснение исполнителя, не слова автора.

- У этих ресиверов одна сигнатура с одним аргументом. Вызов выбран по ней, и ничего не раскрывается:
  `length(S)` отвечает 1, сколько бы полей у `S` ни было. Ошибки неоднозначности здесь нет; вывод исполнителя
  был неверным, абзац книги о ресиверах возвращён к прежнему смыслу.
- Имена формалов этих ресиверов ни для одного записанного правила не нужны; вопрос о них снят, шаг плана об
  объявлении их форм убран.
- Запись программы вопроса. По поправке автора того же дня
  ([журнал](../2026-11-18.md#arg-example-corrected)) Structure с полем `x` записывается `S(int: x 9)` или
  `S: int: x 9`; `S: (int: x 9)` объявляет `S`, внутри которой одна анонимная Structure.
