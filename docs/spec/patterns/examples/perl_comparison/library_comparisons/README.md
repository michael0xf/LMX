# Сравнения реализаций LMX и Perl

В этой директории находятся полные реализации общих операций и их отдельные замеры. Клиентские примеры из [основного набора](../README.md) используют стандартные операции соответствующего языка; исходники отсюда не добавляются к каждому клиенту повторно.

| ID | Договор и исходники |
| --- | --- |
| PI01 | [Последовательные коллекции: map, filter, fold, scan, any, all, bind](PI01_comparision.md) |
| PI02 | [Срезы и изменение диапазонов](PI02_comparision.md) |
| PI03 | [Стабильная сортировка и unique](PI03_comparision.md) |
| PI04 | [Группировка с произвольными ключами](PI04_comparision.md) |
| PI05 | [Копирование и наложение графа данных](PI05_comparision.md) |
| PI06 | [Полный синхронный bracket](PI06_comparision.md) |
| PI07 | [Шаблоны и операции над regex-движком](PI07_comparision.md) |

Каждая страница содержит договор, границу реализации, полный LMX-исходник и полный Perl-исходник. Общие зависимости LMX вынесены в [shared_dependencies.lmx](shared_dependencies.lmx); основные тела извлекаются из канонической библиотеки. Пути, размеры и контрольные суммы записаны в [examples.json](../examples.json).

Числа измеряют исходный текст и включают объявления исключений. Они не являются измерением скорости или памяти. Исполнение изменённого LMX парсером и runtime имеет статус **NOT_RUN**; результаты доступны в [проверке исходников](../validation/source_checks.json), [исполнении Perl-клиентов](../validation/client_tests.json) и [исполнении Perl-реализаций](../validation/implementation_tests.json).
