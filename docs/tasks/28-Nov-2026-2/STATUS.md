# Статус второй поставки 28 ноября

Поставка содержит манифест из 328 позиций и исходные отчёты. Для сравнения с рабочим деревом важны следующие различия.

| Тема | Действующее решение |
| --- | --- |
| Python | В снимке перечислены 15 имён и соответствующие им CODE. Прямое уточнение автора сохраняет за `py.*` доступ к произвольной цели Python без поимённой регистрации. Установка и открытие сессии оформлены как обычные ресиверы LMX `installPython` и `openPython`. [Действующий API](../../../include_languages/python/API.md) |
| Координата метки внутри строки | В исходном `README.md`, §6, наблюдение `atom_char` относится к символу написанного токена, включая кавычку. Языковой якорь задаётся символом отображаемого текста. Для перехода от байтов и исходных символов требуется соответствие, построенное декодером. [Рабочий договор](../../com.mtk.map/p0/README.md#p0-mix-coordinates) |
| Очередь реализации | После начатой работы над именами готовится общий P0 для Cursor/MIX и голов `py.*`. Интеграция владельца MIX, Python-провайдеров и исполнение четырёх Message-протоколов следуют за ядром и API. [Этап P0](../../../next_core_tasks_v3.md#p0-mix-python-priority-20261128) · [Приёмка после ядра](../../../next_core_tasks_v3.md#mix-python-message-after-kernel) |
| Публикации и результаты испытаний | Датированные расписки относятся к файлам поставки. В рабочем каталоге материалы четырёх протоколов вошли в исходники, руководства, Markdown и CSV группы 06. Для XLSX, PDF и сводной статистики сохранён отдельный шаг. Отчёты Java, CPython и хостовой модели P0 имеют указанную в них область проверки. Производственное исполнение Python-ворот, инкрементального P0 и новых протоколов остаётся открытым. [Протоколы](../../spec/patterns/06_async_and_messages/MESSAGE_PROTOCOLS_2026-11-28.md) · [Проверки P0/MIX](../../com.mtk.map/validation/README.md) · [Проверки Python](../../../include_languages/validation/README.md) |
