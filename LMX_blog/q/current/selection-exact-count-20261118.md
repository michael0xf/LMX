# Выбор объявления: объявление с большим числом формалов, когда есть объявление с ровно поданным числом

Дата: 2026-11-18. Задаёт исполнитель (сессия fable_pc). Статус: **открыт**.

## Что столкнулось

Книга, [выбор объявления по вызову](../../../docs/LMX_semantics.ru.md#declaration-selection), говорит две вещи.

- Правило 2: «Если среди них есть объявление, число аргументов которого равно числу поданных, используется оно».
  Для одного аргумента это слова автора ([журнал](../../2026-11-18.md#declaration-selection)); на любое число
  аргументов правило распространил исполнитель.
- Абзац «Общий алгоритм»: проверяются все видимые объявления имени и оба чтения аргументов; порядка предпочтения
  между объявлениями нет; при расхождении с правилами действует алгоритм
  ([журнал](../../2026-11-18.md#general-algorithm)).

Правило 5 книги — чтение исполнителя: все входы необязательны, поэтому вызов с меньшим числом аргументов подходит и
объявлению, у которого формалов больше.

## Программа

```lmx
fn: f (int: a) int
    return: a
fn: f (int: a; int: b) int
    return: a + 100
seen := f(5)
```

## Два чтения

1. Число поданных аргументов выбирает объявление. `f(5)` вызывает первое объявление: `seen` = 5. Объявление, у
   которого формалов больше, рассматривается, только когда объявления с ровно таким числом нет. Два объявления выше
   не перекрываются.
2. Числа никто не предпочитает. `f(5)` подходит обоим объявлениям: второму — потому что `b` необязателен. Это ошибка
   неоднозначности, а два объявления выше перекрываются. Чтобы их развести, пишут `required: int: b`: тогда `f(5)`
   даёт 5, а `f(5; 6)` — 105.

## Масштаб

Все одноимённые объявления, которые различаются числом формалов, и формы ресиверов `call` и `fncall` — у каждого по
три формы с разным числом аргументов.

## Слова автора после вопроса

Автор описал порядок на примере `call(P)` ([журнал](../../2026-11-18.md#call-one-argument-declaration)): «С
одни аргументом есть? Есть. Проверили на непротиворечивое раскрытие … и запустили». Порядок начинается с
объявления с поданным числом аргументов; объявления с большим числом формалов в нём не названы. Исполнитель
читает это как первое чтение; прямо о программе выше автор не говорил, поэтому вопрос остаётся открытым.

## Что исполнитель делает до ответа

Срез выбора объявления готовится вне дерева по первому чтению: оно ближе к словам автора «если объявлена
одноаргументная форма, используется сначала она». Свидетели на эту программу не закрепляются до ответа.
