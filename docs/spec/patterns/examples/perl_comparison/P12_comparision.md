# P12. Настройки окна после наложения и рабочая площадь

## Общий наблюдаемый договор

Наложить плоские совместимые настройки patch на base и вернуть (новые настройки, width*height). После наложения width и height обязательно присутствуют и являются неотрицательными целыми с представимым произведением. Ноль — полноценное значение, все другие поля сохраняются, входы не меняются. Вложенные изменяемые графы не входят в общий профиль сравнения.

Общий минимальный стиль: структурное наложение настроек и вычисление площади; явные обходы не нужны и не меняют меру функционального сахара.

Площадь вычисляется после наложения, так что patch с width=0 влияет и на настройки, и на результат. Обе LMX-формы остаются общей минимальной формой: структурный merge с общей картой копирования не заменён несоответствующим по договору обходом полей.

## Вход и ожидаемое наблюдение

```json
{
  "arguments": [
    {
      "width": 80,
      "height": 24,
      "theme": "dark"
    },
    {
      "width": 120,
      "border": 0
    }
  ],
  "result": [
    {
      "width": 120,
      "height": 24,
      "theme": "dark",
      "border": 0
    },
    2880
  ]
}
```

## LMX — общая минимальная форма обоих стилей

Общий минимальный стиль: структурное наложение настроек и вычисление площади; явные обходы не нужны и не меняют меру функционального сахара.

```lmx
Example:
    @: base
    @: patch
    return: @
    run:
        @: settings (merge(base; patch))
        return: (settings; settings\width * settings\height)
```

[Общий исходник](source/lmx/P12.lm3). Обе формы используют этот текст. 110 непробельных символов; 7 непустых строк. Все объявления и Throws включены.

## Perl

[Полный исходник](source/perl/P12.pl).

```perl
use strict;
use warnings;
sub example {
    my ($base, $patch) = @_;
    my $settings = {%$base, %$patch};
    return [$settings, $settings->{width} * $settings->{height}];
}
```

## Общие библиотечные реализации

Используются базовые операции языка; предметные определения приведены целиком.

Тела библиотечного ядра сохранены в одном общем источнике и не размножаются для двух стилей. Иностранный клиент использует свои настоящие средства; соседние comparison-реализации он не импортирует.
