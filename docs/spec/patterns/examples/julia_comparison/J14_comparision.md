# J14. Все значения положительны

## Общий наблюдаемый договор

Истина, если каждый элемент больше нуля. Пустой вход даёт истину; просмотр заканчивается после первого отказа.

Обе формы сохраняют один наблюдаемый договор; процедурная запись показывает управление и изменение данных, функциональная использует общие операции ядра.



## Вход и ожидаемое наблюдение

```json
{
  "arguments": {
    "xs": [
      1,
      2,
      3
    ]
  },
  "result": true
}
```

## Размер полных клиентов

| Полный исходник | Непробельные символы | Все Unicode-символы | Непустые строки |
| --- | ---: | ---: | ---: |
| LMX процедурный | 85 | 185 | 10 |
| LMX функциональный | 134 | 204 | 11 |
| Julia | 26 | 34 | 1 |

Обе LMX-формы опубликованы и считаются независимо. Все определения, обработчики и ссылки на throws входят в полный размер. Выбор единственного LMX-варианта по длине не выполняется.

## LMX — процедурный

```lmx
Example:
    int[]: xs
    return: int
    run:
        int: i 0
        while: i < length(xs)
            if: xs[i] <= 0
                return: 0
            i += 1
        return: 1
```

[Полный исходник](source/lmx/procedural/J14.lm3). 85 непробельных символов; 10 непустых строк. Все объявления и Throws включены.

## LMX — функциональный

```lmx
Positive:
    int: value
    return: int
    accepts:
        return: value > 0

Example:
    int[]: xs
    return: int
    run:
        throws: copy(all\throws)
        return: all(xs; Positive\accepts)
```

[Полный исходник](source/lmx/J14.lm3). 134 непробельных символов; 11 непустых строк. Все объявления и Throws включены.

## Julia

[Полный исходник](source/julia/J14.jl).

```julia
example(xs) = all(x -> x > 0, xs)
```

## Общие библиотечные реализации

- `all`: [полная пара реализации](library_comparisons/JI01_comparision.md)

Тела библиотечного ядра сохранены в одном общем источнике и не размножаются для двух стилей. Иностранный клиент использует свои настоящие средства; соседние comparison-реализации он не импортирует.

## Проверка

LMX и Julia: **NOT_RUN** в этой сборке. Проверяются обе LMX-формы как текст и общий независимый oracle; это не языковое исполнение.
