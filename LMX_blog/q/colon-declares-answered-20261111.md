## П1. Ссылка на Structure

Место-ссылку объявляет ресивер @. В data структурная форма задаёт Structure; в code она вызывает голову.

```text
Если мы хотим указатель-переменную на структуру то делаем:
@: ptr KnownStruct
```

## П4. Кто получает результат merge

В code `R: merge(A; B)` вызывает R, а в data задаёт Structure R с написанным выражением внутри.
Результат в локальном месте-ссылке code получает форма `@: R merge(A; B)`.
В data эта форма хранит вычисляемое описание: вход в вызов не исполняет merge заранее.
[Объявляющий контракт](../../docs/LMX_semantics.ru.md#receiver-args-only),
[кадр](../../docs/LMX_semantics.ru.md#call-frame-20261115).

## П5. Именованная подача

Именованная подача использует :=; обычная структурная форма аргумента в code вызывает свою голову.

```text
Проследи чтобы разбор аргументов вообще и ресиверов в частности ничем не отличался от универсального разбора и производился общим алгоритмом. Если у нас есть вызов: 
f(arg: Struct) то в code это вызов arg без вариантов, f(arg := Struct) таким образом --именованный аргумент.
```

## П2. Даёт ли запись Имя: (поля) поля непосредственно в Имя?

Нет. Скобки сохраняют анонимную Structure как одно поле.
Для `Box: (int: i 5)` путь к i — `Box[0]\i`.
`Box: int: i 5` и `Box(int: i 5)` помещают поле i непосредственно в Box.
Ресивер объявления примитива сворачивается в ячейку, а не добавляет промежуточный
уровень с именем int. Готовое значение сворачивается при построении чистого графа;
вычисляемое объявление сохраняет написанный код.
[Грамматика §18](../../docs/LMX_grammar.ru.md#empty-colon),
[построение и кадр](../../docs/LMX_semantics.ru.md#call-frame-20261115).

## П3. Ссылка на Structure не копирует её дерево

В data запись `Struct1: Struct2` задаёт Struct1 с одним полем-ссылкой на Struct2.
Она не переносит лексических детей Struct2 под Struct1 и не меняет parent
адресуемой Structure. Имена Structure видны в обе стороны; переменные и const —
последовательно. Явный merge копирует граф по своему общему контракту.

Дословная выдержка автора:

~~~text
То есть У Struct1[0]\Struct2 parent не меняется -- а именно parent у нас это место в дереве
~~~

[композиция](../../docs/LMX_semantics.ru.md#composition),
[видимость](../../docs/LMX_semantics.ru.md#declaration-visibility).
