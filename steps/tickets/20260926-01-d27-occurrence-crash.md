## 1. D-27 — падение без located-отказа (первым: это crash, не ограничение)

`steps/defects.md` D-27: безкорневая форма `\[N]x` для не-параметрного own-локала, объявленного и дважды присвоенного (`int: x` / `x: 10` / `x: 20` / `\[0]x`), — «translation failed with no located diagnostic». После D-79 (F-70) правило одно: поле заводит только объявление, `\[N]` считает объявления (c3c), присваивание вхождением не является. Значит:

- `\[0]x` при одном объявлении — единственное вхождение, читается как `x` (в примере — 20);
- `\[1]x` при одном объявлении — located-отказ «no such occurrence» (как у `\[1]arg`, c3c);
- падение без места — недопустимо в любом случае.

Сделать: найти путь `l2_own_find_occ` / разбор `\[N]` для не-параметрного локала, дать located-отказ или значение по правилу выше; свидетель — фикстура с `\[0]x` = 20 (Entry ненулевой, например 7 при совпадении) и фикстура `l2trans-refuses` с `\[1]x` и needle «no such occurrence»; мутант — вернуть прежний путь → снова «no located diagnostic», строка красная. Обе копии `tests/` (песочница и `l2src/`).
