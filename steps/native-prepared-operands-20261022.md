# Native emission consumes prepared operands

Native expression emission now owns one ordinary operand list and projects
its completed path results. The former whole-path retry, names-only loop,
separate Array/index route and raw member-token fallback in
l2_emit_fields_context are removed. This closes that native entry, not
every path consumer or the full kernel.

## Shared result and evaluation order

l2_emit_fields_context constructs and releases one l2_value_fields list.
Its binary receiving-role check does not adapt the path again.
l2_emit_native_values and l2_emit_native_span borrow that list.
A held path refusal is final; an authoritative non-path primary keeps
its ordinary P0 visitor. There is no names-only or raw-token rescue
after the prepared result.

Logical arms use prepared coordinates with lazy evaluation.
The retained integer operator emitter still reads the live selected
code occurrence, preserves physical child order and refuses a
missing nested site. Its leaves now borrow native spans instead of
re-entering the raw field constructor.

Flat dereference prefixes borrow their already prepared child chain.
The shared type/place resolver takes a record view of that child's
completed verdict. Older raw indirect-head entries remain explicit
preparation boundaries; their ownership migration is not claimed.

Numeric and character primaries are recognized before lexical-name
probing in the common native primary visitor. Retained live literal
loads remain intact. This is source-role classification, not a new
graph opcode or native runtime name table.
