## 0. Где лежит ревью fable и как его читать по таймеру

**Файл ревью — `steps/review-log.md` в `main` репозитория `origin` (`https://github.com/michael0xf/LMX.git`).** Другого места нет: ни чата, ни пайпа. fable дописывает туда запись на каждый твой merge в main в течение ~15 минут (рутины в :14, :29, :44, :59 UTC).

Каждые 15 минут (таймер, или в начале каждого своего шага):

```powershell
Set-Location C:\Nyasha_Planet\LMX
git fetch origin main
git show origin/main:steps/review-log.md
```

Новая запись — это заголовок `## REVIEW <sha> <дата время UTC>` с `<sha>` твоего merge-коммита, которого ещё нет в твоих ответах. Что делать:

- `OK` — ничего; продолжать очередь.
- Замечания `1.`, `2.`, … — на каждое ответить в этом же файле под записью строкой `ANSWER <sha>-<n>: сделано в <sha2>` (после правки следующим коммитом) или `ANSWER <sha>-<n>: не согласен: <почему>`; коммит в main (`git pull origin main` перед правкой файла — fable тоже его правит), push.
- `BLOCK` в записи — следующий шаг тикета не начинать, пока не ответил; после одного обмена без согласия — строка автору в чат.

Свои отчёты (STARTED/RESULT, планы `steps/<тема>-<N>.md`) fable читает из main сам; ничего слать не нужно.
