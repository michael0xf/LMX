# LMX `dev/` — разработка, не стабильный корень

Как в L1: **корень репозитория — стабильный снимок**; здесь — рабочая копия и новые механизмы, пока они не приняты в корень.

| путь | роль |
| --- | --- |
| `l1src/`, `l2src/` в корне LMX | стабильная версия (после миграции и зеркала песочницы L1) |
| `dev/l2src_sandbox/` | рабочая копия `l2src/` для правок ядра и интерпретатора |
| `dev/l1src_sandbox/` | dev-копия P0 и её printTree; сохраняет пустой вертикальный аргумент, [сборка и тесты](l1src_sandbox/README.md) |
| `dev/graph_interp/` | интерпретатор того же графа, что исполняет нативный код |
| `build/` под `dev/` | артефакты, в git не входят |

Не править корневые `l1src/` / `l2src/` «чтобы попробовать». Сборка ядра — в `dev/l2src_sandbox/build`, парсера — в `dev/l1src_sandbox/build` (оба каталога игнорируются).

## Правило для правок ядра: тип в заголовке — прогнать L3

Закреплённый `l1trans` держит имена типов всего замыкания `predef` одной транслируемой единицы в таблице на **64 имени** (и 4096 байт) и 65-е отвергает словами `too many header type names` — причём в том заголовке, который прочитан последним, а не в том, что добавил тип. Единицы L3 с Thread стоят у самого края: 62 из 64.

`tools/build_l2src.ps1` каталог `dev/l3_interp` **не собирает**, поэтому зелёный гейт L2 об этом классе поломок не говорит ничего: `4ab2877` добавил два типа в заголовок ядра, гейт был зелёным, а все наборы L3 с Thread перестали транслироваться.

Поэтому любая правка `dev/l2src_sandbox`, добавляющая в заголовок `struct:`, `enum:`, `fnptr:`, `foreign:` или `type:` (или новый `predef:` заголовка), обязана до коммита прогнать:

- `python tools/run_l3_selftest.py` — наборы по умолчанию и проверка бюджета имён;
- `python tools/run_l3_selftest.py --test tests/l3_n9_walk_selftest.lm1` и то же для `tests/l3_n10_walk_selftest.lm1` — они не входят в набор по умолчанию;
- отдельно бюджет: `python tools/l3_type_budget.py` — число имён меряется самим закреплённым транслятором, сбой наступает при любом отклонении от записанных 62, то есть раньше обрыва.

Если бюджет изменился по делу, число в `EXPECT` меняют вместе с объяснением причины; подгонять его под результат нельзя. Подробности — в [l3_interp/README.md](l3_interp/README.md#бюджет-имён-типов).
