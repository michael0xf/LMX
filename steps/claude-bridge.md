# Мост Claude Code: состояние работы

Актуальные команды, устройство профилей и текст для других агентов: [claude_chat/README.md](../claude_chat/README.md).

- По новому поручению автора настройка возобновлена: создана поддержка N отдельных профилей в `claude_chat/profiles/`.
- Начальные профили: `grok`, `grok_bot`, `claude_code`. Старый каталог `.claude-bridge/` не изменён; он не используется новыми командами автоматически.
- Проверено 7 тестов и реальный `auth status` каждого профиля. Все три возвращают `loggedIn: false`; обмен с моделью не состоялся.
- Ожидается ответ автора о провайдере. Для Anthropic нужен интерактивный вход отдельно в каждом профиле; авторизацию нельзя считать выполненной по факту создания каталога.
- После подключения выполнить два связанных запроса на профиль и обновить состояние по результатам. Два работающих агента L1 не затрагивать.

Проверки: `python -m unittest discover -s tests -p test_claude_bridge.py -v`.

Источники: [CLI](https://code.claude.com/docs/en/headless), [изоляция настроек](https://code.claude.com/docs/en/settings), справка установленного Claude Code 2.1.278.
