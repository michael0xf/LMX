# Используемый общий шаблон

В сравнительных примерах исходного архива, в том числе `lmx_beauty.en.md`, раздел «What the Template Contains», ядро предоставляет следующий общий DATA:

```lmx
sys:
    OPERANDS_TEMPLATE:
        @: left
        []: @ right
        const: int: PASS_ARGS_AS_IS 0
        const: int: PRIORITY priority("+")
```

Пользовательский DATA начинает с `copy: sys\OPERANDS_TEMPLATE`, затем описывает собственный результат и метод. Шаблон не содержит return. Копирование предоставляет готовые свойства; новое одноимённое const-поле поверх скопированного не добавляется.

Исключение операнда требует одновременно написанную безымянную Structure
слева, right.length = 1 и написанную безымянную Structure в right[0]. Открывается
только внешний правый контейнер, один уровень. Left остаётся одной целой
Structure, вложенный RHS повторно не открывается. Возвращённая функцией
Structure, именованная ссылка и произвольный массив не открываются.
P0 сохраняет все написанные группы. Обычный callable W/E остаётся отдельным
контрактом. Для postfix record передаётся присутствующий пустой right Array.
