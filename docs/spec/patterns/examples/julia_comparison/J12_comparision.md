# J12. Группировка уникальных ID по разделам

## Общий наблюдаемый договор

Сначала удалить повторные целые ID по первому появлению, затем разбить их на нечётный и чётный разделы. Порядок внутри разделов сохраняется, отсутствующие разделы не создаются. Порядок самих групп не сравнивается; исходный поток не меняется.

Обе полные реализации выполняют один новый прикладной сценарий: процедурная задаёт алгоритм явно, функциональная использует общие операции ядра. Изменённые тексты требуют нового P0-прогона.

Сценарий расширен по замечанию автора: показана обработка данных и полезный итог, а не только вызов одной функции. Обе LMX-формы опубликованы и считаются независимо. Все определения, обработчики и ссылки на throws входят в полный размер. Выбор единственного LMX-варианта по длине не выполняется.

## LMX — процедурный

```lmx
Example:
    []int: xs
    return: @
    run:
        throws: copy(FxSeqPush\append\throws) copy(record\throws)
        []@: out []
        int: i 0
        while: i < length(xs)
            int: prior 0
            while: prior < i && xs[prior] != xs[i]
                prior += 1
            if: prior = i
                int: key xs[i] % 2 != 0
                int: j 0
                while: j < length(out) && \out[j]\key != key
                    j += 1
                if: j = length(out)
                    @: group (copy(FxGroup))
                    group\key := (key record)
                    group\items := (copy(()))
                    FxSeqPush\append(out; group)
                FxSeqPush\append(out[j]\items; (xs[i] record))
            i += 1
        return: out
```

[Полный исходник](source/lmx/procedural/J12.lm3). 407 непробельных символов; 24 непустых строк. Все объявления и Throws включены.

## LMX — функциональный

```lmx
Parity:
    int: value
    return: int
    key:
        return: value % 2 != 0


Example:
    []int: xs
    return: @
    run:
        throws: copy(groupBy\throws) copy(unique\throws)
        return: groupBy(unique(xs); Parity\key)
```

[Полный исходник](source/lmx/J12.lm3). 158 непробельных символов; 11 непустых строк. Все объявления и Throws включены.

## Julia

[Полный исходник](source/julia/J12.jl).

```julia
using SplitApplyCombine: group
function example(xs)
    distinct = unique(xs)
    group(isodd, distinct)
end
```

## Общие библиотечные реализации

- `unique`: [полная пара реализации](library_comparisons/JI04_comparision.md)
- `groupBy`: [полная пара реализации](library_comparisons/JI04_comparision.md)

Тела библиотечного ядра сохранены в одном общем источнике и не размножаются для двух стилей. Иностранный клиент использует свои настоящие средства; соседние comparison-реализации он не импортирует.

## Проверка

Изменённые LMX-исходники: parser/P0 **NOT_RUN**; прежний receipt не переносится на новый хэш. LMX и Julia runtime: **NOT_RUN** в этой сборке. Проверяются обе LMX-формы как текст и общий независимый oracle; это не языковое исполнение. Численные размеры пересчитаны по текущим полным исходникам.
