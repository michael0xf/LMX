# J08. История отрицательных остатков

## Общий наблюдаемый договор

Построить все остатки счёта: начальный seed и результат каждого поступления или списания из xs. Вернуть только отрицательные остатки в хронологическом порядке, включая отрицательный начальный остаток. Пустой вход может дать один отрицательный seed; переполнение исключено.

Обе полные реализации выполняют один новый прикладной сценарий: процедурная задаёт алгоритм явно, функциональная использует общие операции ядра. Изменённые тексты требуют нового P0-прогона.

Сценарий расширен по замечанию автора: показана обработка данных и полезный итог, а не только вызов одной функции. ## LMX — процедурный

```lmx
Example:
    int[]: xs
    int: seed
    return: @
    run:
        throws: copy(FxSeqPush\append\throws) copy(record\throws)
        @[]: out []
        int: balance seed
        int: i 0
        while: 1
            if: balance < 0
                FxSeqPush\append(out; (balance record))
            if: i = length(xs)
                break
            balance += xs[i]
            i += 1
        return: out
```

[Полный исходник](source/lmx/procedural/J08.lm3). 225 непробельных символов; 17 непустых строк. Все объявления и Throws включены.

## LMX — функциональный

```lmx
Negative:
    int: value
    return: int
    accepts:
        return: value < 0

Example:
    int[]: xs
    int: seed
    return: @
    run:
        throws: copy(scanl\throws) copy(record\throws) copy(filter\throws)
        return: filter(scanl(xs; (seed record); `+`); Negative\accepts)
```

[Полный исходник](source/lmx/J08.lm3). 207 непробельных символов; 12 непустых строк. Все объявления и Throws включены.

## Julia

[Полный исходник](source/julia/J08.jl).

```julia
function example(xs, seed)
    balances = [seed; accumulate(+, xs; init=seed)]
    filter(<(0), balances)
end
```
