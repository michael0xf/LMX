# P03. Итоговый баланс и сигнал дефицита

## Общий наблюдаемый договор

Применить последовательность целочисленных изменений к initial и вернуть (конечный баланс, флаг balance<0). Пустой список оставляет initial, нулевой баланс не является дефицитом. История промежуточных балансов не требуется; вход не меняется. Все суммы входят в общий точный диапазон int LMX и Perl.

Обе формы решают полный прикладной сценарий. Процедурная показывает алгоритм циклами и ветвлениями, функциональная использует общие операции; все поля, порядок, ошибки и полезный результат сохраняются.

Флаг дефицита — отдельный полезный результат, в том числе для пустого списка и ровно нулевого остатка. Другой договор с полной историей остаётся в P04.

## LMX — процедурный

```lmx
Example:
    []int: items
    int: initial
    return: @
    run:
        int: total initial
        int: i 0
        while: i < length(items)
            total += items[i]
            i += 1
        return: (total; total < 0)
```

[Полный исходник](source/lmx/procedural/P03.lm3). 126 непробельных символов; 11 непустых строк. Все объявления и Throws включены.

## LMX — функциональный

```lmx
Example:
    []int: items
    int: initial
    return: @
    run:
        int: balance (+ initial copy(items))
        return: (balance; balance < 0)
```

[Полный исходник](source/lmx/P03.lm3). 100 непробельных символов; 7 непустых строк. Все объявления и Throws включены.

## Perl

[Полный исходник](source/perl/P03.pl).

```perl
use strict;
use warnings;
use List::Util qw(sum0);
sub example {
    my ($items, $initial) = @_;
    my $balance = $initial + sum0(@$items);
    return [$balance, 0 + ($balance < 0)];
}
```

## Общие библиотечные реализации

Используются базовые операции языка; предметные определения приведены целиком.

Тела библиотечного ядра сохранены в одном общем источнике и не размножаются для двух стилей. Иностранный клиент использует свои настоящие средства; соседние comparison-реализации он не импортирует.
