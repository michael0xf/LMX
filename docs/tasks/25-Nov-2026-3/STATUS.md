# Статус коллекции C99 от 25 ноября (3)

**Историческая база.** Состав из 155 компонентов, самостоятельный CMake и
измерения сборки описывают этот снимок. Следующая интеграция пользуется
действующей рабочей коллекцией и выбором профиля для каждого потребителя.
Владение живыми ресурсами, callback-данные и время жизни остаются на стороне LMX.
