# Исторические реализации 2026-11-21

Этот каталог сохраняет прежние исходники и постановки. Он не входит в текущую
сборку. Здесь намеренно остались Int/@-специализации и старые области применения;
они не являются публичным общим API новой редакции. Написание проверяющего
ресивера актуализировано на satisfies; остальные старые ограничения описывают
только этот снимок.

Текущая версия: [README](../../README.md), [API](../../API.md),
[общий каталог](../../CATALOG.md). Старый механический отчёт не означает
исполнения LMX и не относится к новым исходникам.
