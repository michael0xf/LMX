# P21. Транслитерация алфавита ДНК

## Общий договор

Вернуть новую строку с одновременной заменой A↔T и C↔G. Другие ASCII-символы и длина не меняются; уже заменённые символы повторно не обрабатываются.

Общий translate реализует буквальное одновременное соответствие алфавитов и сохраняет прочие символы. Его полное тело и зависимости учитываются отдельно; локального повторного цикла нет.

## Вход и ожидаемый результат

```json
{
  "arguments": [
    "ACGTN"
  ],
  "result": "TGCAN"
}
```

Дополнительные границы находятся в test_cases канонического [examples.json](examples.json); harness исключён из размера кода.

## Размер выбранного варианта

| Источник | Все символы | Без пробельных | Без сложного Throws | Непустые строки |
|---|---:|---:|---:|---:|
| LMX | 142 | 102 | 102 | 6 |
| Perl | 99 | 75 | 75 | 6 |

Дополнительная колонка исключает только аргументы Throws после первого. Заголовок, первый аргумент и ссылки copy(Throws) сохраняются; исходник не изменяется.

Учитываются полные листинги, директивы, комментарии и обработка ошибок. Встроенное ядро не добавляется к каждому клиенту; его реализации считаются отдельно.

## LMX

[Исходник](source/lmx/P21.lm3).

```lmx
Example:
    char[]: text
    return: char[]
    run:
        throws: copy(FxThrows\sequence)
        return: translate(text; "ACGT"; "TGCA")
```

## Perl

[Исходник](source/perl/P21.pl).

```perl
use strict;
use warnings;
sub example {
    my ($text) = @_;
    return $text =~ tr/ACGT/TGCA/r;
}
```
