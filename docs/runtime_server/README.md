# API работающего LMX для агентов

<a id="runtime-service"></a>
## Что получает агент

Агент может передать исходный файл, письмо или уже построенную Structure, посмотреть, что находится в конкретном L3Thread, найти определения и места использования, предложить изменение и получить фактический результат от владельца. Для просмотра и навигации достаточно чистого графа. Явная команда нужна отдельно для исполнения, проверки, компиляции, теста, установки кода или отправки письма. Интерфейс относится к этапу 3 v3, сразу после приёмки ядра. [Очередь и критерии выхода](../../next_core_tasks_v3.md#runtime-agent-api-20261127) · [Книга семантики](../spec/LMX_semantics.ru.md#edit-api-runtime-server).

Сам сервер, команды, обработка событий, выдача каталога, отладочные сценарии и цикл агента пишутся на LMX уровня L3. Сервером служит приложение на том же runtime, которым оно управляет. Низкоуровневые привязки предоставляют ввод-вывод, SQLite и выбранного провайдера модели. Обычные Structure и Message соединяют эти части. Новые операции становятся доступны через допуск обычного вызываемого поля. Для каждого языка транспорта достаточно преобразования его конверта. [Договор API](API.md#runtime-operations) · [MCP и переход с lmx-dev](MCP.md#runtime-mcp).

| Задача | Вход | Что можно проверить |
| --- | --- | --- |
| Найти правило, исходное вхождение, сигнатуру, вызывающих, тесты или документацию | Поиск правил и запрос к выбранной публикации каталога | Источник, версия, порядок полей, доказанные и ещё неизвестные связи. [Каталог](CATALOGUE.md#thread-capture) |
| Посмотреть или собрать программу | `sys\fromLmx(text)`, обычное составление графа, `inspect` и `sys\toLmx(S)` | Текущий граф, включая общие ссылки, циклы и принадлежащие экспортируемому Thread таблицы. [Кодек](../spec/LMX_semantics.ru.md#from-lmx-contract) · [Формулировка автора](../../LMX_blog/2026-11-27-runtime-graph-api.md) |
| Изменить поведение | `insert`, `copyTo`, запись допущенного обработчика, обычная почта | Какое место изменил владелец и какой CODE выбирает следующий вызов. [Операции владельца](API.md#owner-operations) |
| Выполнить и отладить | Отдельный вызов, `post`, шаг конкретного исполнения | Реальный результат, отказ, остановка на следующей границе или статус доставки. [Ход агента](API.md#agent-job) |
| Проверить и собрать | По запросу — P0, семантическая проверка или трансляция, сборка, тест, публикация | Фаза, ревизии, лог, результат языка и процесса, состояние установки. [Существующие клиенты](MCP.md#development-parity) |

**Состояние.** Сегодня агенты пользуются действующим Python/FastMCP `lmx-dev`. Файлы LMX, SQL и сообщения MCP в этом каталоге служат проектом интерфейсов и входами для проверок. Наличие объявления порта, синтетической строки SQL или примера JSON ещё не даёт приложению соответствующей возможности. Для включения каждой возможности в ответ сервера требуется расписка её реального исполнения. [Действующий сервис](../../tools/lmx_dev/USAGE.md) · [Приёмочные сценарии](ACCEPTANCE.md#runtime-acceptance).
