# S15. Несколько возвращаемых значений

Полное сравнение на указанном домене.

## Общий договор

Для целого n>=0 и целого divisor>0 вернуть [quotient,remainder], где n=quotient*divisor+remainder и 0<=remainder<divisor. Числа помещаются в LMX int.

## Размер полных вариантов

| Источник | Без пробельных | Все символы | Непустые строки |
| --- | ---: | ---: | ---: |
| LMX — процедурный | 98 | 150 | 7 |
| LMX — функциональный | 98 | 150 | 7 |
| Common Lisp / SBCL | 60 | 70 | 2 |

Оба стиля LMX сравниваются независимо по одному договору. Все объявления, вспомогательные определения и Throws входят в размер. Реализация общих библиотечных операций учитывается отдельно один раз.

## LMX — общая минимальная форма обоих стилей

Скалярные remainder/division и обычная Structure результата уже составляют минимальное выражение. Оба стиля сохраняют вычисление целого quotient на заявленном int-домене без подмены его bigint-профилем.

```lmx
Example:
    int: n
    int: divisor
    return: @
    run:
        int: remainder n % divisor
        return: ((n - remainder) / divisor; remainder)
```

[Общий полный исходник](source/lmx/S15.lm3). Оба стилевых столбца учитывают этот текст целиком: 98 непробельных символов; 7 непустых строк.

## Common Lisp / SBCL

[Полный исходник](source/common-lisp/S15.lisp).

```common-lisp
(defun example (n divisor)
  (multiple-value-list (floor n divisor)))
```

## Соответствие стилей договору

Скалярные remainder/division и обычная Structure результата уже составляют минимальное выражение. Оба стиля сохраняют вычисление целого quotient на заявленном int-домене без подмены его bigint-профилем.

CL FLOOR возвращает два значения по протоколу multiple values. На общей границе они явно собраны в список; LMX возвращает структуру значений. Отрицательное деление не входит в общий профиль.

LMX возвращает одну структуру из двух значений; она не выдаётся за протокол нескольких независимых return values CL. Деление в числителе точное, отрицательные аргументы вне общего профиля.

## Общие операции и реализации

Общий договор выражен базовыми средствами языка и приведёнными прикладными определениями.

Common Lisp-клиент использует указанные native/standard средства и не импортирует сравнительные реализации.
