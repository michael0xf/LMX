<a id="minimal-mechanism"></a>
## Указатели и минимальный механизм

Последующие технические сообщения автора целиком:

```text
только проследи чтобы там не было каких-то костылей. Возможно там нужны указатели на указатели, например (подумай)
```

```text
то есть не нужно вокруг этой возможности строить инфраструктуру которая ухудшит архитектуру. Нужно найти максимально короткий и лаконичный способ
```

Исполнитель предложил вариант 1: обычные указатели на поля заголовка и явное разыменование
`\(d\native) := 0`; вариант 2 сохранял прямую запись `d\native := 0` через связанные поля.
Было явно указано, что вариант 1 меняет ранее обсуждавшуюся форму записи. Ответ автора дословно:

```text
вот я же объясняю что здесь не важно -- надо сделать тот вариант, который потребляет меньше машинного ресурса. 1?
```

Выбор исполнителя для ТЗ по этому ответу: вариант 1, без специального перенаправления присваиваний.
В результате хранятся адреса исходных полей; запись с явным разыменованием меняет исходную Lmx.
Для полей parent/data нужны соответственно Lmx ** и void **, для native — LmxEntry *, для size — size_t *.
Это техническое решение исполнителя по последнему указанию автора; измеренный выигрыш пока не заявлен.
