# S17. LOOP: условное накопление

Полное сравнение на указанном домене.

## Общий договор

Сложить квадраты нечётных целых из списка; пустой вход даёт 0. Отрицательные нечётные числа тоже включаются. Вход не меняется.

## Входы и ожидаемые наблюдения

```json
[
  {
```

## LMX — процедурный

```lmx
Example:
    int[]: items
    return: int
    run:
        int: total 0
        int: i 0
        while: i < length(items)
            int: value items[i]
            if: value % 2 != 0
                total += value * value
            i += 1
        return: total
```

[Полный исходник](source/lmx/procedural/S17.lm3). 134 непробельных символов; 12 непустых строк. Все объявления и Throws включены.

## LMX — функциональный

```lmx
Example:
    int[]: items
    return: int
    run:
        throws: copy(compress\throws)
        int[]: odd compress(items; items % 2 != 0)
        return: (+ 0 copy(odd * odd))
```

[Полный исходник](source/lmx/S17.lm3). 120 непробельных символов; 7 непустых строк. Все объявления и Throws включены.

## Common Lisp / SBCL

[Полный исходник](source/common-lisp/S17.lisp).

```common-lisp
(defun example (items)
  (loop for x in items when (oddp x) sum (* x x)))
```

## Соответствие стилей договору

Обе записи сохраняют полный договор; процедурная раскрывает прикладной обход, функциональная использует общие операции/Expression без копии ядрового алгоритма.

compress сначала выбирает нечётные числа; затем общий Expression складывает квадраты выбранных значений. Чётные элементы не возводятся в квадрат. Сохраняется общий расчёт LOOP без имитации его синтаксического DSL.
