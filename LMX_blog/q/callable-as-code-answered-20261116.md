## Вопрос

```text
Counter:
    int: steps 0

D:
    int: x 10

sub: s (int: x 5) (Counter\steps := Counter\steps + x)

call(D s)
```

Решено: ресивер запуска не выбирает часть внутри поданной Structure, `call(D s)` исполняет саму `s`,
а тело над другими данными пишется `call(D s\code)`. Из этого не следовало значение `Counter\steps`
после `call(D s)`. Назывались варианты: `10` — тело видит `x` из `D`; `5` — запись `int: x 5` части `s`
исполняется как код; отказ — записи самой `s` в роли code не дают определённого запуска; другое значение.

## Принятое уточнение

Редакторское пояснение, не слова автора. Вопрос был поставлен неверно: он просил выбрать число,
разрешение или запрет для одного сочетания, а это следствие общих механизмов, не отдельная норма.
Имя `s` называет Structure, созданную ресивером `sub`, а не запись объявления и не поданные ресиверу
аргументы; скобки записи объявления её устройства не определяют. В `call` можно передать любую
Structure, в том числе созданную `sub` или `fn` целиком: поданный объект исполняется общим
исполнителем по его фактическим полям. Запрета, автоматического выбора тела и особой ветви для
вызываемого нет; необычный результат такой программы не основание менять общий механизм.
Ни одно из названных значений нормой не закреплено.
