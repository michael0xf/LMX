# Codex: автозаполнение var и динамические входы

## Изменение

По [ответу автора](../../../LMX_blog/2026-11-08.md) все собственные поля автозаполненной var видны с первой строки тела.
Построитель за один проход тела строит его Lmx-операторы/вложенные методы и собирает имена собственных int-полей.
Затем создаёт var нужной длины. Объявление в теле остаётся оператором: инициализатор исполняется на своей строке
при каждом вызове, объявление без кандидата не читает и не сбрасывает существующее значение. Формалы не дублируются в var.
Сведения о происхождении полей не сохраняются; обе версии книги и спецификации реализации согласованы с ответом.

Автозаполнение — этап построения. Сбор методов для native — отдельный обход готового чистого графа: транслятор собирает
адреса методов один раз, использует список для генерации и установки входов, затем освобождает его.
Построитель не передаёт потребителям свои служебные таблицы. Список транслятора не сохраняется в графе.

При входе в метод один обход тела собирает непосредственно используемые свободные имена и отмечает собственные
числовые поля для загрузки. Формалы, собственные имена, селекторы путей и тела вложенных методов различаются по самому
графу; транзитивные требования вызываемых методов не добавляются. Числовые динамические входы получают отдельные
ячейки текущей активации из ближайшего рабочего значения цепочки. Локальная запись и @free используют эту ячейку,
не исходное место. Снимок предшествует исполнению var. После var загрузка идёт по строкам кадра без второго обхода тела.
Строки кадра и список обхода уничтожаются, последующий вход собирает их заново. Ячейки значений принадлежат арене,
как и ячейки фактических аргументов; завершение общего collector остаётся отдельной задачей.

Вложенный метод — обычная именованная Lmx тела, включая вызов до строки его объявления. Префикс разыменования теперь
вычисляет операнд общего вида и проверяет адрес ссылки, а не ищет только имя поля корня.
В книге также сняты действующие формулировки о числовых кодах и код→имя; исторические дословные цитаты не изменены.
