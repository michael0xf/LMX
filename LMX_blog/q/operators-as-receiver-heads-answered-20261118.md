## Как исполнитель читает модель

Оператор — ресивер-голова в инфиксной позиции. Слева стоит его первый операнд, справа — всё остальное до конца
записи, как тело головы. Аргументов у ресивера переменное число.

| запись | чтение |
|---|---|
| `(1 + 2 + 3 + 4)` | `(1 plus: 2 plus: 3 plus: 4)`: три ресивера, вложение вправо |
| `(+ 1 2 3 4)` | один ресивер с четырьмя аргументами |
| `(1 + 2 3 4)` | тот же один ресивер: первый операнд слева, три справа |

Третий вопрос исполнителя — допустима ли сама короткая форма — этим отвечен: допустима.

## С чем это сталкивается

Грамматика, [операторы](../../docs/spec/LMX_grammar.ru.md#operators): «Префиксную, постфиксную или инфиксную роль,
приоритет и смысл операции определяет профиль выражений после P0. В C-проекции сохраняются приоритеты и
ассоциативность ANSI C». Там же решение автора 2026-11-07 о степени: `**` группируется справа и связывает сильнее
`*`, `/`, `%`, `+`, `-`; `2 * 3 ** 2` есть `2 * (3 ** 2)`.

Сегодня разбор оставляет операторы атомами среди полей; приоритеты применяет профиль выражений после разбора:

| запись | дерево разбора сегодня |
|---|---|
| `x := (1 + 2 + 3 + 4)` | Structure из семи полей: `1`, `+`, `2`, `+`, `3`, `+`, `4` |
| `x := (+ 1 2 3 4)` | Structure из пяти полей: `+`, `1`, `2`, `3`, `4` |
| `x := (2 * 3 + 1)` | Structure из пяти полей: `2`, `*`, `3`, `+`, `1` |

## Что исследуется

Направление, названное автором: разбор один и приоритетов не знает; исполнитель разбирает дерево выражения и
исполняет ресиверы по приоритету. Тогда `(2 * 3 + 1)` даёт 7 и `(10 - 3 - 2)` даёт 5, как сегодня, и исходники
не переписываются. Остаётся выяснить: как исполнитель отличает цепочку операторов, исполняемую по приоритету,
от явной группы в скобках, исполняемой целиком; где записан порядок приоритетов — одной таблицей
операторов-ресиверов или в объявлении каждого оператора.

Как исполнитель читает последнее сообщение автора. Исполнение идёт по приоритету: сначала ищутся самые
приоритетные операторы, а менее приоритетные, оказавшиеся внутри их тела, переносятся в родителя; исполненный
узел заменяется своим значением. `(1 + 2 * 2 + 3)` переходит в `(1 + 4 + 3)` и даёт 8. В
`(1 + v := 2 * 3)` присваивание исполняется первым, итог 7; исполнитель читает, что `v` получает 6. Оператор с
несколькими аргументами равен цепочке: `(1 + 2 * 2 + 3 4 5 6)` и `(1 + * 2 2 + 3 4 5 6)` — это
`(1 + 2 * 2 + 3 + 4 + 5 + 6)`, то есть 23.

### 0. Вопрос автору: меняется ли записанная программа

«Меняет само дерево» — описание порядка вычисления, а программа, записанная в чистом графе, остаётся прежней?

```lmx
fn: g () int
    return: (1 + v := v + 1)
```

Два вызова подряд при `v` = 0. Ответы 2 и 3 — программа в графе не меняется, меняется только рабочее значение.
Ответы 2 и 2 — узел присваивания в графе заменён значением. Исполнитель читает первое.

Для сравнения — что было бы без этого: если оператор читается как голова и ничего не добавлено, приоритетов
нет и вложение идёт вправо.

### 1. Разные операторы

`(2 * 3 + 1)`: по модели — `2 * (3 + 1)`, то есть 8; с приоритетами ANSI C — 7.

Масштаб, счёт исполнителя по поддерживаемым исходникам и тестам: из 31 426 записей с инфиксным оператором значение
изменится у 14 373 (`src/l2src` 12 266 из 26 359, `tools` 1 042 из 3 265, `tests/graph` 108 из 504, `tests/dyn` 957
из 1 298). Пример: `if: data = 0 || n = 0U` читалась бы как `data = (0 || (n = 0U))`.

### 2. Цепочка одного неассоциативного оператора

`(10 - 3 - 2)`: по модели — `10 - (3 - 2)`, то есть 9; с ассоциативностью ANSI C — 5. Пять по модели пишется
одним ресивером: `(10 - 3 2)`.

### 3. Что нужно выяснить

- Где и как приоритеты применяются сегодня: разбор, построитель чистого графа, интерпретатор, эмиттер, прежний
  frontend; есть ли одна таблица операторов.
- Какие варианты совместимы со словами «выражения разбирает тот же разбор»: приоритеты в самом разборе; чтение
  без приоритетов с механической расстановкой скобок в исходниках; иное.
- Цена каждого варианта: сколько записей меняется, можно ли переписать их автоматически, что происходит с
  решением 2026-11-07 о `**` и с унарным минусом.

## Что принято

Редакторское пояснение исполнителя, не слова автора.

- В языке один разбор; выражения разбирает он же. Приоритетов разбор не знает.
- Оператор — ресивер-голова с переменным числом аргументов. `(1 + 2 + 3 + 4)` — это
  `(1 plus: 2 plus: 3 plus: 4)`; `(+ 1 2 3 4)` и `(1 + 2 3 4)` — запись одним ресивером.
- Приоритет применяется при исполнении: дерево выражения разбирается, более приоритетные операторы исполняются
  первыми, менее приоритетные переносятся в родителя. `(2 * 3 + 1)` даёт 7, `(10 - 3 - 2)` даёт 5, как сегодня;
  исходники не переписываются. Чистый граф при этом не меняется.
- Порядок приоритетов и ассоциативность остаются теми, что записаны в грамматике, — это чтение исполнителя
  ([ответы исполнителя, Р76](fable-self-answers-20261110.md)).
