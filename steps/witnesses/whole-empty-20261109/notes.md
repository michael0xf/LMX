# Пустая цепочка полей и общий допуск всей структуры аргументов — 2026-11-09

Исполнитель: opus. По ревью Codex результата 323 (CODEX-OPUS-323-RESULT, копия
[records/pins/codex-323-result-review.txt](records/pins/codex-323-result-review.txt)): (1) пустая именованная Structure
как единственная фактическая — пустая цепочка полей, вызов нульарного или только с умолчаниями вызываемого; на 323
`lmx_graph_bind_call` отказывал `count 1 > width 0` до одиночного кандидата, а `lmx_graph_call_single` возвращал 5 при
width 0 и ставил `whole = (n > 0)`; (2) выбор «вся структура или первый аргумент» на 323 шёл по проверке рода поля и
формала (int ↔ int-формал, Structure ↔ формал модели) до общего допуска — это сокращение, не первая часть `implements`,
обещанная автором (журнал 2026-11-08, строки 22–37), и не правило языка.

## Изменение

- `lmx_graph_bind_call`: одиночный кандидат (`lmx_graph_single_candidate`) проходит только проверку формы вызываемого
  (`lmx_graph_call_shape`) и сопоставляется с формалами в `lmx_graph_call_single`; проверка числа фактических и
  обязательных формалов для него — там же, после известного значения, до эффектов.
- `lmx_graph_call_single`: Structure — вся структура аргументов, когда каждое прямое поле называет формал (каждый — не
  более одного раза), каждый формал без поля имеет прямое умолчание и **каждое поле принимается своим формалом общим
  допуском** этого подмножества (`lmx_graph_admit`: int-формал читает int, формал модели — первая часть `implements` по
  используемым путям); проверка родов удалена. Пустая Structure — пустая цепочка (вызов нульарного или только с
  умолчаниями); нульарный вызываемый допускается. Иначе — обычный первый аргумент (у нульарного — отказ формы 5).
  Таблицы преобразований в этом подмножестве ещё нет — граница реализации, не правило.
- Фикстура `whole_empty` (+ `.expected`); `inputs.list` — 342 входа. Ядро — `lmx_graph_run.lm2`; экспорты и
  `tools/build.lm2` не менялись (tool24 прежний).

## Пустая именованная Structure — ограничение построителя

Пробы в стейдже (`S/tests/graph/opus_probe324a–d.lm2`, вне manifest; логи `P/pins/opus324-probe-*.log`): и
`Empty: ()`, и `Empty:` + `end: Empty` P0 разбирает как Frame `Empty` с пустым телом **без** trailer (в вертикальной
форме строка `end: Empty` не становится trailer пустого тела); построитель строит именованную Structure только у головы
данных с trailer `end:`, поэтому делает из такой записи оператор, и исполнение корня отказывает (5) на нём, до вызовов.
Решать на уровне построителя «объявление или присваивание» для `Name: ()` значило бы разрешать имя, чего построитель
не делает (§3.5). Механизм пустой цепочки проверен на существующей пустой Structure — части `var` нульарного метода
(`zero\var`).
