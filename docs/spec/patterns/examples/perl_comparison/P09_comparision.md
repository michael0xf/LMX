# P09. Уникальные идентификаторы и число повторных поступлений

## Общий наблюдаемый договор

Из потока канонических целых идентификаторов оставить первые вхождения в исходном порядке и вернуть (уникальные идентификаторы, число удалённых повторных поступлений). Ноль и отрицательные идентификаторы остаются значениями. Пустой вход даёт ([],0), вход не меняется. Обобщённая операция unique ядра этим прикладным целочисленным доменом не ограничена.

Обе формы решают полный прикладной сценарий. Процедурная показывает алгоритм циклами и ветвлениями, функциональная использует общие операции; все поля, порядок, ошибки и полезный результат сохраняются.

Счётчик повторов нужен для отчёта о повторной доставке идентификаторов. Он не меняет порядок первых вхождений и не сводит результат к демонстрационной сумме.

## LMX — процедурный

```lmx
Example:
    []int: items
    return: @
    run:
        throws: copy(FxSeqPush\append\throws) copy(record\throws)
        []int: out []
        int: i 0
        while: i < length(items)
            int: j 0
            while: j < length(out) && out[j] != items[i]
                j += 1
            if: j = length(out)
                FxSeqPush\append(out; (items[i] record))
            i += 1
        return: (out; length(items) - length(out))
```

## LMX — функциональный

```lmx
Example:
    []int: items
    return: @
    run:
        throws: copy(unique\throws)
        @: selected unique(items)
        return: (selected; length(items) - length(selected))
```

[Полный исходник](source/lmx/P09.lm3). 128 непробельных символов; 7 непустых строк. Все объявления и Throws включены.

## Perl

[Полный исходник](source/perl/P09.pl).

```perl
use strict;
use warnings;
use List::Util qw(uniqnum);
sub example {
    my ($items) = @_;
    my @selected = uniqnum(@$items);
    return [\@selected, scalar(@$items) - scalar(@selected)];
}
```
