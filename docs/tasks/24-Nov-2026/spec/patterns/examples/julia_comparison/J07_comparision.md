# J07. Левая свёртка с неассоциативным шагом

## Общий наблюдаемый договор

Последовательно вычитать элементы из seed: ((seed - x0) - x1) ... . Пустой вход возвращает seed. Арифметика без переполнения.

Обе формы сохраняют один наблюдаемый договор; процедурная запись показывает управление и изменение данных, функциональная использует общие операции ядра.

Используется foldl, а не reduce: порядок связывания входит в контракт.

## Вход и ожидаемое наблюдение

```json
{
  "arguments": {
    "xs": [
      1,
      2,
      3
    ],
    "seed": 100
  },
  "result": 94
}
```

## LMX — процедурный

```lmx
Example:
    int[]: xs
    int: seed
    return: int
    run:
        int: total seed
        int: i 0
        while: i < length(xs)
            total -= xs[i]
            i += 1
        return: total
```

[Полный исходник](source/lmx/procedural/J07.lm3). 103 непробельных символов; 11 непустых строк. Все объявления и Throws включены.

## LMX — функциональный

```lmx
Example:
    int[]: xs
    int: seed
    return: int
    run:
        throws: copy(foldl\throws) copy(record\throws)
        return: \foldl(xs; (seed record); `-`)
```

[Полный исходник](source/lmx/J07.lm3). 116 непробельных символов; 7 непустых строк. Все объявления и Throws включены.

## Julia

[Полный исходник](source/julia/J07.jl).

```julia
example(xs, seed) = foldl(-, xs; init=seed)
```
