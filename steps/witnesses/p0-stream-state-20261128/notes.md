# Запись состояния и шаг потока общего P0: срез P0/MIX A1 (28 ноября 2026 года)

Ведущий `coder`. Приоритет автора (через Sol, `SOL-CODER-P0-MIX-PYTHON-PRIORITY-20261128`): подготовка общего P0 для
Cursor/MIX и `py.*`. План — [следующий срез общего P0](../../../next_core_tasks_v3.md#p0-mix-python-priority-20261128),
пункт 1: выделить в общем P0 договор чтения источника и продолжения. Договор —
[Cursor/MIX](../../../docs/com.mtk.map/p0/README.md#p0-mix-parser-contract): один общий парсер, без отдельных путей; у
`lm_p0_parse_stream` выделить сохраняемое состояние продолжения. Дизайн разграничения согласован Sol до кода (запрос
`CODER-DESIGN-P0MIX-20261128`, ответ `SOL-CODER-P0MIX-DESIGN-REVIEW-20261128`): порядок внутри среза A1 → A2 → A3 → A4;
A1 принимается и публикуется отдельно, если входы файла и буфера, деревья, диагностика и регистры границ совпали с
базой. База: набор `coder-p108` (`006a6ae33`).

## Норма

- План, пункт 1 (выше), и договор Cursor/MIX (выше).
- До среза состояние потока — десять локальных переменных одной функции `lm_p0_parse_stream`: позиция в источнике,
  номер строки, стек отступов, стек форм, отложенный разделитель, отложенный MIX, событие и три признака. Остановить
  автомат на границе и продолжить было нельзя: функция читала один буфер до конца.

## Что сделано

Только запись состояния и шаг. Вход остаётся целым буфером; никакой читатель не объявляет источник незавершённым,
ответа `need more` нет — это A2.

- **Запись `LmP0StreamState`** в заголовке P0, который пишет сборка (`tools/build.lm2`): десять полей — `offset`,
  `line`, `indent_stack`, `stack`, `pending`, `pending_mix`, `event`, `has_last_physical_level`, `group_base_set`,
  `last_physical_level`.
- **`p0_parser.lm2`:**
  - `lm_p0_parse_stream_load` — десять членов записи в параметры-выходы; пять чтений указателей приведены к типу;
  - `lm_p0_parse_stream_leave` — записывает десять значений в запись и отвечает кодом выхода шага;
  - `lm_p0_stream_state_new` — исходная инициализация потока с локальными переменными, включая пять начальных
    значений (позиция 0, строка 1, три признака 0), затем запись их в запись;
  - `lm_p0_stream_state_delete` — освобождает то, что держит запись, и саму запись;
  - `lm_p0_parse_stream_step` — одна итерация потока: текст исходной итерации без переписывания, на один уровень
    меньше отступа; выходы — 0 (диагностика поставлена), 2 (конец источника), 1 (дальше);
  - `lm_p0_parse_stream` — создаёт запись, выполняет шаги до конца, затем то, что стояло в конце (сброс
    отложенного MIX, разрешение отложенного разделителя), и освобождает запись.
- Операторы и их порядок — исходные. Запись между шагами — точное состояние автомата на возвращаемой границе.

## Границы среза

1. Вход только целый буфер. Файл читается целиком и передаётся байтами в `lm_p0_parse_bytes_observed`: один путь для
   файла и для буфера.
2. Граница возврата — только между шагами. Внутри шага значения держатся в локальных переменных и перезаписываются
   в запись на каждом выходе.
3. Квадратная ветка, дерево, диагностика и координаты не менялись.

## История сборки

- Первый кандидат `coder-p0a101` (стадия `stage-p0a1-01`, цепочка 16:04–16:07) остановлен на компиляции
  `p0_parser.lm2`: `5697:145: assignment value has unknown type` — член-указатель новой записи (`state\stack`)
  передавался аргументом прямо; модуль приводит такие чтения к типу. Во второй форме значения читаются в локальные
  переменные шага и записываются обратно на каждом выходе. Стадия `stage-p0a1-01` оставлена как остановленная и не
  используется.
- При сверке первого черновика с оригиналом найден ещё один его дефект: не были заданы пять начальных значений
  потока. Второй генератор берёт их из текста оригинала.
- Черновик делает рабочий инструмент `a1_make_step.py` из копии опубликованного модуля; черновики — в
  `build2/coder-grammar-20261127/p0mix-a1/draft/`.

## Что этим не заявлено

- Вход с незавершённым источником, ответ `need more`, состояние внутри шага и фаза прочитанного префикса — A2.
- `py.*` по границам `c.*` — A3; контроли графа и MIX — A4.
- Круговой проход исходника (`p0 FILE print`) — отдельная работа общей грамматики.
