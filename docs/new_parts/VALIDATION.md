# Проверка расширенной редакции

Дата: 21 ноября 2026 года. Этот отчёт относится к девяти новым группам и к сохранности исходного архива. Старые receipts корневой GoF-подборки не выдаются за повторный запуск в этой редакции.

## Комплектность и сохранность

Все **85 исходных пунктов** сохранены с номерами; добавлены 86–90. В девяти группах ровно **90 уникальных паттернов** и **270 листингов**: LMX и два выбранных контрольных языка у каждого. Для каждой группы предоставлены руководства RU/EN, сравнения Markdown, CSV, XLSX, PDF, JSON-источник и отдельные кодовые файлы.

Все **95 файлов исходного комплекта** сохранены. **91 файл побайтово неизменен**; различаются только README с новой навигацией, одна русская строка о пяти исключениях и два вхождения `success := 1` в английских почтовых документах. Нормативные правила языка при расширении не переписывались.

Переносимый скрипт [tools/recount_patterns.py](tools/recount_patterns.py) использует только стандартную библиотеку Python. Из корня распакованного архива:

```bash
python tools/recount_patterns.py --json recount_report.json
```

Он проверяет покрытие ID, порядок языков, совпадение JSON / кодовых файлов / Markdown, метрики Markdown и CSV, наличие обещанных форматов и целостность контейнеров XLSX. UTF-8 байты тоже вычисляются в отчёте. Скрипт не исполняет примеры и не заменяет визуальную проверку PDF или расчёт формул Excel.

## LMX и остальные контрольные языки

**LMX-ядро в исходном архиве отсутствует. Новые LMX-листинги не запускались; принятие их действующим parser/transpiler не заявляется.** Они проверены по текущим `newdocs` и уточнению автора от 21 ноября. Отдельно проверены DATA/parent, явная запись графовых слотов, W/E для целого аргумента, завершение блока пустой строкой, сохранение вложенных структур и материализация возвращаемых DTO.

Многопоточные варианты построены на Message. Проверка текста различает собственную арену и последовательный turn, запуск шаблона хостом, обычный `post`, ожидание ответа следующим входом и уже описанный HTTP-транспорт. Отмечены границы serial ownership, Message-local state, cancellation, durable delivery и транзакций. Общие контракты собраны в [MESSAGE_HTTP_PROFILE.md](MESSAGE_HTTP_PROFILE.md).

Java, C#, Go, Erlang, Rust, Haskell и Scala не компилировались и не исполнялись в этой среде: нужные toolchains недоступны. Обнаруженная команда `/usr/bin/go` относится к одноимённой настольной игре и не является компилятором Go. Ожидаемые результаты этих листингов остаются критериями для проверки в соответствующем окружении.

Для `post` в пакете есть нормативное описание, но нет полного буквального fixture с `ask`/`answer`. Примеры честно помечены как авторские применения контракта. Ни это ограничение, ни отсутствие runtime не отменяют существующего HTTP-профиля языка.

## Форматы и числовые таблицы

Для всех девяти XLSX проверены итоговые суммы, отсутствие ошибок формул и пересчёт отношения после временного изменения исходного числа с последующим восстановлением. Каждый лист отрисован и просмотрен: заголовки, кириллица, числа и имена файлов помещаются в своих столбцах.

Все девять новых PDF отрисованы и просмотрены постранично: **10 страниц**, поскольку доменная группа с 19 паттернами занимает две страницы. Проверены читаемость кириллицы, границы таблиц, повтор заголовка на продолжении и отсутствие наложений. PDF — краткая сводка; полный код и ограничения каждого случая находятся в Markdown.

Внутренние файловые ссылки новых материалов проверены на существование целей. Исходные документы сохранены с их прежними внешними зависимостями и историческими ссылками; этот отчёт не объявляет проверенными все внешние ресурсы старого комплекта.
