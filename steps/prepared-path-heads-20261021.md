# Compact path heads reuse prepared grammar

CHECK, native emission, retained writes and source eligibility now consume
the compact head's existing prepared path instead of splitting its text
again. The selected record carries qualification, types and maps into the
existing projectors. Forty actual positive runs and twelve write mutants
pass their respective oracles. Paths inside ordinary operand spans still
have repeated preparation routes; this change does not close that work.

Base main is `beb2d8a95b367c986705ac2e63bda15a5be1122d`. Candidate
`build/codex_prepared_heads_150` and frontend
`build/codex_heads150_build_01` use unchanged pinned149 application headers
and L1 working-directory inputs. The
[compiler patch](witnesses/used-scope-20261020/prepared-heads150-u0.patch)
replays over [Private149](shared-path-consumers-20261021.md). There is no
new cache, runtime entity, graph field, opcode or application-header change.

## Consumers borrow the original prepared head

`L2HeadExpression` already owns the compact head's parsed P0 and common
grammar result, including a miss. `l2_path_resolve_head` takes an independent
prepared view and invokes the ordinary semantic walk in the current source
context. It does not add a path grammar or semantic resolver. A partial
head is refused before root selection; a semantic refusal retains its
record. Neither case retries the text adapter.

`l2_check_path_write`, the native path-write branch, source eligibility and
call-path refusal reporting use this interface. CHECK also reads its root
from the prepared record instead of splitting the head text. Indexed head
dispatch uses the same interface before choosing its Array or machine view.
Retained path preparation uses the head interface when its argument is the
original Frame head. An arbitrary text operand remains a separate input
interface; it is never a fallback after a head-adapter failure.

Each successful consumer receives the completed root, per-step contracts,
qualification and maps. Existing native and retained projectors consume
that record. Independent later queries still resolve in their current
context; the retained grammar is not a cache of an earlier semantic answer.

The [prepared-head fixture](witnesses/used-scope-20261020/prepared-heads150-test.c)
passes502 checks over ranks1,2,6,65,129 with both qualifications. It counts
zero P0, run-adapter and text-adapter entries after head preparation, one
selected root and one semantic fold. Each step retains its consumed pointer
type; the final cell retains write qualification. Changing the formal's
type table does not relabel an already held result, while a new query sees
the new incompatible contract. Partial-head and unknown-field failures
remain distinct and do not start a second parser.

## Remaining common path work

This closes the explicitly migrated compact-head consumers, not every path
consumer. Ordinary `L2ValueSpan` still stores source coordinates rather than
prepared grammar and a completed result with an audited lifetime. CHECK's
field loop still has a names-only route; callable-head classification and
other text-only interfaces require their own caller audit. The remaining
text counts above are not hidden or declared harmless by these tests.

The next change must carry one prepared grammar and current resolved record
through the ordinary operand consumers, then remove their old entries rather
than retain a fallback. Native-only operations, numeric `LmxOp`, public-dev,
Model/Shelf scope, full kernel, L3/L2 self-build and mail T01–T26 remain open.
