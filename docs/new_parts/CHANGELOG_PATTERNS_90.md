## Уточнения, сделанные при проверке новых примеров

- Execute Around передаёт ресурс именованному входу целиком, чтобы произвольная Structure не получила иное W/E-чтение.
- У LMX-владельцев состояния внешняя обвязка явно заполняет фактический граф и передаёт вызовы нужному Message. Позиционный вход не предполагается автоматически пропускающим поля состояния.
- Для конкурентных потребителей C# обеспечивается запуск обоих workers; синхронное вычитывание готовой очереди первым вызовом не выдаётся за доказательство параллелизма.
- В P54 LMX-worker получает ответ следующим входом Message; блокирующее ожидание собственного будущего answer внутри текущего turn исключено.
- В P18, P23 и P57 передаваемые DTO собираются через копирование готового шаблона и явную запись полей. Вычисляемые initializer-формы не выдаются за уже материализованные переносимые значения.
- Message-local state, сериализованный доступ и readiness/completion не подменяют соответственно OS TLS, параллельное чтение и разные I/O-протоколы.
