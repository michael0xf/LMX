# P12. Наложение настроек с сохранением полей

## Общий наблюдаемый договор

Объединить плоские настройки со скалярными и строковыми значениями: patch заменяет одноимённые совместимые поля base, новые добавляются. Ноль — значение, остальные поля, включая width/height/theme, сохраняются. Входы не меняются.

Это одна неизменяемая структурная операция merge с единой картой копирования; разворачивание по полям изменило бы её базовый договор. Высокоуровневого обхода или цепочки callback здесь нет.

Общий профиль — плоские совместимые data-поля. merge LMX копирует использованный граф общим отображением; Perl создаёт новый хеш. Для этого сценария сравниваются значения полей; идентичность вложенных изменяемых графов и композиция кода не объявлены одинаковыми.

## Вход и ожидаемое наблюдение

```json
{
  "arguments": [
    {
      "width": 80,
      "height": 24,
      "theme": "dark"
    },
    {
      "width": 120,
      "border": 0
    }
  ],
  "result": {
    "width": 120,
    "height": 24,
    "theme": "dark",
    "border": 0
  }
}
```

## Размер полных клиентов

| Полный исходник | Непробельные символы | Все Unicode-символы | Непустые строки |
| --- | ---: | ---: | ---: |
| LMX процедурный | 59 | 94 | 6 |
| LMX функциональный | 59 | 94 | 6 |
| Perl | 77 | 101 | 6 |

Обе LMX-формы опубликованы и считаются независимо. Все определения, обработчики и ссылки на throws входят в полный размер. Выбор единственного LMX-варианта по длине не выполняется.

## LMX — общая минимальная форма обоих стилей

Это одна неизменяемая структурная операция merge с единой картой копирования; разворачивание по полям изменило бы её базовый договор. Высокоуровневого обхода или цепочки callback здесь нет.

```lmx
Example:
    @: base
    @: patch
    return: @
    run:
        return: (merge(base; patch))
```

[Общий полный исходник](source/lmx/P12.lm3). Оба стилевых столбца учитывают этот текст целиком: 59 непробельных символов; 6 непустых строк.

## Perl

[Полный исходник](source/perl/P12.pl).

```perl
use strict;
use warnings;
sub example {
    my ($base, $patch) = @_;
    return {%$base, %$patch};
}
```

## Общие библиотечные реализации

Используются базовые операции языка; предметные определения приведены целиком.

Тела библиотечного ядра сохранены в одном общем источнике и не размножаются для двух стилей. Иностранный клиент использует свои настоящие средства; соседние comparison-реализации он не импортирует.

## Проверка

Perl-клиенты проверяет [действительный harness](validation/client_tests.json). LMX: **NOT_RUN**; обе формы проверяются как исходники, без заявления runtime-приёмки.
