# S16. DESTRUCTURING-BIND: вложенная форма

Полное сравнение на указанном домене.

## Общий договор

Получить структуру ровно [a,[b,c]] и вернуть a+b*c. Неподходящая форма находится вне этой пары; автоматическое рекурсивное раскрытие аргумента LMX не предполагается.

## Входы и ожидаемые наблюдения

```json
[
  {
    "args": [
      [
        2,
        [
          3,
          4
        ]
      ]
    ],
    "expected": 14
  },
  {
    "args": [
      [
        0,
        [
          0,
          8
        ]
      ]
    ],
    "expected": 0
  },
  {
    "args": [
      [
        -1,
        [
          2,
          -3
        ]
      ]
    ],
    "expected": -7
  }
]
```

## Размер полных вариантов

| Источник | Без пробельных | Все символы | Непустые строки |
| --- | ---: | ---: | ---: |
| LMX — процедурный | 75 | 118 | 6 |
| LMX — функциональный | 75 | 118 | 6 |
| Common Lisp / SBCL | 60 | 79 | 3 |

Оба стиля LMX сравниваются независимо по одному договору. Все объявления, вспомогательные определения и Throws входят в размер. Реализация общих библиотечных операций учитывается отдельно один раз.

## LMX — общая минимальная форма обоих стилей

Обычные пути полей сохраняют точную форму [a,[b,c]] без автоматического рекурсивного раскрытия. Один скалярный Expression является минимальной формой обоих стилей.

```lmx
Example:
    @: tree
    return: int
    run:
        @: tail \tree[1]
        return: \tree[0] + \tail[0] * \tail[1]
```

[Общий полный исходник](source/lmx/S16.lm3). Оба стилевых столбца учитывают этот текст целиком: 75 непробельных символов; 6 непустых строк.

## Common Lisp / SBCL

[Полный исходник](source/common-lisp/S16.lisp).

```common-lisp
(defun example (tree)
  (destructuring-bind (a (b c)) tree
    (+ a (* b c))))
```

## Соответствие стилей договору

Обычные пути полей сохраняют точную форму [a,[b,c]] без автоматического рекурсивного раскрытия. Один скалярный Expression является минимальной формой обоих стилей.

tree передаётся целиком: после запуска корня выполнить обычный вызов Example/run(tree := форма), чтобы исключить CODE W/E для единственной структуры. Вложенность открывается явными индексами; recursive unwrapping отсутствует.

## Общие операции и реализации

Общий договор выражен базовыми средствами языка и приведёнными прикладными определениями.

Common Lisp-клиент использует указанные native/standard средства и не импортирует сравнительные реализации.
