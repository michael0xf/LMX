# J22. Цифры в ASCII-строке

## Общий наблюдаемый договор

Сохранить только символы от ASCII 0 до 9 в прежнем порядке. Контракт строкового клиента ограничен ASCII, а не всеми Unicode-категориями цифр.

Обе формы сохраняют один наблюдаемый договор; процедурная запись показывает управление и изменение данных, функциональная использует общие операции ядра.

Две поэлементные маски int 0/1 умножаются; compress оставляет ровно ASCII-цифры и сохраняет плотный char[]. Профиль сравнения ограничен ASCII, без обещания Unicode-категорий.

## Вход и ожидаемое наблюдение

```json
{
  "arguments": {
    "text": "AB-09 x2!"
  },
  "result": "092"
}
```

## Размер полных клиентов

| Полный исходник | Непробельные символы | Все Unicode-символы | Непустые строки |
| --- | ---: | ---: | ---: |
| LMX процедурный | 209 | 336 | 12 |
| LMX функциональный | 110 | 155 | 6 |
| Julia | 41 | 51 | 1 |

Обе LMX-формы опубликованы и считаются независимо. Все определения, обработчики и ссылки на throws входят в полный размер. Выбор единственного LMX-варианта по длине не выполняется.

## LMX — процедурный

```lmx
Example:
    char[]: text
    return: char[]
    run:
        throws: copy(FxSeqPush\append\throws) copy(record\throws)
        char[]: out []
        int: i 0
        while: i < length(text)
            if: text[i] >= '0' && text[i] <= '9'
                FxSeqPush\append(out; (text[i] record))
            i += 1
        return: out
```

[Полный исходник](source/lmx/procedural/J22.lm3). 209 непробельных символов; 12 непустых строк. Все объявления и Throws включены.

## LMX — функциональный

```lmx
Example:
    char[]: text
    return: char[]
    run:
        throws: copy(compress\throws)
        return: \compress(text; (text >= '0') * (text <= '9'))
```

[Полный исходник](source/lmx/J22.lm3). 110 непробельных символов; 6 непустых строк. Все объявления и Throws включены.

## Julia

[Полный исходник](source/julia/J22.jl).

```julia
example(text) = filter(c -> '0' <= c <= '9', text)
```

## Общие библиотечные реализации

- `compress`: [полная пара реализации](library_comparisons/JI02_comparision.md)

Тела библиотечного ядра сохранены в одном общем источнике и не размножаются для двух стилей. Иностранный клиент использует свои настоящие средства; соседние comparison-реализации он не импортирует.
