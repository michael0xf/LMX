# Load/cache/dirty: отмена механизма 2026-11-15

Прежнее решение о load-dirty и его уточнения 2026-11-13 заменены
[кадрами без обратной публикации](../LMX_semantics.ru.md#call-frame-20261115).
Файл сохраняет прежний адрес для ссылок; действующее ТЗ — [M14](../../next_core_tasks_v3.md#native-structures).

## 1. Что остаётся

Каждый вызов имеет свежий namespace из корневых объявлений data/code. Голое x и @x — локальное
место вызова; data\x и code\x — исходный граф. Поданное значение подавляет свой инициализатор.
Типы без значения сохраняются. Изменение локального места не записывается обратно; явные пути
меняют реально адресованную ячейку. Native и обходчик выбирают снимок исполняемого code при входе,
до инициализаторов; правка исходного code обнуляет native для следующего вызова.

## 2. Что удалить

Удалить load-dirty, публикации локальных кадров на границах, таблицы публикации и обслуживающие
ветки генератора. Задачи общего кеша прямого доступа и flush() отменены.
У S[n] := p нет требования бывшего поля: это запись void*, как у массива @. Убрать проверки
этого требования вместе с его таблицами, переносами и ветками генератора. Именованное
S\x := value проверяет требование поля при построении чистого графа там, где оно известно.

## 3. Что означает публикация после этого решения

Публикация Message и выдача результата построения сохраняют собственные контракты.
Они не являются обратной записью локальных кадров. Обычные локальные значения, GC,
типизированное хранение, карты фактического копирования и общий допуск не удаляются лишь
из-за того, что раньше участвовали в реализации dirty.

## 4. Где выполнять проверку

Построение и проверка чистого графа реализуются в сборщике и оптимизируются под реальные задачи.
Нужные части переносятся в runtime при конкретной потребности с использованием общего кода.
[Группа sys](../../next_core_tasks_v3.md#graph-tools) даёт явные проверки и translate:
translate возвращает текст L1 и ошибки, не LMX. Никакой отдельной инфраструктуры,
универсальных обёрток или дополнительных состояний «на будущее».
