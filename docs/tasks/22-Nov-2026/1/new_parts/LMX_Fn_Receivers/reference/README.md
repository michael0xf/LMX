# Справочные материалы перенесённого пакета

Эти материалы сохраняют происхождение исходного архива 2026-11-21. Написания
`satisfies` и `Name :: DATA`, терминология сигнатур и правило аргументов
согласованы с текущими решениями. Это не альтернативная версия ядра.
Действующая спецификация находится в [docs](../../../README.md); текущие
интерфейсы набора — [API.md](../API.md) и
[KERNEL_REQUIREMENTS.md](../KERNEL_REQUIREMENTS.md).

## Границы аргументов операнда

Исключение действует только при одновременном выполнении трёх условий: слева написана безымянная Structure; в правой последовательности ровно один аргумент; этот аргумент сам является написанной безымянной Structure. Снимается только её внешний правый контейнер, ровно на один уровень. Левый left остаётся одной целой Structure. Вложенные правые контейнеры повторно не открываются; ссылка на структуру, значение массива и возвращённая функцией Structure сами по себе не раскрываются. P0 не снимает никаких контейнеров. Обычные callable W/E сохраняют отдельный действующий контракт.

`Name :: A B` содержит два правых аргумента, а `Name :: (A B)` — одну правую
Structure. Слева находится атом объявляемого имени, поэтому исключение здесь
не срабатывает. `::` использует обычный `OPERANDS_TEMPLATE` и общий режим
сохранения форм; отдельного синтаксического разделителя не вводится.

`(a b c) := (b c a)` и `(a b c) := (copy(s))` передают непосредственные правые
поля по этому правилу. `(a b c) := f()` не открывает возвращённую Structure.
Чтение RHS и проверка числа значений предшествуют первой записи.

## Происхождение и реализация

В `newdocs/implementation-notes.en.md` сохранены явно датированные исторические
receipts. Упоминания прежнего дефекта P0 и отменённых executable-форм описывают
состояние старых проверок, а не разрешают их использовать в текущем ядре.
Общие правила вызова, data/code и именованных сигнатур следует читать вместе с
действующими уточнениями родительского `docs`.

[OPERANDS_TEMPLATE.md](OPERANDS_TEMPLATE.md) фиксирует общий шаблон исходного
пакета. Имя `OPERANDS_TEMPLATE` во множественном числе — точное имя источника;
пользовательское «OPERAND_TEMPLATE» обозначало тот же приём. Мосты к анализу
сигнатуры и построению callable остаются общими, а не отдельными алгоритмами
для curry/partial. Проверки времени жизни typed records и реального parent
не заменяются текстовой проверкой публикации.
