# Индекс: целочисленный операнд, native L2 и checked-исполнение

Codex, 2026-11-24. Принят индексный компонент: checked и native-части проверены вместе в описанном ниже домене.
G1/G2 и проверка устойчивости результата пройдены. Полный набор выполнен, в нём остались открытые отказы.

## Состав

В рабочее дерево перенесены 18 путей: 13 изменённых исходников/тестов, два новых теста и три контроля.
Манифест содержит 1680 файлов; проверка рабочего дерева дала 0 отказов.
Неизменная часть прежнего манифеста содержит 1664 файла и тоже проверена.

SHA-256 манифеста:

`b3cea006c84ad6dfc1173ec6454d3472b7e8b4b057a40405a75e0443107a0c90`

Главные изменения:

- Знак и модуль индекса извлекаются из одного вычисленного Value. Приёма индекса в size_t нет.
- INT_MIN не отрицается в signed-типе; char использует знак настоящего C char; unsigned сохраняет верхний диапазон.
- FOREIGN хранит своё значение и SOURCE. Физический callback не меняет SOURCE и не разрешает операцию сам по себе.
- Checked-проекция читает integer у точного SOURCE: профильной строки, полной сохранённой записи или C-контракта.
- Boolean/i8/int8 делят физический int8_t ABI; integer=0 у Boolean остаётся самостоятельным условием допуска.
- Физическая группа _Bool получает callback; LMX bool/_Bool с integer=0 не становятся целочисленными SOURCE.
- Статический raw C операнд сохраняет C-тип. Целочисленную категорию проверяет сама C-операция до cast к модулю.
- Обычный native L2 читает, пишет и адресует уже выбранный элемент без checked load/store.
- C-указатель сохраняется до эффектов индекса, место — до RHS. Чтение, запись и @ используют один способ подготовки.
- Array с известным элементом получает типизированный C-адрес. У числовых dense cells нет лишнего pointer context.
- Free-значения используют имеющееся физическое описание Array/указателя и сохраняют нужные контексты и roots.
- Checked Array отказывает по negative или magnitude >= length до адресации.
- Checked pointer проверяет представимость magnitude * stride до сужения и выбирает настоящий знак смещения.
- Graph native использует raw reference-slot операции только при доказанном контексте Structure.
- FIELD_ADDRESSES сохраняет одну косвенность. Native-вход не вызывает index_node для повторного допуска holder.
- Неизвестный Graph-контекст использует существующий отбор целого вызываемого к walker до исполнения тела.

## Адресные результаты

Итоговый список final29: 29 строк, 0 отказов. Его 171 PASS — это:

- 51 сборка;
- 102 исполнения;
- 18 проверок ожидаемого отказа.

Это не 171 маршрут исполнения. В список входят индексные проверки и связанные числовые регрессии.
Машинная ядерная строка включена в эти числа; отдельное раннее выполнение не добавляется к итогу.

Новые свидетельства:

- index_integer_value: полный signed MIN, unsigned верхнего диапазона, NONE со знаком, char/uchar;
  SOURCE Boolean/i8 и bool/_Bool/c._Bool, полные SOURCE с integer 0/1 и текстом "1";
  capture/receive/materialize/load сохраняют SOURCE; checked Array и pointer offset отказывают до адресации;
  статические профильные и C-целые индексы, типизированные p+n, p-n и n+p на корректном storage.
- index_checked_access запускается только forced. Порождённый текст оставляет native entry только R0;
  пять пользовательских методов переносимы. Отрицательный/большой индекс и не-reference проверяются внутри них.
- index_numeric_receive/unavailable сохраняют expected 7. Приём int -> size_t не вызывается индексированием;
  отрицательные смещения используют середину живого массива, RHS считается один раз.
- free_index_places содержит корректные native-доступы; намеренно неверные случаи вынесены в forced-свидетельство.

Graph-повтор: семь исходных программ, interp/native/forced, 21 из 21 PASS.
Проверяются замена фрагмента, локальная запись вызывающего, native L2 путь, цепочка alias,
RHS один раз, alias после переприсваивания и alias после вызова.
Ожидаемые данные не переписывались.

Исправления, найденные действительными запусками, включают типизированный pointer-offset resolver,
инициализацию callback при объявлении, правильный L1 lvalue через именованный указатель,
общую подготовку места для C-указателя и ошибочно оставленную пустую строку в теле теста.
Диагностика временно включалась только в частных производных C-файлах; в поддерживаемых исходниках её нет.

Исправление единого собственного места — следующая зависимость M14; допуск модели и разыменование не ослаблялись.

Повтор LEVEL-PINS новым Graph01: оба emit успешны; 11 счётчиков stores, kind и own_kind совпали с pins.
Native entries четырёх context-строк соответствуют прежнему отбору целого callable.
Пример emit_double_known отвечает 2, host process выходит 1: это прежний OPEN 21.25, не успешное исполнение.

## Открытые границы

- Это не готовность всего шага 21.25, M13, M14, W1–W5 или всего native L2 без проверок.
- Полный extent-контракт произвольного внешнего pointer остаётся M13: проверка произведения не доказывает object bounds.
- Не выполнялись огромные pointer-смещения, прошедшие проверку произведения:
  такие C-обращения не являются пробой отказа.
- Линеаризация многомерного индекса и её математическое переполнение не закрыты финальной проверкой одного индекса.
- Generic actual -> place, неизвестные C pointee, descriptor+index и весь flat descriptor остаются открыты.
- Машинный source shape для typed Array ограничен прежним collector/ABI; ordinary native Array проверен отдельно.
- Graph dense Array не выдаётся за void* slots. Его отдельный native lowering остаётся открытым.
- Все FOREIGN-операторы и преобразования в произвольные FOREIGN-числа не объявлены готовыми этим accessor.
- Стандартный C99 каталог не означает поддержку расширенных C integer типов шире unsigned long long.
- 32-битный ABI и штатная команда bootstrap не проверены этим свидетельством.
- Открытые 18 программ полного набора перечислены выше; это свидетельство их приёмки не даёт.
