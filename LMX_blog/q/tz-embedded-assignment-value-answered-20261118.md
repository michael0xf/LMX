# Встроенное присваивание без скобок: значение v; значение или ошибка

Дата: 2026-11-18. Задавал исполнитель (сессия fable_pc). Статус: **закрыт ответом автора 2026-11-18**.

Источники: сообщение автора и файл ТЗ, [журнал](../2026-11-18.md#tz-operands-arguments-priorities);
[ТЗ](../../docs/TZ/to_fable_operands_arguments_priorities.md).

## Запись

```lmx
f(1 + v := 2 + 3)
```

Первый формал `f` называется `x`; `v` — другое поле её `data`.

## Что расходится

Сообщение автора, пункт 2: «тут сначала делает v:=2 для data "f" а потом f(6)».

ТЗ, §4.2, §4.5 и проверка D09: в data `f` записывается `v` = 5, аргумент один и равен 6; значение `v` = 2 названо там
результатом прежнего высокого приоритета присваивания.

Аргумент в обоих чтениях равен 6. Различается значение `v` в data `f` после вызова: 5 или 2.

## Что взял исполнитель

Значение ТЗ, `v` = 5. Оно следует из пункта 1 того же сообщения — приоритеты как в Си, у присваивания низший: правая
часть присваивания — `2 + 3`. Значение `v` = 2 даёт запись с явной группой, `f(1 + (v := 2) + 3)`.

Если верно `v` = 2, меняются примеры раздела книги о выражениях, таблица грамматики и проверки D09–D11, P12, P14 ТЗ.

## Связанный вопрос: значение или ошибка

Запись: `(1 + v := 2 + 2) * (v + 1)`.

Слова автора, [журнал](../2026-11-18.md#result-equals-c): «да, теперь результат равен Си», затем «а нет в Си
этовообще ошибка».

ТЗ, §6.3: ресивер присваивания связан с написанным `v`; нельзя пересобрать его левую часть в `1 + v` и выдать
ошибку «присваивание сумме», ссылаясь на грамматику Си.

Два чтения:

- по ТЗ: запись исполняется, результат 25, `v` = 4; то же даёт запись со скобками
  `(1 + (v := 2 + 2)) * (v + 1)`, допустимая и в Си;
- как в Си: запись без скобок вокруг присваивания — ошибка; значение даёт только запись со скобками.

Что взял исполнитель: чтение ТЗ. Если верно второе, меняются раздел книги о выражениях, таблица примеров, §21
грамматики и проверки D09–D11, D13, P12, P14 ТЗ, а первый вопрос этого файла отпадает.

## Ответ автора

[Журнал](../2026-11-18.md#all-by-the-document):

> нет в LMX это не ошибка -- все по документу, включая вызов v := по требованию

## Что из ответа следует

Редакторское пояснение исполнителя, не слова автора.

- Запись без скобок вокруг присваивания в LMX не ошибка: `(1 + v := 2 + 2) * (v + 1)` даёт 25, и `v` равно 4.
- Действует ТЗ: присваивание исполняется по требованию потребителя, его правая часть — всё выражение справа.
  `f(1 + v := 2 + 3)` записывает в data `f` значение `v` = 5 и подаёт один аргумент 6.
- Норма, записанная до ответа, не меняется.
