## Изменение

Построитель создаёт именованные структуры данных и fn с явными Lmx-частями args, return, var, body. Формал int без
значения использует прежний uninit:int → T; формал модели — обычную Lmx [требование, имя]. P0 освобождается после
построения; разрешённых привязок построитель не сохраняет. Известный неподдержанный ресивер с end не превращается в
неисполняемую структуру данных.

Общий приём сначала проверяет число аргументов и обязательные места, затем принимает вычисленные аргументы по порядку.
Для структуры сравнивает использованные пути из тела с моделью и кандидатом по каноническим адресам имён и типам
адресов. Неиспользованные поля модели не требуются, порядок полей кандидата значения не имеет. Int-значения копируются
в аргументные места; умолчание также получает отдельное место. Таблицы/очередь проверки и refs принадлежат вызову,
сигнатура не переписывается. Общая LmxActivation используется обоими исполнителями и снимается при возврате.

Native метода содержит скомпилированные арифметические операции и читает формалы из refs; это не wrapper обходчика.
При отсутствии native тот же вызов читает текущее тело из графа. Изменение данных сохраняет вход метода; изменение
тела или написанного требования снимает его перед публикацией записи. Отдельного постоянного индекса зависимостей нет.
