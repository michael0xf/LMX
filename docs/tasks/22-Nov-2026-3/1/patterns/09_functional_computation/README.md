# Функциональные вычисления

Haskell даёт естественный контроль для Maybe/Monad и каррирования. Scala сочетает функциональные приёмы с JVM, явным батутом и обычным управлением ресурсами. Эти языки выбраны за подходящие механизмы, а не для универсального рейтинга краткости.

В архиве одно текущее ядро LMX. Его операции вызываются напрямую; переключаемые редакции Maybe/Curry/Bounce не предлагаются. Основным выбран короткий корректный вариант прикладного сценария с полной оплатой его собственного кода. Готовые общие компоненты доступны во всех трёх языках; implementation-строки показывают их настоящие тела и сохраняют общий контракт. Клиент 084 вправе вместо общего bracket использовать локальный Around: все три callbacks и наблюдения сохранены, а helper целиком включён в его размер. Общий bracket остаётся действующей альтернативой с реализацией 098. Прежние публикации сохранены рядом без повторного подсчёта; пометка исторического исходника не означает, что каждая его конструкция запрещена текущим языком.

`patterns.json` хранит допустимые текущие реализации в `variants` и `eligible_variants`, выбор в `primary_variant`, исторический исходник в `alternative`, основной текст в `listings[].code`. Строки реализаций сохраняют полный общий контракт. Для прикладного сценария допустим локальный helper с нужными этому сценарию типами, когда всё его тело включено в клиентский размер: так устроен текущий вариант 084. Он не выбирает старую редакцию ядра, а общий bracket остаётся действующей альтернативой. Исходный сохранённый клиент хранится без изменений в `alternative.LMX.code` и `procedural_lmx`. Для 083 `alternative.LMX.context_prefix` добавляет точные Bounce и BounceRunner из сохранённого 092. Для 084 `alternative.LMX.context_prefix` добавляет перед ним точное тело Around из сохранённого 098: показанный вариант и его отдельный размер включают оба фрагмента. В основные метрики входит только основной текущий листинг. Текущие исходники находятся в `examples/<language>/`; в `.lm3` исторический LMX дополнительно закомментирован рядом. Это не переключаемые версии библиотеки. Для воспроизведения: sync_receiver_bodies.py → select_shortest.py → regenerate_publication.py → check_publication.py. PDF/XLSX используют те же итоговые данные.
