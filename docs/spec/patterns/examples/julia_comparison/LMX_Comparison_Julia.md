# Сводное сравнение LMX / Julia

Все числа — непробельные Unicode-символы. Дополнительный счёт оставляет заголовок и первый аргумент Throws; copy(Throws) сохраняется целиком. Полные исходники не меняются. Явный Throws — видимый точный контракт отказов.

| Слой | LMX полный | LMX без сложного Throws | Julia полный | Julia без сложного Throws |

| Клиенты | 3259 | 2721 | 1244 | 1244 |
| Основные реализации JI01–JI04 | 14554 | 14107 | 8131 | 8131 |
| Общие LMX-тела вне JI-листингов | 4285 | 3270 | — | — |
| Все уникальные LMX-тела реализаций | 18839 | 17377 | — | — |

Уникальная сумма реализаций не прибавляется повторно к компонентам. Границы runtime и общие зависимости описаны в [README](README.md).
