# P03. Сумма с нейтральным значением

## Общий наблюдаемый договор

Сумма конечного списка целых чисел; пустой список даёт 0. Примеры не выходят за диапазон машинного int LMX.

Обе формы сохраняют один наблюдаемый договор; процедурная запись показывает управление и изменение данных, функциональная использует общие операции ядра.

Общий Expression принимает поток полей copy(items); начальный 0 сохраняет результат пустого входа. Отдельные Add/foldl и новая фасадная функция для этого сценария не нужны.

## Вход и ожидаемое наблюдение

```json
{
  "arguments": [
    [
      7,
      -2,
      0,
      4
    ]
  ],
  "result": 9
}
```

## Размер полных клиентов

| Полный исходник | Непробельные символы | Все Unicode-символы | Непустые строки |
| --- | ---: | ---: | ---: |
| LMX процедурный | 101 | 193 | 10 |
| LMX функциональный | 55 | 85 | 5 |
| Perl | 90 | 115 | 7 |

Обе LMX-формы опубликованы и считаются независимо. Все определения, обработчики и ссылки на throws входят в полный размер. Выбор единственного LMX-варианта по длине не выполняется.

## LMX — процедурный

```lmx
Example:
    int[]: items
    return: int
    run:
        int: total 0
        int: i 0
        while: i < length(items)
            total += items[i]
            i += 1
        return: total
```

[Полный исходник](source/lmx/procedural/P03.lm3). 101 непробельных символов; 10 непустых строк. Все объявления и Throws включены.

## LMX — функциональный

```lmx
Example:
    int[]: items
    return: int
    run:
        return: (+ 0 copy(items))
```

[Полный исходник](source/lmx/P03.lm3). 55 непробельных символов; 5 непустых строк. Все объявления и Throws включены.

## Perl

[Полный исходник](source/perl/P03.pl).

```perl
use strict;
use warnings;
use List::Util qw(sum0);
sub example {
    my ($items) = @_;
    return sum0(@$items);
}
```

## Общие библиотечные реализации

Используются базовые операции языка; предметные определения приведены целиком.

Тела библиотечного ядра сохранены в одном общем источнике и не размножаются для двух стилей. Иностранный клиент использует свои настоящие средства; соседние comparison-реализации он не импортирует.

## Проверка
