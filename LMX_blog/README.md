# Технический журнал LMX

Здесь сохранены дословные технические уточнения автора, совместимые с текущей документацией.
При сверке 2026-11-15 удалены отменённые цитаты и устаревшие выводы исполнителей;
опустевшие записи до 2026-11-09 удалены целиком. Оставшиеся выдержки не переписывались под новую норму.

Действующие правила — [семантика](../docs/spec/LMX_semantics.ru.md), [грамматика](../docs/spec/LMX_grammar.ru.md),
[L2](../docs/spec/L2_spec_ru.md), [спецификация ядра](../docs/spec/kernel-implementation.ru.md).
Задачи и готовность реализации — [план v3](../next_core_tasks_v3.md).
[Открытые вопросы](q/current/README.md) отделены от закрытых обсуждений в `q/`.

История до этой чистки доступна в [зафиксированной версии журнала](https://github.com/michael0xf/LMX/tree/495e8435ede179ed6e6dd1c4a95d4f7445718317/LMX_blog).
Прежний журнал до 2026-10-14 — в [архивном коммите](https://github.com/michael0xf/LMX/tree/0a764078/LMX_blog).
