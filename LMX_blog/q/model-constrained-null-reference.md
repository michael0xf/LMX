# Ссылка, ограниченная моделью и изначально пустая

Статус: ЗАКРЫТ, 2026-10-10, ответом автора. Вопрос поставил Codex при переходе ссылок на Structure к записи
«сначала место назначения» (K03-S5-MIGRATION-20261007-06 и дополнение к нему); файл записал Opus.
Утверждённое присваивание `b: A` / `@: b A` и копирование этим вопросом не пересматриваются.

## Ответ автора

Реплика автора в чате Codex 2026-10-10, передана Codex в `CODEX-FABLE-Q-CURRENT-20261010-1940`
как дословная техническая реплика (в журнале автора —
[2026-10-10](../2026-10-10.md#three-questions-20261010)):

> @: Model box 0

## Что из этого следует

Явная запись пустой ссылки с требованием модели — тип, имя, явный `0`: `@: Model box 0`. Это не
чтение «@: box Model» (связывание существующей `Model`) и не снятие требования. Транслятор на
a946e2d9 переводит и `@: Model box 0`, и `@: Model box` без значения (проба трансляции fable_pc,
2026-10-10, без исполнения); ответ не требует переписи 296 строк `steps/k03-typed-reference-census.tsv`
— записи «тип, имя» остаются; явная форма с `0` внесена в таблицу форм ссылок книги
([ссылки](../../docs/LMX_semantics.ru.md#fields)).

Ниже — вопрос в том виде, в каком он был открыт.

## Вопрос

Формулировка Codex (дословно): «how to express a reference constrained by ordinary Model but
initially null under the adopted destination-first Structure reference contract».

Как записать ссылку, допускающую только обычную `Model`, но изначально пустую (null), если ссылка на
Structure записывается «сначала место назначения»?

```text
Model: (int: v 11)
fn: empty () int
    @: Model box
    if: box = 0
        return: 7
    return: box\v
end: empty
sendMessage: exit(exit_code: empty(); stdout: ""; stderr: "")
return
```

Сейчас `@: Model box` без значения даёт присутствующий пустой указатель с моделью `Model`: `empty()`
возвращает 7. Если переписать строку как `@: box Model`, по документам это ссылка на существующую
`Model`, и `empty()` вернула бы 11.

## Почему это вопрос, а не вывод

- `docs/LMX_semantics.en.md:666` и таблица `:832-838`: «For absent b, b: A and @: b A are equivalent
  assignment forms introducing b»; `@: b A` — явное присваивание ссылки; `@: p` — ссылка без
  структурного требования (void), изначально 0; `@: int p`, `@@: int pp` — объявления указателей на
  примитив. То же — `docs/L2_spec_en.md:206`.
- `L2_L3_CODING_INSTRUCTION.md:297` (§5.5): «An omitted reference initializer produces the typed null
  value.»
- Тип первым в записи стоит только у объявлений указателя на примитив и в неисполняемых сигнатурах
  (`(A: b)`, `(@: A b)`, `docs/LMX_semantics.en.md:709-716`); отдельной альтернативы «тип первым» для
  обычной Structure в исполняемом теле документы не дают (Codex).
- Ни одна из документированных записей не даёт одновременно требование `Model` и пустое начальное
  значение: `@: box Model` связывает `Model`, `@: box` снимает требование. Codex запретил
  изобретать синтаксис, молча снимать требование модели, связывать `Model` вместо null и
  инициализировать `Model` с последующей очисткой.

## Что транслятор делает сейчас (измерено 2026-10-07 на `5f7826b5`, не норма)

Пример выше и три его варианта, нативно и с `--walk-methods`, одинаково:

| Строка 3 | Результат |
| --- | --- |
| `@: Model box` | переводится, `empty()` = 7 (пустой указатель с моделью) |
| `@: box Model` | отказ `3:8: unknown type` — `box` прочитано как тип |
| `box: Model` | `box` — определение Structure с телом `Model`, не ссылка; отказ `6:17: unresolved name` у `box\v` |
| `@: box` | отказ `3:5: unsupported body` — ссылка без модели не реализована |

Фикстура с тем же намерением: `dev/l2src_sandbox/tests/unit_free_path_null.lm2:26`
(`fn: empty`, `@: Model box`); связанная история — `steps/defects.md`, OWN-REFERENCE-CANDIDATE-LOSS.

## Что зависит от ответа

Перепись всех объявлений `@...: T name [значение]`, где `T` — Structure фикстуры (или
`MainLetter`/`LongLetter`): `steps/k03-typed-reference-census.tsv`, 296 строк в 150 фикстурах.
Классы измерены отдельно, чтобы ответ применялся точно:

- `@: T name` без значения (пустая ссылка с моделью) — 76 строк: корень 26, метод 41, тело
  именованной Structure 8 (поля-ссылки), блок 1. Среди них 23 корневых `@: MainLetter m` —
  место приёма письма.
- `@: T name значение` — 205 строк (метод 164, корень 30, блок 11).
- Хвост длиннее одного значения — 12 строк (строки отказа «одно значение» и составные значения).
- Глубина 2, `@@: T name значение` — 3 строки.

Пока ответа нет, эти записи не переписываются и не переклассифицируются. Независимая часть
работы идёт дальше: `b: A` для отсутствующего `b` как привязка ссылки, перевод `Model: m` в
`m: merge: Model` там, где намерение — новый экземпляр, и полей-ссылок `Inner: box` в `box: Inner`.
Объявления указателей на примитив, сигнатуры и записи «сначала место назначения» (`@: h f(a)`) к
этому вопросу не относятся.
