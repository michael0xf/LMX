Python показывает компактные функции, dataclass и явные адаптеры; C# — records, интерфейсы и привычную организацию прикладного доступа к данным. LMX сопоставляется с обоими без обязательной иерархии классов.

19 исходных паттернов 16–34 сохранены отдельно. Листинги показывают одинаковую ограниченную задачу. Внешние БД и коллекции с методами, не заданными языком, перечислены как порты: их цена не считается нулевой. Транзакция БД отличается от последовательного turn Message. HTTP-профиль LMX существует; он доставляет запрос к прикладной границе и не создаёт автоматических гарантий хранения. Все листинги авторские; источники использованы для определения паттерна. LMX-фикстура заранее помещает зависимости и начальное состояние в фактический DATA владельца; входы с потенциальной неоднозначностью позиции передаются явно по имени. Например, account\debit(amount := 30). Листинги контролей рассчитаны на Python 3.10+, C# 12, Java 17 и Go 1.18+ там, где соответствующий язык присутствует.

Считаются все непробельные Unicode-символы полного показанного листинга, включая объявления, локальные вспомогательные методы, комментарии и Throws. Списки ошибок копируются из вызываемых методов там, где это сохраняет контракт; текст copy и всех дополнительных отказов входит в размер. Зелёным подчёркивается минимальное число в сопоставимой строке; при равенстве — все победители.

LMX parser/runtime: NOT_RUN для изменённых листингов. Проверки исходников и публикации не являются исполнением языка. Размер кода не измеряет скорость или расход памяти.

Одинаковые числовые данные используются в Markdown, PDF и XLSX. Машинный источник — PUBLICATION_DATA.json в корне каталога patterns; генератор — tools/build_publication_data.py.
