# Первая часть implements: листовое поле модели против поля значения другого вида

Дата: 2026-11-18. Задаёт исполнитель (сессия fable_pc). Статус: **открыт**. Автор велел случаи, когда первой части
`implements` не хватает, обсуждать с ним ([журнал](../../2026-11-18.md#both-readings-checked)).

## Программа

```lmx
fn: h (int: x) int
    return: x
@: One (int: x 9)
seen := h(One)
```

Норма, [книга](../../../docs/LMX_semantics.ru.md#declaration-selection): место `int` не допускает Structure, вызов
отказывает. Подходит ли вызов объявлению, решает первая часть общего `implements`, которая сверяет поля; пара
сверяется так: модель — данные `h`, то есть `(int: x)`, значение — аргументы, присвоенные формалам, то есть
`(x := One)` ([ответы исполнителя, Р80](../fable-self-answers-20261110.md)).

## Что есть в коде

Опись вспомогательной сессии opus, пробы на принятом инструменте
(`receipts/opus/one-graph/declaration-selection/Q4-LIBRARY-LEAF.txt`):

- первая часть библиотеки `lmx_implements`, вызванная через читатель чистого графа, отказывает только по карте
  полей: если у значения нет поля модели;
- на листовое поле она отказа не даёт. `int` против ссылки на Structure — не отказ; `int` против `char` — не отказ;
  ссылка на `X` против ссылки на `Y` с другой моделью — не отказ;
- причина: читатель графа на ссылочное поле отвечает «неизвестно», а «неизвестно» в библиотеке — не запрет; в
  заметках самой библиотеки сказано, что значения примитивов в первой части не участвуют, а преобразования открыты.

Значит, сегодня пара `(int: x)` против `(x := One)` первой частью допускается, и `h(One)` по одной только серии
`implements` не отказал бы.

## Что предлагает исполнитель

Слова автора 2026-11-18 ([журнал](../../2026-11-18.md#standard-implements-only)): указатель void удовлетворяет любая
структура ещё на этапе сверки полей; у `implements` есть таблица преобразований. По ним первая часть при сверке
полей сравнивает и листовое поле:

- тип поля значения равен типу поля модели — да;
- типы разные, а в таблице преобразований есть переход — да;
- перехода нет — нет: `int` против Structure, ссылка на `X` против ссылки на `Y`;
- поле модели — указатель void — да для любой Structure.

Таблица преобразований уже записана на LMX (`convert.lm2`). Отдельной проверки вида значения в связывателе тогда
не остаётся.

## Наблюдаемая разница

`h(One)`: отказ 4 от первой части — либо отказа серии нет, и вызов отвергает отдельная проверка вида значения, как
сегодня (`lmx_graph_admit_field`), то есть «собственное» подмножество графа, которое автор велел снять.

`fn: g (int: x) int` и `g(c)` при `char: c 65`: допускается, если в таблице есть переход `char` → `int`.

## Масштаб

Шаг «серия = библиотека» среза выбора объявления; строки допуска базы; любая неоднозначность, где у второго
кандидата формал-примитив.
