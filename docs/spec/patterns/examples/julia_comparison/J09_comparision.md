# J09. Общий дефицит по сопоставленным позициям склада

## Общий наблюдаемый договор

Попарно сопоставить требуемое и доступное количество до конца более короткого входа. Излишки одной позиции не компенсируют дефицит другой: сложить max(required-available,0) для сопоставленных позиций. Пустой любой вход даёт 0; входы сохраняются, переполнение исключено.

Обе полные реализации выполняют один новый прикладной сценарий: процедурная задаёт алгоритм явно, функциональная использует общие операции ядра. Изменённые тексты требуют нового P0-прогона.

Сценарий расширен по замечанию автора: показана обработка данных и полезный итог, а не только вызов одной функции. ## LMX — процедурный

```lmx
Example:
    int[]: left
    int[]: right
    return: int
    run:
        int: total 0
        int: i 0
        while: i < length(left) && i < length(right)
            int: gap left[i] - right[i]
            if: gap > 0
                total += gap
            i += 1
        return: total
```

[Полный исходник](source/lmx/procedural/J09.lm3). 153 непробельных символов; 13 непустых строк. Все объявления и Throws включены.

## LMX — функциональный

```lmx
Shortage:
    int: required
    int: available
    return: int
    value:
        int: gap required - available
        if: gap > 0
            return: gap
        return: 0

Example:
    int[]: left
    int[]: right
    return: int
    run:
        throws: copy(zipWith\throws) copy(sum\throws)
        return: \sum(zipWith(left; right; Shortage\value))
```

[Полный исходник](source/lmx/J09.lm3). 234 непробельных символов; 16 непустых строк. Все объявления и Throws включены.

## Julia

[Полный исходник](source/julia/J09.jl).

```julia
function example(left, right)
    shortages = [max(required - available, 0) for (required, available) in zip(left, right)]
    sum(shortages)
end
```
