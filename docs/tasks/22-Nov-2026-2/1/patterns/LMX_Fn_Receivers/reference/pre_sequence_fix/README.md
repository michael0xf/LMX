# Прежние алгоритмы текущего загруженного комплекта

Сохранены тела выбора полей и списков, заменённые универсальными делегатами. Это пояснительные варианты исходного алгоритма; они не подключаются вместе с текущей сборкой и не объявляют другую версию ядра.

Исторические алгоритмы сохранены, а типовая запись в `.lmx` приведена к текущей постфиксной норме `T[]` и `Model@: name`. Точные прежние байты находятся в исходном загруженном архиве; синтаксическая миграция не меняет алгоритмы и не приписывает им возможности текущей реализации.

- [Выбор структурных полей](structures_selection.lmx).
- [Списки](containers_list.lmx).

Текущие реализации и типизированный доступ находятся в [разделе последовательностей](../../SEQUENCES_IMPLEMENTATION.md).
