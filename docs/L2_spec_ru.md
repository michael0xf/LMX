# Спецификация L2

L2 — LMX со специальными операциями низкого уровня. Настоящая спецификация описывает эти операции и их семантику. Семантика чистого герметичного LMX (L3) определена в [основной спецификации](LMX_semantics.ru.md), общая грамматика — в [спецификации грамматики LMX](LMX_grammar.ru.md).

Точное устройство реализации ядра, включая представление данных, размещение в памяти, доступ из потоков и выполнение операций через L1 и C99, определяется [спецификацией L1](L1_spec_ru.md). Семантика операций L2 и соответствующие правила реализации L1 совместно определяют поведение ядра.
