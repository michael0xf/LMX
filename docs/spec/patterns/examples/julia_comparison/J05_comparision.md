# J05. Квадраты через comprehension

## Общий наблюдаемый договор

Вычислить квадрат каждого целого слева направо. Значения выбраны без переполнения, исходный массив сохраняется.

Обе формы сохраняют один наблюдаемый договор; процедурная запись показывает управление и изменение данных, функциональная использует общие операции ядра.

Чистое поэлементное умножение — уже существующее Expression. Оно даёт новый плотный int[]; результат сравнивается по значениям. Отдельный callback Square не требуется.

## Вход и ожидаемое наблюдение

```json
{
  "arguments": {
    "xs": [
      -3,
      0,
      4
    ]
  },
  "result": [
    9,
    0,
    16
  ]
}
```

## Размер полных клиентов

| Полный исходник | Непробельные символы | Все Unicode-символы | Непустые строки |
| --- | ---: | ---: | ---: |
| LMX процедурный | 152 | 266 | 12 |
| LMX функциональный | 40 | 70 | 5 |
| Julia | 25 | 34 | 1 |

Обе LMX-формы опубликованы и считаются независимо. Все определения, обработчики и ссылки на throws входят в полный размер. Выбор единственного LMX-варианта по длине не выполняется.

## LMX — процедурный

```lmx
Example:
    int[]: xs
    return: @
    run:
        throws: copy(sys\resize\throws)
        int[]: out []
        sys\resize(out; length(xs))
        int: i 0
        while: i < length(xs)
            out[i] := xs[i] * xs[i]
            i += 1
        return: out
```

[Полный исходник](source/lmx/procedural/J05.lm3). 152 непробельных символов; 12 непустых строк. Все объявления и Throws включены.

## LMX — функциональный

```lmx
Example:
    int[]: xs
    return: @
    run:
        return: xs * xs
```

[Полный исходник](source/lmx/J05.lm3). 40 непробельных символов; 5 непустых строк. Все объявления и Throws включены.

## Julia

[Полный исходник](source/julia/J05.jl).

```julia
example(xs) = [x * x for x in xs]
```

## Общие библиотечные реализации

Используются базовые операции языка; предметные определения приведены целиком.

Тела библиотечного ядра сохранены в одном общем источнике и не размножаются для двух стилей. Иностранный клиент использует свои настоящие средства; соседние comparison-реализации он не импортирует.

## Проверка

LMX и Julia: **NOT_RUN** в этой сборке. Проверяются обе LMX-формы как текст и общий независимый oracle; это не языковое исполнение.
