# J13. Сигнал только после двух превышений подряд

## Общий наблюдаемый договор

Одиночный выброс датчика не включает тревогу. Вернуть истину при первой паре соседних значений, оба строго выше limit. При длине меньше двух ответ ложный; после первого успеха дальнейшие пары не проверяются. xs и limit доступны predicate через действующее динамическое связывание LMX.

Обе полные реализации выполняют один новый прикладной сценарий: процедурная задаёт алгоритм явно, функциональная использует общие операции ядра. Изменённые тексты требуют нового P0-прогона.

Сценарий расширен по замечанию автора: показана обработка данных и полезный итог, а не только вызов одной функции. | Полный исходник | Непробельные символы | Все Unicode-символы | Непустые строки |
| --- | ---: | ---: | ---: |
| LMX процедурный | 112 | 224 | 11 |
| LMX функциональный | 212 | 297 | 12 |
| Julia | <span style="color:#176233"><u>94</u></span> | 119 | 4 |

Обе LMX-формы опубликованы и считаются независимо. Все определения, обработчики и ссылки на throws входят в полный размер. Выбор единственного LMX-варианта по длине не выполняется.

## LMX — процедурный

```lmx
Example:
    []int: xs
    int: limit
    return: int
    run:
        int: i 1
        while: i < length(xs)
            if: xs[i - 1] > limit && xs[i] > limit
                return: 1
            i += 1
        return: 0
```

[Полный исходник](source/lmx/procedural/J13.lm3). 112 непробельных символов; 11 непустых строк. Все объявления и Throws включены.

## LMX — функциональный

```lmx
Consecutive:
    int: i
    return: int
    accepts:
        return: xs[i - 1] > limit && xs[i] > limit

Example:
    []int: xs
    int: limit
    return: int
    run:
        throws: copy(FxSeqRange\range\throws) copy(any\throws)
        return: any(range(1; length(xs); 1); Consecutive\accepts)
```

[Полный исходник](source/lmx/J13.lm3). 212 непробельных символов; 12 непустых строк. Все объявления и Throws включены.

## Julia

[Полный исходник](source/julia/J13.jl).

```julia
function example(xs, limit)
    positions = 2:length(xs)
    any(i -> xs[i-1] > limit && xs[i] > limit, positions)
end
```

## Общие библиотечные реализации

- `range`: [полная пара реализации](library_comparisons/JI02_comparision.md)
- `any`: [полная пара реализации](library_comparisons/JI01_comparision.md)

Тела библиотечного ядра сохранены в одном общем источнике и не размножаются для двух стилей. Иностранный клиент использует свои настоящие средства; соседние comparison-реализации он не импортирует.

## Проверка

Изменённые LMX-исходники: parser/P0 **NOT_RUN**; прежний receipt не переносится на новый хэш. LMX и Julia runtime: **NOT_RUN** в этой сборке. Проверяются обе LMX-формы как текст и общий независимый oracle; это не языковое исполнение. Численные размеры пересчитаны по текущим полным исходникам.
