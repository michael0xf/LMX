# Каталог изменений

Ниже перечислены решения, заданные первичными
[package_plan.lmx](package_plan.lmx), [core/inventory.lmx](core/inventory.lmx),
[catalog/schema.lmx](catalog/schema.lmx), [common_models.lmx](types/common_models.lmx)
и [profiles.lmx](new_primitives/profiles.lmx).

| Область | Изменение | Следующая работа в ядре |
|---|---|---|
| Опись LMX | Существующие семантические договоры отделены от старого самосборщика, значений и будущих требований | Публиковать существующие LMX-тела по выбранным путям, сохраняя варианты receiver |
| Опись C | Все текущие компоненты SOURCES сведены в LMX; включены 23 ранее пропущенные библиотеки и новые наборы | Выбирать и проверять рабочий профиль конкретного метода |
| Пакеты | Пути из 1–3 сегментов; большие наборы распределены по имени функции и public header; коллизии видимы | Публиковать выбранные общие определения через явные ссылки |
| Обёртки | CODE содержит конкретный `c.*` внутри L2; unavailable profiles и application hooks не имеют включаемой native-ветки | Привязать реальные lowering-функции и завершить проверки каждого C-договора |
| Общие данные | 38 моделей и 30 договоров преобразования; точное соответствие всем текущим backend | Реализовать нужные конвертеры; проверять точный тип и владельца native resources |
| Примитивы | `bigint`, `decimal`, arbitrary `real`; контексты, квоты и владение явны | Подключить к каноническим [TypeRef](../TYPE_REFERENCES_CHANGE.md), допуску, copy/revert и финализаторам ядра |
| Новые исходники | Очищенные gb/cute/libc, APR/SDL, NetSurf и научные форматы; отдельные профили и альтернативы сохранены | Выбирать реализацию по возможностям и договору; измерять конкретную композицию |
| Проверки | Полный metadata round-trip, независимые API checks, static LMX и C99 fail-closed gates; native reports имеют собственный scope | Выполнить настоящие тесты LMX после интеграции в актуальное ядро |

## Матричный обзор 2026-11-28

[Матричные подключения](matrix/README.ru.md) сопоставляют задачи с конкретными
entry существующей коллекции, общими моделями и CMake targets. Восстановлен
отдельный неизменённый архив `third_party.tar.gz` из 180 компонентов. Проверка
исходников уточнила нетривиальное соответствие transpose/adjoint в liquid,
порядок matrix_div, потерянные статусы solve/inverse, unpivoted LU, пределы
fixed-point и ограничения маленьких/tensor-профилей. Альтернативы CMINPACK QR,
klib symmetric eig и liquid sparse отделены от ещё не реализованных общих
SVD/Schur/complex eig. Bridge-порты и production LMX остаются незавершёнными
там, где нет действительного исполнения.

`Tensor` использует signed element strides; отрицательные представления
не проверяются старым unsigned C-extent helper. Добавлены общая CSR/CSC
модель и проверяемый договор упаковки. IEEE/ARM binary16 и SoftFloat
отделены от Q-форматов; `Quantization.saturate` не обещает saturating
арифметику libfixmatrix.

## Изменения текущего дополнения

**Полнота и идентичности.** Загруженная коллекция содержала 155 компонентов,
но `docs/core_catalog` охватывал 132. Для всех 23 пропусков добавлены primary
LMX tables, c.*-обёртки, пути, общие модели и карточки. Текущая разница с этим
снимком отделяет заполнение старых пропусков от новых native исходников:
[api_census_delta.json](validation/api_census_delta.json).

**Callbacks.** Парсер декларатора теперь понимает calling convention перед
звёздочкой и function typedef со скобками вокруг имени. Старые записи по
ошибочным именам возвращаемых типов, например `void`/`int`, не заражают
обычные аргументы ложными callback-ссылками. 47 неверных identities
сопоставлены 125 настоящим typedef names; все прежние публичные callable IDs
сохранены. Полная [таблица миграции](validation/callback_identity_migration.json)
содержит исходные места и новые IDs.

**Доступность.** В описи остаются все исходные ветви, включая APR skiplist,
PCRE2 16/32-bit, lwIP sockets, SDLTest, внешние GL/EGL prototypes, gb window
backend и optional cute_sound codecs. Их source contracts отличаются от
выбранных реализаций. Force-enable unavailable/application/absent
native gates проверен отдельным C99 executable: 5/5 отказов без линковки
native providers — [profile_gates.json](validation/profile_gates.json).

**Научные данные.** `Hyperslab` и `MpiContext` — обычные LMX Structures;
`scientificSelection` и `mpiResource` объединяют нужные преобразования,
типизацию handles, rank/count/offset и правила коллективных операций.
Самостоятельные numeric primitives для HDF5/MAT/netCDF/MPI не вводятся.
Названия **netCDF-5 / CDF-5**, `nc5`, `64-bit data` и C API aliases сохранены
в [scientific_profiles.lmx](types/scientific_profiles.lmx).

**Общие неизменяемые определения.** `independent: immutable:` объекты, CODE
и immutable DATA используются по ссылке; в арены акторов их копии не
создаются. Изменяемые invocation contexts и native workspaces имеют своих
владельцев. Обычное копирование mutable-графа, explicit resource duplication
и bootstrap со ссылками описаны отдельно в
[архитектуре](ARCHITECTURE.ru.md#5-r0-акторы-и-общие-неизменяемые-определения).

**Размер документации.** Устранён искусственный предел 10 MB для первичного
LMX-каталога: он препятствовал добавлению полного API без изменения модели
runtime. Таблицы по-прежнему объединяют повторяющиеся строки/типовые данные;
огромный промежуточный JSON и тысячи однотипных C-файлов не поставляются.
Каталог не загружается и не копируется каждому актору целиком.

## Сохранённые исправления предыдущего этапа

**MongoDB C driver.** В исходной компактной поставке отсутствовали некоторые
входы CMake. Восстановлены 23 небольших файла из соответствующей upstream
версии; полная реплика не добавлялась. Подробности в
[mongo_build_recovery.json](validation/mongo_build_recovery.json).

**Afan.** Проверка точного upstream-файла не учитывала изменение CRLF в LF.
Адаптер допускает только два проверенных хеша того же текста и сохраняет
существующее исправление размера входного слоя. Произвольное изменение
файла по-прежнему отклоняется. См.
[afan_compat_recovery.json](validation/afan_compat_recovery.json).

**LibBF.** Отдельный build view использует portable 32-bit limbs и
различимые имена внутренних символов, чтобы сосуществовать с LibTomMath.
Regression с нулевой квотой обнаружил непроверенный `bf_resize` в разборе
числа и запись по NULL; проверка отказа добавлена с переходом в существующий
`mem_error`. Оригинальный vendor-файл не переписан.

**LibTomFloat.** Экспериментальная альтернатива сохранена вместе с upstream
WARNING. Две узкие адаптации исправляют `sqrt(0)` и конструктор полного
signed `long`. Декларации `mpf_from_string`/`mpf_to_string`, для которых
в upstream нет реализаций, остаются явно помеченными.

**PCG.** В выбранном C99 build view выключен автоматический 128-bit compiler
extension и исправлен возврат void-выражения. Portable варианты состояний
8/16/32/64 bit остаются. **xxHash.** Новая реализация размещена в отдельном
пространстве C-символов; старая копия LZ4 сохранена и проверена совместно
через отдельные translation units.

**libevent.** Три узкие правки двух заголовков устраняют несовместимые с
strict C99 формы. Адаптер восстанавливает глобальную настройку конфигураций
CMake после включения upstream и исключает дублирующий комбинированный
архив из сборки по умолчанию. Core/extra/pthreads остаются выбранными
целями; legacy target доступен явно.

## Что остаётся руководством

Новые `.lm3` и `.lmx` под `docs/` не проходили исполнение актуальным LMX
runtime. `BridgeLower`, типовые shim-макросы, привязка native handles,
callback quiescence, бюджеты времени и публикация пакетов требуют реальной
интеграции. У каждого шага указан конкретный договор или исходный шаблон.
Работающие C99 reference и их проверки подтверждают отдельные механизмы,
а не автоматически всю защищённую семантику L3.
