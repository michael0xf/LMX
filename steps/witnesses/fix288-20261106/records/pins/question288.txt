Факты кода (selfbuild 6bdc419a):
- Единственная исходная категория «машинный» у транслятора — машинная функция: `lm_compiler_m_machine(i)` (l2_frontend_coords.lm2:1718) истинна только в машинном модуле (`lm_compiler_machine_module`: режим библиотеки, список машинных имён, без construct-имени), для метода корневого уровня этого модуля. У программы-юнита она ложна для всех методов.
- `tests/sha/sha256_vectors.lm2` — юнит (`runs sha/sha256_vectors.lm2 7 n ../tools/sha256.lm2`: машинный модуль — только лишняя часть `tools/sha256.lm2`). Его `run` — обычное тело, графовое снижение (как в срезе 178: int-арифметика там проверяемая). `@: all char c.malloc(256U)` — собственное поле типа `@ char` (базовый указательный тип 12), `int: i`, строка 31 `all[i]: (cast: (char) i)`.
- По вашему п. 1–2 `all[i]` тогда — L3 INDEX над собственным полем: индекс int принимается в size_t обычным приёмом; приёмника `primitive.convert` у программы нет → штатный отказ трансляции (тот самый `the program has no method lm_stg_convert_int_size_t, the receiver of this conversion`, который дал boot149a). То есть «не заставлять машинный тест стать L3» и «нет приёмника → отказ, не unchecked C index» сейчас сходятся на этой строке в противоречие, а отличить её по исходной категории транслятор не умеет.

Варианты, которые я вижу (не выбираю сам, книга :7):
(a) Категория — место, чьё значение дала C-дверь (`c.malloc`): индекс по указателю из внешней памяти — машинный. Статически это провенанс инициализатора, а место можно переприсвоить адресу арены; по-моему, это не категория источника.
(b) Категория — метод: тело с L2-операциями (`cast:`, вызовы `c.*`) — машинный профиль целиком. Книга :797 говорит лишь, что L2-операции не интерпретируются; что все операции такого тела становятся L2, я в норме не нахожу.
(c) Категории нет: `all[i]` — L3 INDEX, фикстура исправляется явным типом индекса (`size_t: i` или явное преобразование), её машинные операции (`c.malloc`, `c.free`, `cast:`) остаются машинными. Это меняет тест под норму, а не тест под реализацию; сам тест не становится L3 целиком.
