# J27. Сдвиг истории на месте и маска неизменившихся позиций

## Общий наблюдаемый договор

Сдвинуть прежнюю историю values на одну позицию вправо без изменения длины, поместить next в первую позицию непустого Array и вернуть отдельную маску равенства нового и прежнего значения каждой позиции. Пустой Array сохраняется и даёт пустую маску. Сам target и его внешняя идентичность сохраняются. Элементы имеют любой допущенный полный тип с чистым скалярным равенством; next совместим с целевыми местами. Маска в общих наблюдениях нормализована к 0/1: LMX даёт int, Julia — Bool.

Один прикладной договор: процедурный вариант задаёт алгоритм циклами, функциональный использует общие выражения и операции. Все объявления и throws входят в размер; обе формы требуют нового P0-прогона.

Здесь разные операции видны рядом: .: присваивает выбранные элементы, := присваивает одно место values[0], .= строит маску равенства. В Julia им соответствуют .=, = и .==. Правая values[:-1] в VALUE получается целиком до записи в пересекающийся левый срез; это исключает порчу следующего старого значения. before сохраняется только для последующего сравнения позиций. Процедурный вариант идёт справа налево и сравнивает каждое старое место перед изменением; дополнительная копия истории ему не нужна. Julia имеет явную защиту пустого входа перед индексированием. Нормализация Bool-маски и запись изменённого target в наблюдение находятся только в test harness, вне сравниваемого клиента. Декорация .op передаёт depth=1 базовой операции; ссылки throws используют её базовое точное имя. Ресиверные имена с добавленной точкой не создаются как алиасы.

## LMX — процедурный

```lmx
Example:
    @: values
    @: next
    return: @
    run:
        throws: copy(sys\resize\throws)
        int: n length(values)
        []int: same []
        sys\resize(same; n)
        int: i n - 1
        while: i > 0
            same[i] := values[i] = values[i - 1]
            values[i] := values[i - 1]
            i -= 1
        if: n > 0
            same[0] := values[0] = next
            values[0] := next
        return: same
```

[Полный исходник](source/lmx/procedural/J27.lm3). 241 непробельных символов; 18 непустых строк. Все объявления и Throws включены.

## LMX — функциональный

```lmx
Example:
    @: values
    @: next
    return: @
    run:
        throws: copy(slice\throws) copy(`:=`\throws) copy(`=`\throws)
        @: before values[:]
        values[1:] .: values[:-1]
        if: length(values) > 0
            values[0] := next
        return: values .= before
```

[Полный исходник](source/lmx/J27.lm3). 187 непробельных символов; 11 непустых строк. Все объявления и Throws включены.

## Julia

[Полный исходник](source/julia/J27.jl).

```julia
function example(values, next)
    before = copy(values)
    if !isempty(values)
        values[2:end] .= values[1:end-1]
        values[1] = next
    end
    values .== before
end
```

## Проверка

Изменённые LMX-исходники: parser/P0 **NOT_RUN**; прежний receipt не переносится на новый хэш. LMX и Julia runtime: **NOT_RUN** в этой сборке. Проверяются обе LMX-формы как текст и общий независимый oracle; это не языковое исполнение. Численные размеры пересчитаны по текущим полным исходникам.
