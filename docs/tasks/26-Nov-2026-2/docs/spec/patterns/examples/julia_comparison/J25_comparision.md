# J25. Калибровка сигнала и отбор по порогу

## Общий наблюдаемый договор

Из одномерного Array xs получить gain*x+bias для каждого отсчёта, затем сохранить значения не ниже limit в исходном порядке. Источник сохраняется; результат — новый внешний Array, включая пустой результат. Полный числовой тип T и его скалярные операции произвольны, при условии что умножение и сложение замкнуты в T, сравнение чистое и входы допускаются выбранным профилем. Никакого ограничения только на int нет; наблюдения выполняются без арифметического переполнения и нехватки ресурсов.

Один прикладной договор: процедурный вариант задаёт алгоритм циклами, функциональный использует общие выражения и операции. Все объявления и throws входят в размер; обе формы требуют нового P0-прогона.

Функциональный LMX объединяет только калибровочное выражение fuse(gain .* xs .+ bias) в один обход. Создание маски .>= и compress — следующие самостоятельные операции; вся цепочка не объявляется одним циклом. Julia автоматически объединяет соседние dot-вызовы. Процедурный вариант явно читает, вычисляет и отбирает отсчёты в одном цикле; результат выделяется по фактическому профилю источника. Это сравнение полных исходников, без заявления о выигрыше по времени. В throws отдельно скопированы исходы fuse и выбранных операций: fuse не обещает скрытого union любого RAW-выражения. Декорация .op передаёт depth=1 базовой операции; ссылки throws используют её базовое точное имя. Ресиверные имена с добавленной точкой не создаются как алиасы.

## LMX — процедурный

```lmx
Example:
    @: xs
    @: gain
    @: bias
    @: limit
    return: @
    run:
        throws: copy(FxSeqInfo\get\throws) copy(FxSeqAllocate\make\throws) copy(sys\resize\throws)
        @: info FxSeqInfo\get(xs)
        @: out FxSeqAllocate\make(info\arrayType; length(xs))
        int: used 0
        int: i 0
        while: i < length(xs)
            @: value gain * xs[i] + bias
            if: value >= limit
                out[used] := value
                used += 1
            i += 1
        sys\resize(out; used)
        return: out
```

[Полный исходник](source/lmx/procedural/J25.lm3). 330 непробельных символов; 20 непустых строк. Все объявления и Throws включены.

## LMX — функциональный

```lmx
Example:
    @: xs
    @: gain
    @: bias
    @: limit
    return: @
    run:
        throws: copy(fuse\throws) copy(`*`\throws) copy(`+`\throws) copy(`>=`\throws) copy(compress\throws)
        @: calibrated fuse(gain .* xs .+ bias)
        return: compress(calibrated; calibrated .>= limit)
```

[Полный исходник](source/lmx/J25.lm3). 215 непробельных символов; 10 непустых строк. Все объявления и Throws включены.

## Julia

[Полный исходник](source/julia/J25.jl).

```julia
function example(xs, gain, bias, limit)
    calibrated = gain .* xs .+ bias
    calibrated[calibrated .>= limit]
end
```
