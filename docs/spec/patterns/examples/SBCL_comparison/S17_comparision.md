# S17. LOOP: условное накопление

Полная пара в указанном ниже договоре.

## Общий договор

Сложить квадраты нечётных целых из списка; пустой вход даёт 0. Отрицательные нечётные числа тоже включаются. Вход не меняется.

## Входы и ожидаемые наблюдения

```json
[
  {
    "args": [
      [
        1,
        2,
        3,
        4
      ]
    ],
    "expected": 10
  },
  {
    "args": [
      []
    ],
    "expected": 0
  },
  {
    "args": [
      [
        -3,
        -2,
        0,
        5
      ]
    ],
    "expected": 34
  }
]
```

## LMX

[Исходник](source/lmx/S17.lm3).

```lmx
Example:
    int[]: items
    return: int
    run:
        throws: copy(FxThrows\mutation) FxShape
        int[]: odd compress(items; items % 2 != 0)
        return: (+ 0 copy(odd * odd))
```

## Common Lisp / SBCL

[Исходник](source/common-lisp/S17.lisp).

```common-lisp
(defun example (items)
  (loop for x in items when (oddp x) sum (* x x)))
```

## Почему эти варианты сопоставимы

Общий compress сначала отбирает нечётные элементы; elementwise умножение работает только с выбранными числами, затем штатный + потребляет явный поток. Квадраты исключённых чётных значений не вычисляются.

compress сначала выбирает нечётные числа; затем общий Expression складывает квадраты выбранных значений. Чётные элементы не возводятся в квадрат. Сохраняется общий расчёт LOOP без имитации его синтаксического DSL.

Средства Common Lisp/SBCL: `CL:LOOP`.
