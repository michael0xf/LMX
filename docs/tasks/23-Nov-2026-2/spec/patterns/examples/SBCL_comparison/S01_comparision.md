# S01. MAPCAR: преобразование списка

Полная пара в указанном ниже договоре.

## Общий договор

Умножить каждый элемент конечного списка целых на 3; сохранить порядок, вход не менять. Числа и промежуточные результаты помещаются в LMX int.

## Входы и ожидаемые наблюдения

```json
[
  {
    "args": [
      [
        -2,
        0,
        3
      ]
    ],
    "expected": [
      -6,
      0,
      9
    ]
  },
  {
    "args": [
      []
    ],
    "expected": []
  },
  {
    "args": [
      [
        7
      ]
    ],
    "expected": [
      21
    ]
  }
]
```

## Размер основного варианта

| Источник | Полный, без пробельных | Без сложного Throws | Все символы | Непустые строки |
| --- | ---: | ---: | ---: | ---: |
| LMX | 49 | 49 | 79 | 5 |
| Common Lisp / SBCL | 50 | — | 62 | 2 |

Учитывается полный основной листинг. Тестовый стенд и отдельные реализации ядра в него не входят; их файлы и размеры приведены отдельно.

## LMX

[Исходник](source/lmx/S01.lm3).

```lmx
Example:
    int[]: items
    return: int[]
    run:
        return: items * 3
```

## Common Lisp / SBCL

[Исходник](source/common-lisp/S01.lisp).

```common-lisp
(defun example (items)
  (mapcar (lambda (x) (* x 3)) items))
```

## Почему эти варианты сопоставимы

Элементная Array/scalar арифметика прямо закреплена §18; чистый общий int-профиль, без изменения входа.

 Основной вариант выбран по меньшему полному размеру: Элементная Array/scalar арифметика прямо закреплена §18; чистый общий int-профиль, без изменения входа.

Средства Common Lisp/SBCL: `CL:MAPCAR`.

## Реализации используемых функций

Основной листинг использует базовые средства языка и полностью приведённые прикладные определения.

Common Lisp-клиент не загружает сравнительные reference-реализации.

## Другой подход: LMX с общими ресиверами ядра

Исходный полный вариант; нормы и конечные эффекты проверены. Полные текущие размеры приведены в статистике.

[Исходник](alternatives/lmx/S01_core.lm3). В основной коэффициент не входит.

```lmx
Scale:
    int: value
    return: int
    run:
        return: value * 3

Example:
    int[]: items
    return: @
    run:
        throws: copy(FxThrows\traversal)
        return: map(items; Scale\run)
```

`map`: [SI01](library_comparisons/SI01_comparision.md).
