# Статус поставки 26 ноября (2)

**Историческая норма.** Квадратные и указательные суффиксы TYPE, прежние
групповые записи с `:=` и обработка ссылки как подгруппы относятся к исходной
редакции. Текущие формы — `[][]T`, `@T`, `(a b c) .: f()` и целый Array при
установленном `satisfies = 0`. `.=` остаётся сравнением с глубиной 1.

Проверка пустой строки, синтаксис и готовые примеры идут
[первыми в v3](../../../next_core_tasks_v3.md#grammar-first-20261126).
Хранение, Expression, каталог и общий путь интерпретатора/SLJIT учтены в
[29.8](../../../next_core_tasks_v3.md#types-arrays-20261126).
