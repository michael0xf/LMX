# J10. Слитное поэлементное выражение

## Общий договор

Для двух целочисленных векторов одинаковой длины вернуть 2*x + y*y по позициям. Арифметика без переполнения, callbacks не имеют эффектов.

В обеих сторонах используется поэлементная арифметика существующего языка. Общий домен — одинаковые длины, целые без переполнения и чистые операции. Материализованный результат сохраняет порядок; отдельный Combine/zipWith не нужен.

Вход:

```json
{
  "left": [
    1,
    2,
    3
  ],
  "right": [
    4,
    5,
    6
  ]
}
```

Ожидаемое наблюдение:

```json
[
  18,
  29,
  42
]
```

## LMX

```lmx
Example:
    int[]: left
    int[]: right
    return: @
    run:
        return: 2 * left + right * right
```

## Julia

```julia
example(left, right) = 2 .* left .+ right .* right
```

## Размер полного клиента

| Язык | Без пробельных символов | Без сложного Throws | Непустые строки | Все Unicode-символы |
| --- | ---: | ---: | ---: | ---: |
| LMX | 66 | 66 | 6 | 106 |
| Julia | 41 | 41 | 1 | 51 |

Дополнительная колонка оставляет заголовок и первый аргумент Throws; copy(Throws) сохраняется целиком. Полный исходник и его основной счёт не изменяются.

## Реализации использованного ядра

Только уже существующие Expression/array arithmetic; отдельный helper не вводится.

Julia-клиент использует реальные Base/пакет; реализации из library_comparisons он не импортирует. [Общие зависимости и границы](library_comparisons/README.md) учитываются отдельно. Код проверен как текст и по договорам; исполнение LMX/Julia здесь не заявлено.
