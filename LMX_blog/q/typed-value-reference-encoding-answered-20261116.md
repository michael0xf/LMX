# Что хранит ссылка на запись значения: адрес кода типа или адрес значения

Дата: 2026-11-16. Задаёт исполнитель (сессия fable_pc). Статус: **закрыт ответом автора 2026-11-16 — «б»**.

Норма, к которой относится вопрос: [запись значения, L2 §3](../../docs/spec/L2_spec_ru.md#value-record),
[журнал](../2026-11-16.md#typed-value-raw-layout), [план M15](../../next_core_tasks_v3.md#typed-value-records).
Запись в памяти в обоих вариантах одна и та же: код типа, вплотную за ним значение. Различается только число,
которое хранит слот и любая другая ссылка графа.

## Минимальная программа

```lmx
int: x 5
S:
    int: a 1
@: p int @x
```

Пусть запись `x` лежит так: код `int` по адресу A, значение 5 по адресу A+4.

## Вариант «а»: ссылка — адрес кода

Слот поля, `@x`, значение `p` и `parent` хранят адрес кода. Тип читается по ссылке, значение — по ссылке+4; у
Structure ссылка R, дескриптор `parent/length/storage` — по R+4. Так сказано в описании автора: «указатель на начало
записи».

Что из этого следует в коде. У каждого объекта два адреса: ссылка — в слотах, `parent`, ячейках ссылок, ключах
таблицы имён и карты копирования; адрес значения — `Lmx *`, `int *` для чтения полей и для двери C. Каждое место
перехода между ними получает +4 или −4. По описи нынешнего кода (opus, чтением): приведений к `Lmx` в `lmx_*.lm2` —
618; в выпущенном `p.c` одной фикстуры `(Lmx *)` — 131 и `->parent =` — 104. Оба адреса имеют один и тот же тип
указателя C, поэтому ошибку на четыре байта компилятор не обнаруживает. `@x`, передаваемый в C как `int *`,
пересчитывается на двери.

## Вариант «б»: ссылка — адрес значения

Слот поля, `@x`, значение `p` и `parent` хранят адрес значения: для `x` это A+4, для Structure — адрес её
дескриптора, как сегодня. Значение читается по ссылке, тип — по ссылке−4.

Что из этого следует в коде. Все существующие адреса сохраняют нынешний смысл — адрес ячейки `int`, адрес заголовка;
слоты, `parent`, `@x`, таблица имён и дверь C не меняются. Меняются только места, где сегодня тип узнаётся по адресу:
они читают код четырьмя байтами раньше.

## Что наблюдает программа

Одинаково в обоих вариантах: `\p` даёт 5, `sys\typeof(@x)` — `int`, `sys\typeof(S)` — Structure, `S[0] := @x`
кладёт в слот ссылку на `x`, запись через `p` видна по имени `x`. Память и скорость одинаковы: смещение кода
относительно значения постоянно.

## Вывод исполнителя и сомнение

Вывод: «б» — та же раскладка при заметно меньшей и более безопасной переделке. Сомнение: слова автора называют
указателем начало записи. До ответа в документах был записан «а».
