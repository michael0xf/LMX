# Спецификация L2

L2 — LMX со специальными операциями низкого уровня. Настоящая спецификация описывает эти операции, их семантику и точное устройство ядра на уровне L2, включая представление данных, размещение в памяти и доступ из потоков. Семантика чистого герметичного LMX (L3) определена в [основной спецификации](LMX_semantics.ru.md), общая грамматика — в [спецификации грамматики LMX](LMX_grammar.ru.md).

Описанию каждого механизма ядра соответствует раздел [спецификации L1](L1_spec_ru.md), определяющий его реализацию на L1 и C99. Оба описания задают один механизм на соответствующих уровнях; перевод L2 → L1 → C99 сохраняет его поведение.

## Атомарные флаги рукопожатия

Атомарные флаги рукопожатия размещаются в арене родителя. К этим флагам допускается многопоточный доступ, включая изменение, без синхронизации. Доступ из нескольких потоков допускается также к неизменяемым константным веткам; флаги, в отличие от этих веток, изменяются.

Соответствующая реализация на L1/C: [атомарные флаги рукопожатия](L1_spec_ru.md#atomic-handshake-flags).
