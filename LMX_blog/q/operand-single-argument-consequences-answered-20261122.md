# Раскрытие единственного аргумента операнда: следствия на подтверждение

Дата: 2026-11-21. Задавал исполнитель (сессия fable_pc). Статус: **закрыт ответом автора 2026-11-22**.
Следствия 3 и 4 закрыты ответами автора 2026-11-21, следствие 1 — выводом из них, следствие 2 — ответом
автора 2026-11-22 ([журнал](../2026-11-22.md#operand-left-unnamed-structure)): правило отредактировано.

## Что решено

[Решение автора 2026-11-21](../2026-11-21.md#group-assign-decision): единственный аргумент операнда, если он
безымянная Structure, раскрывается (слова «как в методах» автор затем снял); Structure, возвращённую функцией, не
раскрывают; `(a b c) := copy(s)` — ошибка, надо `(a b c) := (copy(s))`.

## Следствие 1. Результат функции слева принимает группа мест — закрыто

`myFn` возвращает Structure из трёх `int`: 1, 2, 3.

```lmx
(a b c) := myFn()
```

- **А (взято, внесено в книгу).** Результат не раскрывается: справа одно значение, мест три — отказ по числу.
  До решения книга говорила, что места получают поля результата по позиции (решения 2026-11-10 и 2026-11-16).
- **Б.** Запись остаётся присваиванием между Structure и раздаёт поля результата без раскрытия: a=1, b=2, c=3.

Закрыто выводом исполнителя из двух ответов автора: утверждена
[форма `() := ()`](../2026-11-21.md#group-assign-form), а Structure, возвращённую функцией, не раскрывают
([решение](../2026-11-21.md#group-assign-decision)). Запись — ошибка: чтение А.

## Следствие 2. Одно место слева — закрыто

`struct` — объявленная ссылка; запись взята из
[требования о потоках](../../docs/spec/LMX_semantics.ru.md#composition), §6.1.

```lmx
struct := (copy(args))
```

- **А (документы сейчас в этом чтении).** Правило действует, когда слева группа мест. При одном месте слева
  группа справа остаётся одним значением, как сказано в §6.1: `struct` получает одну Structure. Так же
  `p := (1, 2)`.
- **Б (буква правила).** Правило от левой стороны не зависит: группа раскрывается и здесь.
  `struct := (copy(args))` становится потоком на одно место, а одна Structure пишется
  `struct := ((copy(args)))`. Тогда в требовании меняются пример §6.1, две строки таблицы §10 и строка P05.

Прежнее основание чтения А — сравнение с подачей `f(arg := S)` у методов — автор снял
([журнал](../2026-11-21.md#operand-right-rule)), поэтому вопрос был поставлен заново. Масштаб в программах
нулевой: в исходниках, тестах и примерах автора нет ни одной строки `место := (несколько значений)` и ни одной
`место := (copy(…))`.

Ответ автора 2026-11-22 ([журнал](../2026-11-22.md#operand-left-unnamed-structure)): чтение А, но условие —
не число мест слева, а то, что `left` — безымянная Structure. Правило отредактировано: если `left` —
безымянная Structure и единственный аргумент `right` — тоже безымянная Structure, скобки справа
раскрываются, и в `right` приходит всё их содержимое. В `struct := (copy(args))` слева не безымянная
Structure: скобки не раскрываются, `struct` получает одну Structure. Внесено в документы — Р136.

## Следствие 3. Несколько значений справа без скобок — закрыто

`a`, `b`, `c`, `d` — объявленные `int` со значениями 1, 2, 3, 4; запись — строка S01 того же требования, §8.

```lmx
(c b d a) := a b c d
```

- **А (было взято).** Правило говорит о единственном аргументе; здесь их четыре, запись верна.
- **Б (ответ автора).** Справа от группы мест стоит одна Structure: запись без скобок — ошибка, как у `copy`.

Ответ автора — [журнал](../2026-11-21.md#group-assign-form): утверждена форма `() := ()`. Пример записан
`(c b d a) := (a b c d)`, результат тот же: c=1, b=2, d=3, a=4.

## Следствие 4. Правило методов шире правила операнда — закрыто

По [требованию о связывании](../../docs/spec/LMX_semantics.ru.md#declaration-selection), §9.3–§9.4, у
метода чтение полями рассматривается для единственного поданного значения, которое есть Structure либо ссылка
на неё, — в том числе именованной и полученной из вызова. Для операнда решение называет только безымянную
Structure и исключает результат функции.

```lmx
f(myFn())
```

`f` объявлена с тремя входами `int`, `myFn` возвращает Structure из трёх `int`.

- **А (было взято, подтверждено).** Правило методов не менялось.
- **Б.** Сравнение с методами относится к обоим: результат функции не раскрывается и у метода.

Ответ автора — [журнал](../2026-11-21.md#operand-right-rule): у метода всё иначе, сравнение с методами
снято; правило операнда своё — раскрывается его единственный аргумент `right`, когда он безымянная Structure.
