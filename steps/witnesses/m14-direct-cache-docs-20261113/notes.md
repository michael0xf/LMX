# M14: локальные значения и общий кеш прямого доступа

Документальный срез Codex (Sol), 2026-11-13. База main `035d3fcd`.
Подготовленные изменения приняты в основном дереве; код ядра не изменяется.

Локальные рабочие значения и dirty принадлежат каждой активации. Прозрачный кеш прямого
доступа общий для корня и всех его вызовов одного исполнения, включая native/обходчик.
Он согласует одну физическую ячейку через пути, индексы, разыменование и любые алиасы;
правило сохранения локального снимка после вложенного вызова на него не переносится.
При смене промежуточной ссылки обновляется выбранный конечный адрес.

flush() сначала публикует dirty собственных локалов текущего кадра в общее состояние
ячеек в прямом порядке полей, затем ожидающие записи общего кеша — в граф. Чужие локалы
не публикуются и не перечитываются. Локальная публикация обязательно согласует общий кеш.
Конфликт `x := 2; data\x := 9` даёт прямое чтение 9 до flush и 2 после публикации dirty-локала;
чистый локал сохраняет 9. Повтор без изменений ничего не пишет. Нового кадра, выхода, yield и
публикации Message нет. Универсальный журнал, копия графа и поиск на каждом доступе
не требуются; native по возможности определяет необходимые записи статически.
