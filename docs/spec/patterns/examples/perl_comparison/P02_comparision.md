# P02. Отбор элементов через grep

## Общий договор

Сохранить только чётные целые числа, включая ноль и отрицательные; сохранить исходный порядок и повторы.

Готовая поэлементная маска заменяет отдельное тело чистого предиката; compress сохраняет профиль, порядок и повторы исходного массива.

## Вход и ожидаемый результат

```json
{
  "arguments": [
    [
      -3,
      -2,
      0,
      1,
      2,
      2
    ]
  ],
  "result": [
    -2,
    0,
    2,
    2
  ]
}
```

Дополнительные границы находятся в test_cases канонического [examples.json](examples.json); harness исключён из размера кода.

## Размер выбранного варианта

| Источник | Все символы | Без пробельных | Без сложного Throws | Непустые строки |
|---|---:|---:|---:|---:|
| LMX | 144 | 100 | 93 | 6 |
| Perl | 107 | 77 | 77 | 6 |

Дополнительная колонка исключает только аргументы Throws после первого. Заголовок, первый аргумент и ссылки copy(Throws) сохраняются; исходник не изменяется.

Учитываются полные листинги, директивы, комментарии и обработка ошибок. Встроенное ядро не добавляется к каждому клиенту; его реализации считаются отдельно.

## LMX

[Исходник](source/lmx/P02.lm3).

```lmx
Example:
    int[]: items
    return: @
    run:
        throws: copy(FxThrows\mutation) FxShape
        return: compress(items; items % 2 = 0)
```

## Perl

[Исходник](source/perl/P02.pl).

```perl
use strict;
use warnings;
sub example {
    my ($items) = @_;
    return [grep { $_ % 2 == 0 } @$items];
}
```
