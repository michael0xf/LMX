## План коммитов (каждый под полным гейтом; P0-коммиты — плюс `run_parser.py --profile current`, self-build парсера, пин L1)

1. **Голый атом-оператор native (N7; без решения автора; чинит segfault).** `l2_check_body` и эмиттер разрешают голый атом через один резолвер (-131): fn/sub — нульарный вызов, тот же путь, что `m()`; литерал/own-поле/формал — discard (data-атом плана); обычная именованная Structure — located-отказ до коммита 4; неразрешённое имя — существующая диагностика. Строки: `unit_bare_fn_stmt`, `_sub_stmt` (3), `_in_method`, `_literal_stmt`, `_own_stmt`, `_struct_refused`, `_unknown_refused`. Мутант: без ветки атома строки снова падают.
2. **Контракт получателя (N5/N6/(f); без решения автора).** Имя метода в позиции значения: callable-формал — ссылка (как сегодня); результатный (`l2_m_ret != 8`) — исполняется; без результата (sub) — отказ «a callable without a result has no value». Trailer `return: m` идёт путём тела. Отказ `return: s` убирает эмиссию в колонке 0; void-ветка `l2_emit_nullary_call` сохраняет `ind`. `S()` при существующей S — присваивание пустой Structure через admission (при отказе — неявный `implements`, ловится catch). Строки: d2 (7), d3 (отказ), f1 (7), f3 (отказ), `S()` на S без полей (присваивает) и с полем (исход admission `()` → S). Мутанты: без ветки значения — d2/f1 RED; без отказа no-result — d3/f3 RED. Удалить устаревший комментарий «C ABI wrapper» (:12928).
3. **P0 terminal return (после C1).** `lm_p0_trailer_role_accepts_target` берёт решённую таблицу; удалить шесть заглушек реестра и 3 места вызова; синхронизировать копии парсера, 3 C-зеркала, пин L1; удалить или явно исключить `tmp_unitroot_test`. Goldens: закрытие return для fn (есть), sub (голый), fm (голый), обычной S (только чтение А); отрицательные: `if: c` + тело + return колонки 0 остаётся элементом; `x: 5` / `return: x` — элементом; `else:` + тело + return — элементом; неизменные деревья `f()`, `f: ()`, закрытая вертикаль `f:` + `---`; голое `f` — атом. Гейт «взрыва»: diff деревьев всех фикстур/источников под новым парсером = решённое множество. Мутанты: R-any проваливает отрицательные; fn-only проваливает goldens sub/fm/S.
4. **Определения в трансляторе (после C1 и Q-138-2).** `l2_unit_role` принимает sub/fm/S, закрытые return-trailer'ом; `fm` — либо пункт дизайна (N2 результат-структура), либо явная located-строка «fm is not supported» (сегодня отсутствует и читается как присваивание); `l2_take_ns_body` принимает исполняемые операторы по Q-138-2, голое `S` и `return: v` исполняют.
5. **Ядро и интерпретаторы (файлы Grok, после -134).** Бит «с результатом» в `LmxCallable`/`LmxMethod` + запрос рядом с `lmx_call_ready`; walker RET: результатный активируется, без результата — возвращается ссылкой (или отказ там, где нужно значение); L3 и тело walker'а: голый CALLABLE-оператор исполняется или явный UNSUPPORTED, никогда молча OK; plain Structure-оператор — явный UNSUPPORTED. Строки: `lmx_walk_selftest` «RET of a sub occurrence», L3 голый callable-оператор. Мутант: без проверки бита строка sub падает.
6. **Гейт инвентаря:** проверка, падающая на любом `lm_p0_registry_` или литерале имени головы вне грамматической таблицы и на расхождении копий парсера.

Пересечения: коммиты 1, 2, 4 правят `l2trans.lm1` в других функциях, чем Sonnet -137 (предпроход, `l2_emit_sig`) — сажать после -137 или перебазировать; коммит 5 — файлы Grok -134.
