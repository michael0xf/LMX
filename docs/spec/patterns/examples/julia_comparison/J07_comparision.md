# J07. Последовательные списания и возвраты с нижней границей

## Общий наблюдаемый договор

Начать с неотрицательного seed. Положительное amount списывает средства, отрицательное возвращает их; после каждого шага баланс ограничивается снизу нулём. Порядок важен: превышение доступного баланса не превращается в переносимый долг. Пустой вход сохраняет seed; переполнение исключено.

Обе полные реализации выполняют один новый прикладной сценарий: процедурная задаёт алгоритм явно, функциональная использует общие операции ядра. Изменённые тексты требуют нового P0-прогона.

Сценарий расширен по замечанию автора: показана обработка данных и полезный итог, а не только вызов одной функции. ## LMX — процедурный

```lmx
Example:
    []int: xs
    int: seed
    return: int
    run:
        int: balance seed
        int: i 0
        while: i < length(xs)
            balance -= xs[i]
            if: balance < 0
                balance := 0
            i += 1
        return: balance
```

[Полный исходник](source/lmx/procedural/J07.lm3). 131 непробельных символов; 13 непустых строк. Все объявления и Throws включены.

## LMX — функциональный

```lmx
BudgetStep:
    int: balance
    int: amount
    return: int
    apply:
        int: next balance - amount
        if: next < 0
            return: 0
        return: next

Example:
    []int: xs
    int: seed
    return: int
    run:
        throws: copy(foldl\throws) copy(record\throws)
        return: \foldl(xs; (seed record); BudgetStep\apply)
```

[Полный исходник](source/lmx/J07.lm3). 227 непробельных символов; 16 непустых строк. Все объявления и Throws включены.

## Julia

[Полный исходник](source/julia/J07.jl).

```julia
function example(xs, seed)
    debit(balance, amount) = max(balance - amount, 0)
    foldl(debit, xs; init=seed)
end
```
