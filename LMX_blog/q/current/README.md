# Открытые вопросы автору

Открытых вопросов автору сейчас нет. [Вопросы к поручению 2026-11-10 из пяти пунктов](../rework-questions-20261110.md)
закрыты ответами автора в тот же день. По поручению автора от 2026-11-10 исполнитель до конца плана вопросов ему не
задаёт: записывает их, отвечает сам с пометкой «ответил fable» и переносит уровнем выше —
[ответы исполнителя 2026-11-10](../fable-self-answers-20261110.md). [Вопрос U3 об обычной var снят](../ordinary_var_execution_20261103.md)
после сверки истории и подтверждения прежних правил 2026-11-03; реализация
остаётся в WIP267.

Для нового вопроса укажите минимальный пример, точные противоречащие
нормы/измерения и зависимый этап [плана v3](../../../next_core_tasks_v3.md).
После ответа перенесите вопрос и дословный ответ в `LMX_blog/q/`;
организационную переписку сюда не помещайте.
