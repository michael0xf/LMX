# Состояние ссылки на безымянное место: проверка, 2026-11-25

План 29.3 (после д1 и д2): «Отдельная проверка состояния (после широкой проверки): при жизни кадра полезная нагрузка
ссылки равна адресу выбранного места, или `n` меняется после присваивания и новое читается через `typed`; не тронутая
ссылка — uninit (д1 проверяет истинный нуль); именованный адресат — существующая положительная ветвь». Проверка
выполнена на комплекте д5: состояние ссылки соответствует норме, дефекта нет, ядро не менялось. Добавлена одна
постоянная строка. Строка `k3_reference_places` остаётся красной: печать останавливается на именованной ссылке с
ненулевым адресом безымянного адресата — явный диагностический отказ по решению Sol и Astra
(`SOL-ASTRA-K3-UNNAMED-REFERENCE-DUMP-20261125-01`, д6).

## Что измерено

1. Полезная нагрузка равна адресу выбранного места (gdb, отладочный graph producer комплекта д5; `CF/d5-02/dbg`,
   `gdb-payload.log`; скрипт `gdb_payload.py`). Запись `Observed\typed := @n` (`lmx_graph_store_path_reference`):
   данной ячейке рода 5 отвечает полезная нагрузка `0x2211a3a8160`, значение там 5. Чтение `\(Observed\typed)`
   (`lmx_graph_reference_value`): ячейка ссылки `0x…a7f70` рода 5, та же полезная нагрузка, значение 5. После `n := 6`
   то же чтение даёт ту же полезную нагрузку и значение 6. Полезная нагрузка — адрес места, а не снимок значения.
2. То же по значениям в строке `reference_state_in_frame`: `seen_first` 5, `seen_after` 6.
3. Не тронутые ссылки остаются uninit: `typeof(Observed[1])` для `@: untouched` — 1001029, `typeof(Observed[2])` для
   `@: untouched_int int` — 1001028.
4. Записанная ссылка: `typeof(Observed[0])` — 1001025.
5. Именованный адресат: `Observed\zero := build\data\h` печатается `@: zero Box`, `Observed\zero\value` читается 1;
   чтение через `zero` идёт по ячейке рода 6, её полезная нагрузка — адрес Structure Box.
6. `n := 6` внутри `main` пишет место вызова и не пишет обратно: корневое `int: n 5` без изменения. Ссылка `typed`
   обнулена до конца кадра (`@: typed int 0`), поэтому печать доходит до конца.

## Норма

- Ссылки присваиваются только друг другу и обнуляются (`provenance/semantics-book.md:11`, русская сторона; `:70`,
  английская).
- Присваивание и места объявления (`:2498–2503`, #frame-and-graph-assignment): локальное присваивание пишет кадр и
  оставляет исходный граф без изменения; явная запись по пути заменяет фрагмент графа в выбранном структурном месте, и
  новое обращение через это место видит новый фрагмент.
- `typeof` (`:4891–4892`, #get-type): код типа выбранной типизированной записи; запись `uninit:T` даёт свой код без
  чтения значения. `:4881`: тип ссылки не смешивается с отсутствием значения.
- P01 (`docs/spec/kernel-implementation.en.md`, #primitive-storage): `uninit:T` — только код типа.
- Коды (`selfbuild/tools/build.lm2:1157`): 1001025 `LMX_TYPE_GRAPH_INT_REF`, 1001026 `LMX_TYPE_GRAPH_LMX_REF`,
  1001027 `LMX_TYPE_GRAPH_REF`, 1001028 `LMX_TYPE_UNINIT_GRAPH_INT_REF`, 1001029 `LMX_TYPE_UNINIT_GRAPH_LMX_REF`;
  тип → род (`selfbuild/src/l2src/lmx_checks.lm2:44–53`): 5, 6, 7, 8, 9.
