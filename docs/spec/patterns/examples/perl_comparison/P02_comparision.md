# P02. Отбор элементов через grep

## Общий наблюдаемый договор

Сохранить только чётные целые числа, включая ноль и отрицательные; сохранить исходный порядок и повторы.

Обе формы сохраняют один наблюдаемый договор; процедурная запись показывает управление и изменение данных, функциональная использует общие операции ядра.

Готовая поэлементная маска заменяет отдельное тело чистого предиката; compress сохраняет профиль, порядок и повторы исходного массива.

## Вход и ожидаемое наблюдение

```json
{
  "arguments": [
    [
      -3,
      -2,
      0,
      1,
      2,
      2
    ]
  ],
  "result": [
    -2,
    0,
    2,
    2
  ]
}
```

| LMX процедурный | 208 | 333 | 12 |

Обе LMX-формы опубликованы и считаются независимо. Все определения, обработчики и ссылки на throws входят в полный размер. Выбор единственного LMX-варианта по длине не выполняется.

## LMX — процедурный

```lmx
Example:
    int[]: items
    return: @
    run:
        throws: copy(FxSeqPush\append\throws) copy(FxRecordOperands\record\throws)
        int[]: out []
        int: i 0
        while: i < length(items)
            if: items[i] % 2 = 0
                FxSeqPush\append(out; (items[i] record))
            i += 1
        return: out
```

[Полный исходник](source/lmx/procedural/P02.lm3). 208 непробельных символов; 12 непустых строк. Все объявления и Throws включены.

## LMX — функциональный

```lmx
Example:
    int[]: items
    return: @
    run:
        throws: copy(FxSeqCompress\compress\throws)
        return: compress(items; items % 2 = 0)
```

[Полный исходник](source/lmx/P02.lm3). 105 непробельных символов; 6 непустых строк. Все объявления и Throws включены.

## Perl

[Полный исходник](source/perl/P02.pl).

```perl
use strict;
use warnings;
sub example {
    my ($items) = @_;
    return [grep { $_ % 2 == 0 } @$items];
}
```
