# P01. Преобразование целого списка

## Общий наблюдаемый договор

Вернуть новый список, умножив каждое целое число на 3; порядок и нули сохраняются. Вход не меняется.

Обе формы сохраняют один наблюдаемый договор; процедурная запись показывает управление и изменение данных, функциональная использует общие операции ядра.

Чистая поэлементная арифметика существующего Expression даёт новый плотный int[]; сравниваются значения и порядок. Для callback с эффектами применялся бы map.

## Вход и ожидаемое наблюдение

```json
{
  "arguments": [
    [
      -2,
      0,
      3
    ]
  ],
  "result": [
    -6,
    0,
    9
  ]
}
```

| Полный исходник | Непробельные символы | Все Unicode-символы | Непустые строки |
| --- | ---: | ---: | ---: |
| LMX процедурный | 160 | 274 | 12 |

Обе LMX-формы опубликованы и считаются независимо. Все определения, обработчики и ссылки на throws входят в полный размер. Выбор единственного LMX-варианта по длине не выполняется.

## LMX — процедурный

```lmx
Example:
    int[]: items
    return: @
    run:
        throws: copy(sys\resize\throws)
        int[]: out []
        sys\resize(out; length(items))
        int: i 0
        while: i < length(items)
            out[i] := items[i] * 3
            i += 1
        return: out
```

[Полный исходник](source/lmx/procedural/P01.lm3). 160 непробельных символов; 12 непустых строк. Все объявления и Throws включены.

## LMX — функциональный

```lmx
Example:
    int[]: items
    return: @
    run:
        return: items * 3
```

[Полный исходник](source/lmx/P01.lm3). 45 непробельных символов; 5 непустых строк. Все объявления и Throws включены.

## Perl

[Полный исходник](source/perl/P01.pl).

```perl
use strict;
use warnings;
sub example {
    my ($items) = @_;
    return [map { $_ * 3 } @$items];
}
```

## Общие библиотечные реализации

Используются базовые операции языка; предметные определения приведены целиком.

Тела библиотечного ядра сохранены в одном общем источнике и не размножаются для двух стилей. Иностранный клиент использует свои настоящие средства; соседние comparison-реализации он не импортирует.

## Проверка
