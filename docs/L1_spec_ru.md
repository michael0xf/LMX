# Спецификация L1

Область описания — язык L1, его трансляция в C99 и точное устройство реализации ядра L2 на L1 и C. Представление данных, размещение в памяти, доступ из потоков и механизмы выполнения являются частью этой спецификации, включая детали, от которых зависит сохранение модели языка.

Семантика чистого герметичного LMX (L3) определена в [основной спецификации](LMX_semantics.ru.md). Специальные низкоуровневые операции и устройство ядра на уровне L2 описаны в [спецификации L2](L2_spec_ru.md). Соответствующие разделы настоящей спецификации определяют их реализацию на L1 и C.
