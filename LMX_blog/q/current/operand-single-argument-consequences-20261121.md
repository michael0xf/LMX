# Раскрытие единственного аргумента операнда: следствия на подтверждение

Дата: 2026-11-21. Задаёт исполнитель (сессия fable_pc). Статус: **открыт**. Работу не останавливает: решение
автора внесено в документы и в план; ниже — три следствия, в которых исполнитель взял одно чтение и назвал его.

## Что решено

[Решение автора 2026-11-21](../../2026-11-21.md#group-assign-decision): единственный аргумент операнда, если он
безымянная Structure, раскрывается точно так же, как в методах; Structure, возвращённую функцией, не
раскрывают; `(a b c) := copy(s)` — ошибка, надо `(a b c) := (copy(s))`.

## Следствие 1. Результат функции слева принимает группа мест

`myFn` возвращает Structure из трёх `int`: 1, 2, 3.

```lmx
(a b c) := myFn()
```

- **А (взято, внесено в книгу).** Результат не раскрывается: справа одно значение, мест три — отказ по числу.
  До решения книга говорила, что места получают поля результата по позиции (решения 2026-11-10 и 2026-11-16).
- **Б.** Запись остаётся присваиванием между Structure и раздаёт поля результата без раскрытия: a=1, b=2, c=3.

## Следствие 2. Одно место слева

`struct` — объявленная ссылка; запись взята из
[требования о потоках](../../../docs/TZ/LMX_Fable_TZ_Import_Copy_Merge_Field_Streams_2026-11-21.md), §6.1.

```lmx
struct := (copy(args))
```

- **А (взято, документы здесь не менялись).** `имя := значение` — подача одному названному месту, как
  `f(arg := S)` у методов: раскрытия нет, `struct` получает одну Structure. Так же `p := (1, 2)`.
- **Б.** Группа справа раскрывается и здесь: поля `args` идут на одно место — отказ по числу, когда полей не
  одно; Structure целиком пишется с двойными скобками.

## Следствие 3. Несколько значений справа без скобок

`a`, `b`, `c`, `d` — объявленные `int` со значениями 1, 2, 3, 4; запись — строка S01 того же требования, §8.

```lmx
(c b d a) := a b c d
```

- **А (взято, строка оставлена).** Правило говорит о единственном аргументе; здесь их четыре, запись верна:
  c=1, b=2, d=3, a=4. То же даёт `(c b d a) := (a b c d)`.
- **Б.** Справа от группы мест должна стоять одна Structure: запись без скобок — ошибка, как у `copy`.
