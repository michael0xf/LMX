# Тикеты LMX

Действующий порядок работ задаёт [план v3](../../next_core_tasks_v3.md), а [текущее состояние](../current.md) указывает единственного writer/build. Тикет уточняет зависимость, дефект и критерий приёмки; сам по себе он не назначает исполнителя, не меняет приоритет плана и не разрешает параллельную сборку.

В новом тикете укажите минимальный свидетель, затронутую общую норму, точные места кода, ожидаемые native/walker проверки, статус OPEN / IN WORK / DONE и подтверждающий commit или запуск. При реальном противоречии общих норм сформулируйте автору вопрос; не добавляйте частный обход. Завершённый тикет не закрывает автоматически соседний этап или полный gate.

Прежний процесс 2026-09-25 с Grok CLI и автоматической раздачей через Fable сохранён в истории Git; это не текущая инструкция. Для связи с доступными агентами используйте [актуальные маршруты](../../work_chat/README.md).
