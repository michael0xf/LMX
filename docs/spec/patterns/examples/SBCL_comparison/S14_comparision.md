# S14. LABELS: локальная рекурсия

Полное сравнение на указанном домене.

## Общий договор

Вычислить n! для целого 0<=n<=12. Локальный рекурсивный helper принадлежит вызову example; нет глобального изменяемого счётчика.

## Размер полных вариантов

| Источник | Без пробельных | Все символы | Непустые строки |
| --- | ---: | ---: | ---: |
| LMX — процедурный | 125 | 244 | 13 |
| LMX — функциональный | 125 | 244 | 13 |
| Common Lisp / SBCL | 71 | 107 | 4 |

Оба стиля LMX сравниваются независимо по одному договору. Все объявления, вспомогательные определения и Throws входят в размер. Реализация общих библиотечных операций учитывается отдельно один раз.

## LMX — общая минимальная форма обоих стилей

Договор явно требует локальный рекурсивный helper, принадлежащий Example. Обе формы сохраняют его и тот же scalar Expression; замена рекурсии product/range означала бы другой механизм.

```lmx
Example:
    int: n
    return: int
    Factorial:
        int: k
        return: int
        compute:
            if: k = 0
                return: 1
            return: k * compute(k - 1)
    ---
    run:
        return: Factorial\compute(n)
```

[Общий полный исходник](source/lmx/S14.lm3). Оба стилевых столбца учитывают этот текст целиком: 125 непробельных символов; 13 непустых строк.

## Common Lisp / SBCL

[Полный исходник](source/common-lisp/S14.lisp).

```common-lisp
(defun example (n)
  (labels ((fact (k)
             (if (zerop k) 1 (* k (fact (1- k))))))
    (fact n)))
```

## Соответствие стилей договору

Договор явно требует локальный рекурсивный helper, принадлежащий Example. Обе формы сохраняют его и тот же scalar Expression; замена рекурсии product/range означала бы другой механизм.

Вложенный helper принадлежит Example. Сравнивается результат на 0..12 и область имени, не идентичность создаваемого LABELS function object.

## Общие операции и реализации

Общий договор выражен базовыми средствами языка и приведёнными прикладными определениями.

Common Lisp-клиент использует указанные native/standard средства и не импортирует сравнительные реализации.
