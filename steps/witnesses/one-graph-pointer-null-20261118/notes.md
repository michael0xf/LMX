## The norm

The book, #scope: pointers to Structures and methods are assigned only to one another and are nulled; the null address
is written as zero, `@: ptr 0`. The author's order of 2026-11-18 (`LMX_blog/2026-11-18.md#interpreter-runs-l2`), plan
#one-graph-plan, step P1: the checks live in one kernel module and the types of L3 are its own. Executor's answer R51,
question 3: `p := 0` is accepted; a read, a path step or a call through a null pointer answers what that operation
already answers for an operand that does not suit it; no new answer code.

## What changed

- `lmx_checks.lm2`: the new check `lmx_check_nulled` -- a pointer to an int or to a Structure or a method takes the
  null address; `lmx_check_data_read` also asks the type of the referent, so a read through a null pointer to data is
  refused as a read through what is no pointer to data.
- `lmx_graph.lm2`, `lmx_graph_reference_payload`: an int cell holding 0 given to a pointer place is the null address.
- `lmx_graph_run.lm2`: a place of a call not yet loaded gets a new pointer cell of the pointer's type holding the null
  address (`lmx_graph_null_reference`); the read `\p` passes the type of the referent to the check.
- `tools/build.lm2`: the list of the exports of the module of checks, four names to five.
- Eight new fixtures `checks_pointer_*` and `checks_data_pointer_*`. The emitter and the builder are not changed.

Before this slice the nulling `p := 0` answered 4.

## Recorded and not changed here

- The value decides, not the writing: an int cell holding zero nulls a pointer whether it is a written `0` or the
  value of a variable. The clean graph holds typed cells only, and a written number is such a cell.
- The line form of the dump prints nothing usable for a pointer to an int that holds the null address; no fixture
  reaches it.
- Pointers to data of all scalar types and a write through a pointer are slice C3; the array `[]: T` is slice C4.

## What the running program holds after the step

The clean graph and the native methods, as before. A nulled pointer is a pointer cell of its type holding the null
address; the check is a function of the module of checks, not a mark in the graph. A write to a local of a call
changes neither the graph nor the data: after `p := 0` in a call the data of `main` still print `@: p A`.
