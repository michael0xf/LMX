# Функциональные вычисления

[Руководство RU](LMX_Design_Patterns.ru.md) · [Guide EN](LMX_Design_Patterns.en.md)

Четыре исходных пункта 82–85 сохранены отдельно. Код сравнивает конкретные наблюдения: отсутствие результата, передачу следующего шага, освобождение ресурса и сохранение частично применённого значения. LMX использует обычные структуры и методы; в контрольных языках допускаются их стандартные функциональные библиотеки.
