grammar. Fields, INDEX and mixed steps enter the same semantic fold. The old
n>=3/resolve_whole branch is removed, not kept behind a new helper as fallback.

l2_path_fact_store publishes a current verdict into the same bound owned
record. l2_path_fact_note_bytes uses that same publication operation.
l2_path_same_grammar only compares the existing geometry, original INDEX AST
and counters; it is not another parser or name resolver. A changed view is
refused before types/maps are modified. A current failed resolution replaces
its earlier successful leaf instead of preserving it as permission.

The prior direct Structure-leaf category is retained, not widened into a new
physical-producer policy. Root-only observations are still not empty field
paths. Missing source inventory does not trigger the deleted path parser.
These bounds matter: bare roots, return/copy namespaces and the typed runtime
value transport are still open dependencies, not silently solved by this patch.
