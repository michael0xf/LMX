## 6. Ловушки (проверенные на этом этапе)

- Python в heredoc с `\x` в тексте (пути `M\x`) падает даже при `\\x` — скрипты с такими строками писать в файл (Write) и запускать файлом; цепочку `&&` писать в одну строку (перевод строки = продолжение после падения: так однажды ушёл коммит без CORE.md).
- Предефы тел (`predef: "l2src/x.lm1"`) vs заголовков: два тела в одной единице трансляции → multiple definition; L3 — single-TU через `lmx_walk.lm1`.
- Буферы спеллинга в l2trans — 1024, копирование по `strlen + 1`; счётный проход когда-то был 2^глубина (починен в T4a).
- Проверка по строкам Opus (`verify2b`) обязана читать строку `l2_eternal_driver: N checks`, не только код выхода; фикстура, печатающая в stdout без `\n`, склеивается со строкой драйвера.
- Селфтесты, строящие вложенные Structure вручную, обязаны ставить `\parent` (копир решает own/терминал по `child\parent == holder`).
- `build_l2src -Run` раньше оставлял `lmx_root_*_selftest.err/.out` в корне дерева — теперь под `build/`.
- Файлы docs/CORE на диске CRLF, в индексе LF (`autocrlf=input`) — предупреждения git безвредны.
- Тексты webhook grok_bot ≤ ~3.5 KB (не актуально после остановки).
