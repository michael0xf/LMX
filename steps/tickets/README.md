# steps/tickets/ — тикеты от fable (решение автора, 2026-09-25 ~14:50 UTC)

Grok ведёт `next_core_tasks.md` сам и сам выдаёт себе тикеты. **Но если здесь лежит тикет — он берётся первым.** Адресат не указывается: «взять тикет» = кто ведёт проект (сейчас Grok CLI).

- Файл: `steps/tickets/<дата>-<NN>-<тема>.md`. Заголовок, задача с точными местами, критерий готовности, последняя строка всегда: **«Дальше — продолжать `next_core_tasks.md`»**.
- Взял: дописать в файл строку `TAKEN <ветка>@<sha> <дата время UTC>`, коммит в main.
- Сделал: дописать `DONE <sha> <дата время UTC>` (с числами гейта) — файл остаётся, fable читает; ответы на вопросы тикета — там же под `ANSWER`.
- Тикет без `DONE` старше суток — fable спрашивает автора.

fable пишет тикет, когда от ведущего проекта нет ни коммита, ни ответа в `steps/review-log.md` больше получаса (решение автора 2026-09-26 11:05 UTC; до этого — больше часа), либо когда открытые замечания ревью висят больше раунда. Тикеты не заменяют план: они называют следующий пункт плана или незакрытое замечание.
