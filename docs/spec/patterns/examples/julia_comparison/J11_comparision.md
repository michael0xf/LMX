# J11. Плоское разворачивание результатов

## Общий наблюдаемый договор

Для каждого целого x получить пару [x, x*x] и объединить пары по порядку. Происходит ровно одно разворачивание внешнего результата callback.

Обе формы сохраняют один наблюдаемый договор; процедурная запись показывает управление и изменение данных, функциональная использует общие операции ядра.

Julia требует 1.9 или новее для Iterators.flatmap. LMX возвращает обычную структуру как Array<@>; отдельный контейнер items не создаётся.

## Вход и ожидаемое наблюдение

```json
{
  "arguments": {
    "xs": [
      2,
      -3
    ]
  },
  "result": [
    2,
    4,
    -3,
    9
  ]
}
```

## Размер полных клиентов

| Полный исходник | Непробельные символы | Все Unicode-символы | Непустые строки |
| --- | ---: | ---: | ---: |
| LMX процедурный | 225 | 345 | 12 |
| LMX функциональный | 133 | 204 | 11 |
| Julia | 53 | 62 | 1 |

Обе LMX-формы опубликованы и считаются независимо. Все определения, обработчики и ссылки на throws входят в полный размер. Выбор единственного LMX-варианта по длине не выполняется.

## LMX — процедурный

```lmx
Example:
    int[]: xs
    return: @
    run:
        throws: copy(FxSeqPush\append\throws) copy(FxRecordOperands\record\throws)
        @[]: out []
        int: i 0
        while: i < length(xs)
            FxSeqPush\append(out; (xs[i] record))
            FxSeqPush\append(out; ((xs[i] * xs[i]) record))
            i += 1
        return: out
```

[Полный исходник](source/lmx/procedural/J11.lm3). 225 непробельных символов; 12 непустых строк. Все объявления и Throws включены.

## LMX — функциональный

```lmx
Expand:
    int: x
    return: @
    expand:
        return: (x; x * x)

Example:
    int[]: xs
    return: @
    run:
        throws: copy(FxListBind\bind\throws)
        return: bind(xs; Expand\expand)
```

[Полный исходник](source/lmx/J11.lm3). 133 непробельных символов; 11 непустых строк. Все объявления и Throws включены.

## Julia

[Полный исходник](source/julia/J11.jl).

```julia
example(xs) = collect(Iterators.flatmap(x -> (x, x * x), xs))
```

## Общие библиотечные реализации

- `bind`: [полная пара реализации](library_comparisons/JI01_comparision.md)

Тела библиотечного ядра сохранены в одном общем источнике и не размножаются для двух стилей. Иностранный клиент использует свои настоящие средства; соседние comparison-реализации он не импортирует.

## Проверка

LMX и Julia: **NOT_RUN** в этой сборке. Проверяются обе LMX-формы как текст и общий независимый oracle; это не языковое исполнение.
