## Implementation under test

Canonical field origins and the selected private attribute travel in the
existing activation binding and call-input rows, separately from Value.
Call19 and Walk191 retain origin-aware entries around the existing workers;
old entry signatures remain compatibility callers of those workers.
Explicit actuals take the receiving DATA field attribute. Hidden captures
retain the selected source field. Exact lexical-origin resolution may use
the current independent working Value, including a private lexical field.

Borrowed origin spans live through their call. Retargeting to a wider local
input vector allocates padded owned spans and preserves the prefix; pop
frees only owned spans. Existing execution roots cover pending origins,
and the activation GC loop covers input origins and local binding origins.

Frontend CODE declarations remain in CODE rather than backfilling DATA.
Their local Values begin clear and are registered on a reached store.
Bindings hold current Values and canonical source cells, not source payloads.
Publication emission, dirty carriers and frontend publication helpers are
removed together. Binding scopes truncate the existing activation vector;
cached indices are validated against Value and origin after truncation.

The cancelled runtime publication functions, Walk publisher and its calls,
Work.dirty, PRIM_PUB opcode/branches and publication-only driver assertions are
removed together. Explicit graph writers remain immediate graph writers.
Other numeric opcode values retain their original numbers. Driver's generic
primitive shape check uses PRIM; stop/order/receiver/destination checks remain.

Walk Work uses its existing nwork as the active prefix of its scratch row chain.
Lookup, origin resolution and GC use the same prefix. A reached CODE SET creates
its row after evaluating RHS; a read cannot open a future local. Body exit restores
the prefix on every status without rewinding scratch or discarding result cells.
UNTIL keeps body locals through its condition; FOR keeps its counter through body
and increment, then retires it. Rows beyond the prefix are reusable storage.

Frontend own_mi still identifies storage ownership, while own_host retains the
actual lexical scope. Reuse selects an already visible prior field through the
existing source/scope predicates and source-to-place association. Sibling fields
keep distinct origins and attributes; a true visible repeat keeps its original
receiving type and private attribute. Machine reception and ABI remain unchanged.

## Open boundaries

The ordinary private_hidden_binding fixture checks the existing regular FE
namespace form. It does not accept the whole normative root DATA/CODE migration.
Private, public, explicit, live lexical, SOURCE20/local21, DATA0, lazy cold RHS
and public/private branch-scope cases now pass the ordinary four-mode gate.
Raw CODE declarations without a reached SET and additional PAD payload binding
events were not expanded by the Work scope change.

Opaque C by-value inherited hidden inputs still need typed projection after
default selection. The broader native DATA/header migration and direct known
native-to-native C ABI remain OPEN. Future-CODE raw lexical fallback and static
outside-inline candidate selection are not accepted by the new origin API.

The preexisting runtime resolver selects the first eligible public binding in
a priority layer. Ambiguity needs a result propagated through its consumers;
boolean absence must not turn ambiguity into lexical fallback. Graph408's
uniqueness gate does not prove native/Walk ambiguity. The runtime publication
exports have been removed; ambiguity propagation is still OPEN.

The targeted12 gate is not a full historical-suite claim. The active legacy
var_own_nested fixture still expects CODE backfill, publication, the old call
operand order and admission of CODE locals. It must migrate with the ordinary
frontend M10 consumer: struct_call_operands still treats its first operand as
code and second as data. The main v3 records the exact remaining work; the row
has not been disabled and its expectations have not been weakened.
