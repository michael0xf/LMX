# Передача декларации как DATA-структуры

Редакция от 22 ноября 2026 года. Уточнение автора для объединения с правками Fable.

## Правило

**Декларация, переданная аргументом, является DATA-структурой. При передаче она не выполняется как вызов. Её внутреннее имя вообще не используется для выбора принимающего аргумента.**

Обычная позиционная передача выбирает соответствующую переменную принимающего DATA. Затем выполняется обычная попытка принять в неё всю переданную декларацию как структуру. Совпадение внутреннего имени декларации с именем какого-либо входа ничего не меняет. Если структура не допускается выбранной переменной, нельзя вместо неё подставить результат инициализатора, поискать одноимённый вход или повторить передачу в другую позицию.

Именованная передача задаётся обычным внешним присвоением `name := <значение>`. Значением может быть структура, декларация или другое допустимое значение. Имя после `:=` внутри декларации не подменяет внешнюю метку.

Например, если позиции принимающего DATA называются `a` и `b`:

| Переданный аргумент | Выбранный вход | Передаваемое значение |
| --- | --- | --- |
| `int: b producer()` на первой позиции | `a` | Вся декларация `int: b producer()` как DATA-структура |
| `b := int: item producer()` | `b` | Вся декларация `int: item producer()` как DATA-структура |

При передаче этих деклараций `producer()` не вызывается. Приёмник может позднее явно выполнить принятую структуру; её инициализатор тогда подчиняется обычным правилам достигнутого исполнения. Это правило не превращает самостоятельный аргумент-вызов `producer()` в DATA-декларацию.

Позиционное соответствие, допустимость типов и чтения W/E остаются общими. P0 сохраняет написанные контейнеры и ничего не снимает ради этой передачи.

## Полный пример

```lmx
numbers:
    int: position 0
    return: int
    next:
        throws: Stop
        if: node\position >= 3
            throw: Stop()
        node\position += 1
        return: node\position
    demo:
        node\position := 0
        int: total 0
        cycles\iterate: int: item numbers\next()
            item *= 2
            total += item
        return: total

cycles:
    @: iteration
    @: body
    iterate:
        while: 1
            iteration()
            catch: Stop ()
                break
            body()
```

`iteration` получает декларацию целиком; её внутреннее имя `item` не ищется в DATA `cycles`. Во время передачи `numbers\next()` ещё не выполняется. В каждой итерации явное `iteration()` выполняет принятую декларацию и получает очередной элемент, после чего `body()` использует установленный `item`.

Связанное тело сохраняет доступ к живой переменной `total` из `demo` по существующему договору передачи тела и его исходного контекста. Здесь нельзя подставить независимую резервную копию `total` или заново инициализировать `item` при входе в тело. Для этого не вводятся отдельный объект замыкания или новый способ поиска имён.

Ожидаемый результат `numbers\demo()` — **12**. `next()` достигается четыре раза, тело — три раза. После удвоения значения `item` равны 2, 4, 6; накопленные значения `total` — 2, 6, 12. Четвёртый вызов `next()` сообщает `Stop`; тело больше не выполняется, итоговое `position` равно 3. Это ожидаемая трасса по спецификации; запуск LMX в этой редакции архива не выполнялся.

## Что исправить в коде ядра

1. Удалить маршрутизацию аргумента-декларации по её внутреннему имени, включая ветку «если имя найдено — заменить одноимённый вход».
2. Принимать всю DATA-структуру по уже вычисленному обычному соответствию аргументов и переменных. Внешняя именованная метка продолжает работать обычным образом.
3. Не вычислять инициализатор при передаче, подготовке кандидатов или повторной проверке допустимости. Поздний явный вызов принятой структуры должен исполнять её в предусмотренном договором контексте.
4. Сохранить связь переданного тела с установленным `item` и исходным живым `total`; проверить приведённый пример, окончание по `Stop` и отсутствие лишнего исполнения тела.
5. В адаптерах различать внутренний транспорт уже выбранного места `kind=place` и публичный переданный аргумент `kind=actual`. Внутренняя пара `(frame, sourcePosition)` не является аргументом-декларацией. `kind=actual` должен сохранять DATA-форму и обычное соответствие входам. Это обязательство интеграции `FxKernel\prepare`, а не новый публичный синтаксис.
