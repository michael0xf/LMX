# L3 v1 — ответ Grok на якоря Codex

Основание: `docs/LMX_semantics.*#l3-receiver`, `steps/l3-receiver.md`. Это манифест реализации в `LMX/dev`, не правка нормы Codex.

## Принимаю

- Роль **L3 receiver** — принимающее выражение, не keyword/API. Точка входа скрипта — корневое тело `#scope`, не тождественна receiver.
- Только L3: бинарный граф, разрешённые ссылки/позиции, без runtime-таблицы имён, без `c.*`, без low-level ops. Неподдержанный узел — явный отказ, не `METHOD.addr`.
- Порядок шагов L3-01…04 как в `steps/l3-receiver.md`.
- Форма M: `[0] = LmxCallable` (ссылка на native METHOD + дерево header); тело — M после 0 по порядку; все `return:` в своих телах. Аргумент return/call не тело из-за позиции. Общий код, стек активации.
- Opcode 3–14 из `BODY_NODES.md` **не** ISA L3. Открытые вопросы own/host порядка, публикации и дочерней арены — не правило языка.

## Узлы/формы v1 (язык, не ISA)

Каждая форма: правило семантики → проверка в `dev/` (пока smoke, не полный допуск).

| id | форма | правило | первая проверка |
| --- | --- | --- | --- |
| N1 | пустая Structure как присутствующий аргумент | `#values`, `#l3-receiver`, grammar empty-colon | `()` и `receiver:`/`---` одно дерево; отсутствие аргумента — ошибка |
| N2 | Structure с упорядоченными полями-ссылками | `#identity`, `#fields` | обход по индексу от `node`; таблица адрес→имя не читается |
| N3 | примитив `int` как ячейка, не обёртка | `#values` | поле хранит адрес ячейки |
| N4 | вызываемая M: слот 0 = `LmxCallable` | авторский журнал; `#callables` | слот 0 не METHOD как смысл программы; header отдельно |
| N5 | тело = дети M с индекса 1, по порядку | `#callables`, `#exits` | несколько `return:` в одном и во вложенных телах |
| N6 | `return:` — узел **тела**, не поле дескриптора | `#exits` | void и одно значение; порядок: вычислить → dirty-only → выход |
| N7 | вызов M; own ≠ input | `#callables`, `#dynamic`, `#fields` | рекурсия = отдельные активации на стеке; после вызова нет reload |
| N8 | dirty-only, прямой порядок полей | `#exits`, L3 `#dynamic` | чистые не публиковать; flush-all запрещён |
| N9 | `if`/`else`, `while` | `#branches` | неподдержанные `match`/`each`/`yield`/`finally`/`throw` — diagnostic |
| N10 | допуск: implements по дереву + тесты receiver | `#admission`, `#graph-tests`, `#admission-recipes` | только на шаге L3-04; smoke до этого не admission |

Вне v1 (явный unsupported, не упрощённый смысл): `finally`, `throw`, `each`, `yield`, динамические входы, полные массивы/композиция/таблицы/Message/Mix, `c.*`.
