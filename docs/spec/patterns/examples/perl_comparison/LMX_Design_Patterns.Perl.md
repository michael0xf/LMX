# Группы характерных сценариев Perl

## Списки

- [P01. Калибровка измерений и итог пакета](P01_comparision.md): Калибровать целочисленные измерения множителем 3; вернуть пару (новый список измерений, их сумма). Порядок, нули и знак сохраняются, пустой пакет даёт ([],0). Вход не меняется. Все промежуточные значения и сумма входят в общий точный диапазон int LMX и Perl.
- [P02. Отбор допустимых размеров и суммарная нагрузка](P02_comparision.md): Из списка целых размеров отобрать неотрицательные чётные значения, сохранив порядок и повторы; вернуть (принятые размеры, сумма принятой нагрузки). Ноль допустим, отрицательные и нечётные значения отбрасываются. Пустой результат имеет сумму 0. Вход не меняется; арифметика остаётся в общем точном диапазоне.
- [P03. Итоговый баланс и сигнал дефицита](P03_comparision.md): Применить последовательность целочисленных изменений к initial и вернуть (конечный баланс, флаг balance<0). Пустой список оставляет initial, нулевой баланс не является дефицитом. История промежуточных балансов не требуется; вход не меняется. Все суммы входят в общий точный диапазон int LMX и Perl.
- [P04. Все промежуточные остатки счёта](P04_comparision.md): Из начального остатка и списка изменений получить начальный остаток и все последующие суммы, в том числе начальный элемент для пустого списка.
- [P05. Короткое замыкание any и all](P05_comparision.md): Вернуть два булевых int: существует ли отрицательный элемент; все ли элементы меньше 10. На пустом списке результат [0,1].
- [P13. Пакетная загрузка с сохранением размеров пакетов](P13_comparision.md): Объединить один уровень конечной последовательности пакетов rows и вернуть (плоская последовательность элементов, последовательность исходных размеров пакетов). Пустые пакеты сохраняются в отчёте размеров как 0; пустой внешний список даёт ([],[]). Глубже одного уровня ничего не раскрывается: вложенный массив остаётся отдельным элементом и сохраняет ссылку. Входы не меняются. Размеры во второй последовательности — обычные целые значения в общем протоколе результатов.

## Массивы

- [P06. Перестановка экспортируемых полей вместе с метками](P06_comparision.md): items и labels — две последовательности одинаковой длины: значения экспортируемых полей и их метки. Выбрать обе по одному списку допустимых индексов positions; вернуть пару новых внешних массивов. Порядок и повторы индексов существенны; повторная ссылка указывает на тот же исходный объект, вложенные поля не теряются. Пустые positions дают два пустых массива. Индексы 0..n-1 являются общим предусловием, входы не меняются.
- [P07. Изменение массива с возвратом удалённых](P07_comparision.md): Заменить диапазон [begin,end) и вернуть [тот же изменённый массив, новый список удалённых элементов]. Вставляемые значения читаются до изменения; пустые вставка и удаление допустимы. Общий домен диапазона: 0 <= begin <= end <= length(items); отрицательные и выходящие за границы Perl-индексы не сравниваются с этим договором.
- [P08. Ограниченный приоритетный пакет и суммарная ширина](P08_comparision.md): Отсортировать ссылки на записи по возрастанию priority, сохранить исходный порядок равных ключей, взять первые min(limit,n) записей и вернуть (выбранные записи, сумма их width). limit — неотрицательное целое; каждый width — неотрицательное целое, сумма представима. Все поля и идентичность исходных записей сохраняются, вход не меняется. limit=0 и пустой вход дают ([],0). Общий домен priority имеет полный согласованный порядок без NaN.
- [P09. Уникальные идентификаторы и число повторных поступлений](P09_comparision.md): Из потока канонических целых идентификаторов оставить первые вхождения в исходном порядке и вернуть (уникальные идентификаторы, число удалённых повторных поступлений). Ноль и отрицательные идентификаторы остаются значениями. Пустой вход даёт ([],0), вход не меняется. Обобщённая операция unique ядра этим прикладным целочисленным доменом не ограничена.

## Хеши

- [P10. Частотная таблица с порядком первых вхождений](P10_comparision.md): Для списка целых кодов вернуть пары [код,число вхождений], расположенные по первому появлению кода, а не по произвольному порядку хеша.
- [P11. Автовивификация групп записей](P11_comparision.md): Сгруппировать целые записи по целому kind. Порядок групп — первое появление kind, порядок записей внутри группы — исходный. Никакие поля записи не удаляются.
- [P12. Настройки окна после наложения и рабочая площадь](P12_comparision.md): Наложить плоские совместимые настройки patch на base и вернуть (новые настройки, width*height). После наложения width и height обязательно присутствуют и являются неотрицательными целыми с представимым произведением. Ноль — полноценное значение, все другие поля сохраняются, входы не меняются. Вложенные изменяемые графы не входят в общий профиль сравнения.

## Строки и regex

- [P14. Проверка строки импорта и пустых полей](P14_comparision.md): Разделить ASCII-строку простого импорта по запятым и вернуть (поля, флаг числа полей=columns, число пустых полей). columns — положительное ожидаемое число колонок. Начальные, промежуточные и конечные пустые поля сохраняются; пустая строка означает одно пустое поле. Это явно простой формат без CSV-кавычек/экранирования; ввод не исправляется автоматически и не меняется.
- [P15. Отбор допустимых имён и число отклонений](P15_comparision.md): Обработать список ASCII-строк как предложенные имена: принять только целые строки вида [A-Za-z][A-Za-z0-9_]*; вернуть (принятые имена в исходном порядке, число отклонённых). Повторные корректные имена сохраняются. Пустая строка, ведущая цифра и конечный перевод строки недопустимы. Пустой список даёт ([],0), входные строки не меняются.
- [P16. Именованные группы с явным отсутствием](P16_comparision.md): Разобрать всю строку key=value, где key — непустые ASCII-буквы, value — непустые ASCII-цифры. Вернуть [1,key,value] либо [0,"",""]. Ведущие нули значения сохраняются.
- [P17. Слова журнала с порогом длины](P17_comparision.md): Из ASCII-текста журнала извлечь максимальные последовательности букв [A-Za-z]+, оставить слова длины не меньше неотрицательного minimum и вернуть (принятые слова, число отброшенных коротких слов). Порядок и регистр сохраняются; цифры и знаки — разделители. При отсутствии слов результат ([],0), minimum=0 оставляет все найденные слова. Вход не меняется.
- [P18. Буквальная замена с отчётом о числе изменений](P18_comparision.md): Заменить все неперекрывающиеся буквальные вхождения needle на replacement в ASCII-строке и вернуть (новая строка, число выбранных замен). Исходный текст не меняется; regex-метасимволы needle и доллар/backslash в replacement остаются буквальными. Пустой needle вставляет между символами и на концах, давая length(text)+1 замен; предыдущее regex-состояние Perl не влияет. Вставленный replacement повторно не просматривается.
- [P19. Вычисляемая замена с сохранением ширины](P19_comparision.md): Каждую максимальную последовательность ASCII-цифр заменить таким же количеством звёздочек. Длина строки и прочие символы сохраняются; callback вызывается один раз на выбранное совпадение.
- [P20. Исправление повторённого слова в списке строк](P20_comparision.md): Из списка ASCII-строк выбрать те, что целиком состоят ровно из двух одинаковых непустых слов [A-Za-z]+ с одним пробелом; заменить каждую принятую строку одним экземпляром слова. Вернуть (исправленные слова в исходном порядке, число отклонённых строк). Сравнение чувствительно к регистру, лишние пробелы и конечный перевод строки запрещены. Пустой список даёт ([],0), вход не меняется.

## Строки

- [P21. Обратная комплементарная последовательность ДНК](P21_comparision.md): Вернуть reverse-complement ASCII-последовательности: одновременно заменить A↔T и C↔G, затем развернуть весь результат. Длина сохраняется; N, дефис, строчные буквы и прочие неуказанные символы только меняют позицию, но не транслитерируются. Это явно профиль uppercase ACGT, а не полная таблица IUPAC. Пустая строка остаётся пустой, вход не меняется.

## Состояние

- [P22. Независимые замыкания со своим счётчиком](P22_comparision.md): Создать два независимых счётчика: первый стартует с initial, второй со 100. Последовательно прибавить первому 1 и 3, второму 2, первому −2; вернуть все четыре результата.
- [P23. Ленивый итератор, в котором ноль не означает конец](P23_comparision.md): Итератор выдаёт квадраты 0..limit−1 по одному и завершается отдельно от значения. Собрать его в список; limit неотрицателен. Нулевой первый элемент нельзя потерять как false.

## Ресурсы

- [P24. Освобождение ресурса при успехе и исключении](P24_comparision.md): Ресурс содержит value=42 и width=8. Журнал: 1 acquire, 2 action, 3 release. mode=0 возвращает [50,123], mode=1 — отказ action и [0,123], mode=2 — отказ acquire и [0,1]. Release после успешного acquire выполняется ровно один раз.
