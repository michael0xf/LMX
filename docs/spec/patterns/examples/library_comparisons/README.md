# Отдельные реализации функций исходного набора examples

Эти файлы сравнивают реализации функций на LMX и Haskell. Сравнительные модули
Haskell не импортируются прикладными примерами: там используются настоящие
средства языка, base и monad-loops. Клиентские сравнения публикуют обе полные LMX-формы: процедурную и функциональную.
Эти файлы показывают единые реализации ядра и их зависимости; библиотечное тело не дублируется ради двух стилей клиента.

| Сравнение | Функция или механизм |
|---|---|
| [H01](h01_apply_comparision.md) | apply и обычное применение |
| [H03](h03_capture_comparision.md) | partial, захват аргументов |
| [H06](h06_pipe_comparision.md) | compose/pipe, порядок композиции |
| [H07](h07_evaluation_modes_comparision.md) | lazy/once, повторное вычисление, защита рекурсии и сбой |
| [H09](h09_iterator_comparision.md) | короткий Cycles, whileJust_ и отдельный адаптер отказов |
| [R01](r01_derive_comparision.md) | derive и обновление записи |
| [V02](v02_character_range_comparision.md) | between и включённые границы |

Канонические исходники функций LMX находятся в
[LMX_Fn_Receivers](../../LMX_Fn_Receivers/API.md); общие зависимости указаны из
каждого сравнения. Исходные самостоятельные Haskell-модули сохранены в
[каталоге реализаций](../libraries/README.md).

Сравнения 24 новых сценариев Perl и их семь групп реализаций находятся в
[отдельном наборе Perl](../perl_comparison/README.md). Они не заменяют этот
исходный набор. Размер клиента и размер реализации функции учитываются отдельно.

## Запуск корня и дальнейшие операции

Всегда запускается корень R0 как L3 Thread. У корня нет DATA и пользовательских аргументов. Локальные объявления и вызовы обрабатываются общим механизмом языка.

Именованные операции из invoke, inputs и тестовых cases выполняются корнем или обычным обработчиком уже после старта. Main и Example\run не являются альтернативными точками запуска программы. Заглушка-родитель может иметь собственные аргументы и отправить корню сообщение; эти аргументы не становятся DATA корня.

load_before обозначает необходимые определения фикстуры. Отдельного режима запуска через загрузку в DATA он не вводит; import открывает доступные имена. Для короткого фрагмента явно задаётся принимающий контекст последующей обычной операции. Новая команда CLI или API запуска здесь не определяется. LMX runtime: NOT_RUN. [Норма запуска](../../../LMX_semantics.en.md#source-entry-profiles).
