# Общая грамматика L1, L2 и L3

Уточнение автора от 27 ноября 2026 года, переданное из чата Astra.

> L1 не делайте отдельной грамматикой, только отдельной семантикой (семантику делайте какую хотите для L1)

Один P0 сохраняет одинаковые структурные границы для одинакового текста.
Семантика L1 применяется к дереву общего P0.
