# Связь LMX — указатель на действующие инструкции

Текущая матрица адресатов и граница проверки — [work_chat/README.md](work_chat/README.md). Обязанности почтальона — [to_lmx_uds.md](to_lmx_uds.md); обязательный маршрут `fable_chat` — [for_lmx_uds_about_fable_chat.md](for_lmx_uds_about_fable_chat.md); вход в уже существующую задачу Codex — [CODEX_INBOUND.md](claude_chat/CODEX_INBOUND.md).

Ранняя версия этого файла описывала пробы 2026-09-19, Grok CLI и старые Claude-сессии. Она осталась в истории Git, но не задаёт сегодня получателя, PID, действующую сессию или полномочия на запуск. Grok CLI теперь выведен автором из работы; старый адаптер не использовать без нового решения, даже если процесс вновь обнаружится. На 2026-10-14 локальный реестр не обнаружил его; старая привязка Codex сначала дала `ENOENT`, затем адресная задача выполнила `bind`, и повторный `status` прошёл. Это не подменяет проверку доставки каждого сообщения.
