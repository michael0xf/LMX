# Recognizable receiver names

This edition applies the author's final naming table to the preceding delivered archive: **15 public renames and three new receivers**. The approved spellings are recorded in [api_revision_20261122.json](patterns/api_revision_20261122.json). The earlier naming table remains historical evidence; it is not applied a second time.

The review prefers recognizable operation names and considers Haskell, Julia, MATLAB, and Perl first. Lowercase is preferred when it offers a suitable familiar name; it is not a mechanical rule. The author's final choices below take precedence over that preference. A foreign API name is evidence for a word or spelling, not a promise of identical argument order, indexing, return value, mutation, evaluation, or failure behavior. Regex terminology alone does not establish that a word is a commonly called API.

The current inventory is [CATALOG.md](patterns/LMX_Fn_Receivers/CATALOG.md). Exact contracts are in the [unified chapter](CORE_SEQUENCES_REGEX.en.md), [sequence specification](CORE_SEQUENCES_REGEX.en.md#sequences-details), and [pattern specification](CORE_SEQUENCES_REGEX.en.md#patterns-details). All these operations belong to the same current core. Superseded spellings are migration evidence, not compatibility aliases or additional library versions.

## 1. Sequences and mutation

| Operation | Mutation and result |
| --- | --- |
| `replaceRange(target; begin; end; values)` | Replace `[begin,end)` with the immediate insertion values; return the **same target descriptor**. |
| `splice(target; begin; end; values)` | Perform the same replacement; return a **fresh outer container of the removed pre-write elements**. |
| `append(target; values)` | Insert at the original end; return the same target. |
| `insert(target; position; values)` | Insert a sequence at one position; return the same target. |
| `deleteAt(target; begin; end)` | Remove the explicit half-open interval; return the same target. |

All five entrances share one mutation algorithm. Bounds, final size, and dense-target element admission are checked before mutation. Overlapping insertion values and any removed-result snapshot are stabilized before a write or resize can change them. Commit invokes no user converter or callback. Actual-evaluation effects and resource failures retain the existing failure rules; no general transactional rollback is added.

The new `splice` result preserves the target's actual element requirement and storage profile: dense T[] yields fresh dense T[], while Structure/@[] yields fresh @[] containing the original record references. It is a shallow snapshot: reference identities and actual lexical parents remain unchanged. Replacing a result slot does not replace a target slot; mutations of a shared referenced object remain shared. An empty removed interval yields an initialized empty container of that same profile. `replaceRange` need not allocate an unused removed-result container.

The exact word `replaceRange` occurs in [Kotlin's text API](https://kotlinlang.org/api/core/kotlin-stdlib/kotlin.text/replace-range.html); those String/CharSequence functions return replacement text. Swift's related mutating array operation is named [**replaceSubrange(_:with:)**](https://developer.apple.com/documentation/swift/array/replacesubrange%28_%3Awith%3A%29), and returns Void. Neither is claimed to have LMX's same-target return contract. Julia's range form of [splice!](https://docs.julialang.org/en/v1/base/collections/#Base.splice!) provides a familiar removed-elements result; [Perl splice](https://perldoc.perl.org/functions/splice) returns removed elements in list context and has a different scalar-context result. LMX always returns the specified removed container and uses its own half-open interval.

Other established contracts remain visible. `insert` accepts a sequence, not just one item; `deleteAt` takes an interval, not an arbitrary index set. `compress` requires equal source/mask lengths. `index(items; accepts)` returns Maybe of the first accepted physical index, including index 0, rather than a negative sentinel. The names `any`, `all`, `index`, `count`, `append`, `insert`, `reverse`, and `compress` are unchanged in this revision.

## 2. Text patterns

`oneOf`, `noneOf`, and the unchanged `satisfy` have direct spelling analogues in [Haskell Parsec](https://hackage-content.haskell.org/package/parsec-3.1.18.0/docs/Text-Parsec-Char.html). The other approved pattern spellings state their LMX operation directly. This table does not claim that `sameAs`, `extendFirst`, or `stopFirst` are literal names of Perl regex functions. Foreign examples retain real APIs such as Python `re.fullmatch` and Julia `eachmatch`.

The new boundary predicates accept a Pattern **or literal text**, exactly as the existing matching operations do. A literal text argument is not parsed as regex syntax.

| Receiver | Result and acceptance condition |
| --- | --- |
| `hasPrefix(source; pattern)` | int 1 iff a candidate starts at source position 0; consuming the whole source is not required. Otherwise 0. |
| `hasSuffix(source; pattern)` | int 1 iff a candidate at some valid start ends at the source end. Otherwise 0. |
| `wholeMatch(source; pattern)` | Existing Maybe of a Match beginning at 0 and ending at the source end. |
| `matches(source; pattern)` | int 1/0 for the same whole-source condition. |
| `contains(source; pattern)` | Existing int 1/0 for a match anywhere. |

For `hasSuffix`, all relevant candidates and overlapping starts remain eligible. On `ab`, `literal("a") | "ab"` has a suffix match even though the first candidate at start 0 ends early. On `ababa`, literal `aba` has a suffix match starting at 2, even if a nonoverlapping iterator selects the earlier match at 0. A final `find`/`eachMatch` result is therefore not the definition of suffix testing. Empty-pattern matches at the appropriate boundary count; empty source follows the same rules. The matcher retains the full source context for anchors and lookaround, and matching errors remain errors rather than 0.

`replace(source; pattern; replacement)` remains text replacement producing **new text**; it does not mutate source. `replaceFirst` retains its explicit one-match limit. Sequence interval mutation has the separate names `replaceRange` and `splice`. Pattern construction and calls continue through ordinary methods and the established Expression operand protocol, with no new parser or callable ABI.

## 3. Existing functional operations

The final names are `flatMap` and `groupBy`. They are established spellings in [Scala collections](https://docs.scala-lang.org/overviews/collections-2.13/trait-iterable.html); Java also uses [Stream.flatMap](https://docs.oracle.com/en/java/javase/25/docs/api/java.base/java/util/stream/Stream.html#flatMap(java.util.function.Function)). Foreign Julia/Python examples retain their real lowercase names where applicable.

LMX `flatMap` remains eager under its current sequence contract. LMX `groupBy` collects all equal-key members and retains explicit comparison and stable first-occurrence group order. These contracts are not replaced by Haskell's [adjacent-run groupBy](https://haskell.foundation/haskell-2010-revised-report/stdlib/Data-List.html), Python's [adjacent-run itertools.groupby](https://docs.python.org/3/library/itertools.html#itertools.groupby), or a foreign collection's order policy. The chosen names do not change any example's task or library boundary.

## 4. Mixed-case names retained after review

| Names | Reason to retain them |
| --- | --- |
| `zipWith` | Recognizable Haskell name; no unrelated spelling change is introduced. |
| `signatureTypes` | Constructs a signature from type requirements. `signature` and `types` already have introspection roles. |
| `bindFields`, `bindResult` | Distinguish DATA-field binding from a successful Result continuation; `bind` is already the Maybe operation. |
| `runUntil`, `retryCall` | Keep callable wrappers distinct from the control receivers `until` and `retry`. |
| `composeData` | Names the specific DATA-overlay operation without changing `compose` or `merge`. |
| `charRange`, `boundaryOf`, `utf8Text`, `byteText`, `matchAt` | Preserve range, context, encoding, or position distinctions. |
| `matchedSpan`, `matchedText`, `captureSpans`, `lastCapture`, `captureText`, `captureTexts` | Distinguish spans from materialized text, and one capture from its history. |
| `replaceFirst`, `atLeast`, `atMost` | Preserve the explicit limit or count bound. |
| Ready-made `ascii*`, `line*`, and other Pattern values | Qualifiers state actual restrictions; these values are not additional callable APIs. |

Model and declared-failure names such as `Pattern`, `TextView`, `Match`, `Span`, and `PatternEncoding` retain their spelling. Internal helper and kernel-bridge names are outside this public rename table. No additional automatic lowercasing is authorized by it.

## 5. Application and verification

The current inventory has **115 unique public callable/operand names: 61 existing generic/container operations, 14 sequence operations, and 40 text-pattern operations**. The separate **24 named values, models, settings, and declared failures** remain non-callable entries. There is one text `replace`; the sequence operations have their own names and require no new overload dispatcher or syntax.

Apply the approved map once to current LMX declarations, references, exports, catalogs, normative documentation, examples and alternatives, fixture descriptions, and publication inputs. Keep actual foreign-language APIs and exact uploaded-source snapshots unchanged. Current source forms use `T[]: array` and `Struct@: ptr` where the type requirement belongs in the declaration head; a universal `@: ptr Model` refers to Model itself and does not supply a hidden type annotation.

Statistics are regenerated from current main listings after selecting the shortest eligible complete variant. A rename cannot make a different task eligible for comparison. PDF, XLSX, CSV, JSON, and Markdown totals are rebuilt from that selection. Source, link, and publication checks do not assert LMX kernel execution; runtime acceptance remains explicitly separate.
