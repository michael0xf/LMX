# Вопросы, ожидающие ответа автора

Здесь находятся только вопросы к автору, без ответа на которые агенты не могут выбрать языковое правило. Рабочие тикеты, дефекты и ещё не выполненные проверки сюда не относятся.

Ответ получен — файл переносится в `LMX_blog/q/`; незавершённая реализация не делает вопрос снова открытым. Сейчас таких вопросов в `current/` нет.
