# J14. Проверка заказа против доступных запасов

## Общий наблюдаемый договор

Принять заказ, если длины required и available равны, каждая заказанная величина положительна и не превышает доступный запас на той же позиции. Любое нарушение даёт ложь; пустой заказ с пустым запасом корректен. После отказа дальнейшие позиции не проверяются.

Обе полные реализации выполняют один новый прикладной сценарий: процедурная задаёт алгоритм явно, функциональная использует общие операции ядра. Изменённые тексты требуют нового P0-прогона.

Сценарий расширен по замечанию автора: показана обработка данных и полезный итог, а не только вызов одной функции. ## LMX — процедурный

```lmx
Example:
    int[]: required
    int[]: available
    return: int
    run:
        if: length(required) != length(available)
            return: 0
        int: i 0
        while: i < length(required)
            if: required[i] <= 0 || required[i] > available[i]
                return: 0
            i += 1
        return: 1
```

[Полный исходник](source/lmx/procedural/J14.lm3). 190 непробельных символов; 13 непустых строк. Все объявления и Throws включены.

## LMX — функциональный

```lmx
Fits:
    int: i
    return: int
    accepts:
        return: required[i] > 0 && required[i] <= available[i]

Example:
    int[]: required
    int[]: available
    return: int
    run:
        throws: copy(FxSeqRange\range\throws) copy(all\throws)
        if: length(required) != length(available)
            return: 0
        return: all(range(0; length(required); 1); Fits\accepts)
```

[Полный исходник](source/lmx/J14.lm3). 276 непробельных символов; 14 непустых строк. Все объявления и Throws включены.

## Julia

[Полный исходник](source/julia/J14.jl).

```julia
function example(required, available)
    length(required) == length(available) || return false
    all(i -> 0 < required[i] <= available[i], eachindex(required))
end
```

## Общие библиотечные реализации

- `range`: [полная пара реализации](library_comparisons/JI02_comparision.md)
- `all`: [полная пара реализации](library_comparisons/JI01_comparision.md)

Тела библиотечного ядра сохранены в одном общем источнике и не размножаются для двух стилей. Иностранный клиент использует свои настоящие средства; соседние comparison-реализации он не импортирует.

## Проверка

Изменённые LMX-исходники: parser/P0 **NOT_RUN**; прежний receipt не переносится на новый хэш. LMX и Julia runtime: **NOT_RUN** в этой сборке. Проверяются обе LMX-формы как текст и общий независимый oracle; это не языковое исполнение. Численные размеры пересчитаны по текущим полным исходникам.
