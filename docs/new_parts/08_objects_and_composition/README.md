# Объекты, зависимости и композиция

[Руководство RU](LMX_Design_Patterns.ru.md) · [Guide EN](LMX_Design_Patterns.en.md)

Все десять исходных паттернов сохранены. Примеры работают в одном последовательном владельце; shared mutable состояние в LMX принадлежит Message. Отдельно отмечены границы Marker Interface и Fluent Interface: совпадение наблюдаемой задачи не означает одинаковой номинальной типизации или синтаксиса цепочек.
