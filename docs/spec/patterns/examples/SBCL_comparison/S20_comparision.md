# S20. Макрос: вычислить форму ровно один раз

Полное сравнение на указанном домене.

## Общий договор

Связать результат producer один раз, использовать его дважды в теле и вернуть [двойное значение, число вызовов producer]. Макрос показывает синтаксическое связывание, но сравнение ограничено этим эффектом; это не реализация произвольного MACROEXPAND в LMX.

Оба стиля LMX сравниваются независимо по одному договору. Все объявления, вспомогательные определения и Throws входят в размер. Реализация общих библиотечных операций учитывается отдельно один раз.

## LMX — процедурный

```lmx
Producer:
    return: int
    produce:
        calls += 1
        return: value

Example:
    int: value
    return: @
    run:
        int: calls 0
        int: saved Producer\produce()
        return: (saved + saved; calls)
```

[Полный исходник](source/lmx/procedural/S20.lm3). 139 непробельных символов; 12 непустых строк. Все объявления и Throws включены.

## LMX — функциональный

```lmx
Producer:
    return: int
    produce:
        calls += 1
        return: value

Example:
    int: value
    return: @
    run:
        int: calls 0
        return: (Producer\produce() * 2; calls)
```

[Полный исходник](source/lmx/S20.lm3). 121 непробельных символов; 11 непустых строк. Все объявления и Throws включены.

## Common Lisp / SBCL

[Полный исходник](source/common-lisp/S20.lisp).

```common-lisp
(defmacro with-value ((name expression) &body body)
  `(let ((,name ,expression)) ,@body))

(defun example (value)
  (let ((calls 0))
    (list (with-value (x (progn (incf calls) value)) (+ x x))
          calls)))
```

## Соответствие стилей договору

Один сохранённый результат, использованный дважды, и одно вычисление producer с умножением на 2 дают одинаковый int-результат и число вызовов на заявленном домене; произвольный macroexpand не сравнивается.

WITH-VALUE — локально определённый макрос данного примера, не функция библиотеки Common Lisp. Его полное определение входит в сравнение.

Producer читает value и изменяет calls из текущего Example по динамическому связыванию. Значение вычисляется один раз, сохранённое saved используется дважды; лишняя формальная передача value удалена.

## Общие операции и реализации

Общий договор выражен базовыми средствами языка и приведёнными прикладными определениями.

Common Lisp-клиент использует указанные native/standard средства и не импортирует сравнительные реализации.
