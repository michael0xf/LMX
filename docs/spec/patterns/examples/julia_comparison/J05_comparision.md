# J05. Энергия отклонений от опорного показания

## Общий наблюдаемый договор

Вычесть baseline из каждого целого измерения и сложить квадраты отклонений. Пустой набор имеет энергию 0, источник не меняется. Домен арифметики выбран без переполнения.

Обе полные реализации выполняют один новый прикладной сценарий: процедурная задаёт алгоритм явно, функциональная использует общие операции ядра. Изменённые тексты требуют нового P0-прогона.

Сценарий расширен по замечанию автора: показана обработка данных и полезный итог, а не только вызов одной функции. ## LMX — процедурный

```lmx
Example:
    int[]: xs
    int: baseline
    return: int
    run:
        int: total 0
        int: i 0
        while: i < length(xs)
            int: delta xs[i] - baseline
            total += delta * delta
            i += 1
        return: total
```

[Полный исходник](source/lmx/procedural/J05.lm3). 133 непробельных символов; 12 непустых строк. Все объявления и Throws включены.

## LMX — функциональный

```lmx
Example:
    int[]: xs
    int: baseline
    return: int
    run:
        throws: copy(sum\throws)
        @: delta xs - baseline
        return: \sum(delta * delta)
```

[Полный исходник](source/lmx/J05.lm3). 107 непробельных символов; 8 непустых строк. Все объявления и Throws включены.

## Julia

[Полный исходник](source/julia/J05.jl).

```julia
function example(xs, baseline)
    delta = xs .- baseline
    sum(delta .* delta)
end
```
