# S15. Несколько возвращаемых значений

Полная пара в указанном ниже договоре.

## Общий договор

Для целого n>=0 и целого divisor>0 вернуть [quotient,remainder], где n=quotient*divisor+remainder и 0<=remainder<divisor. Числа помещаются в LMX int.

## Размер основного варианта

| Источник | Полный, без пробельных | Без сложного Throws | Все символы | Непустые строки |
| --- | ---: | ---: | ---: | ---: |
| LMX | 98 | 98 | 150 | 7 |
| Common Lisp / SBCL | 60 | — | 70 | 2 |

Учитывается полный основной листинг. Тестовый стенд и отдельные реализации ядра в него не входят; их файлы и размеры приведены отдельно.

## LMX

[Исходник](source/lmx/S15.lm3).

```lmx
Example:
    int: n
    int: divisor
    return: @
    run:
        int: remainder n % divisor
        return: ((n - remainder) / divisor; remainder)
```

## Common Lisp / SBCL

[Исходник](source/common-lisp/S15.lisp).

```common-lisp
(defun example (n divisor)
  (multiple-value-list (floor n divisor)))
```

## Почему эти варианты сопоставимы

Исходный полный вариант; нормы и конечные эффекты проверены.

CL FLOOR возвращает два значения по протоколу multiple values. На общей границе они явно собраны в список; LMX возвращает структуру значений. Отрицательное деление не входит в общий профиль.

LMX возвращает одну структуру из двух значений; она не выдаётся за протокол нескольких независимых return values CL. Деление в числителе точное, отрицательные аргументы вне общего профиля.

Средства Common Lisp/SBCL: `CL:FLOOR`, `CL:MULTIPLE-VALUE-LIST`.

## Реализации используемых функций

Основной листинг использует базовые средства языка и полностью приведённые прикладные определения.

Common Lisp-клиент не загружает сравнительные reference-реализации.
