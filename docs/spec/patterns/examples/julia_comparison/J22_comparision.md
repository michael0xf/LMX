# J22. Последние четыре цифры нормализованного номера

## Общий наблюдаемый договор

Из ASCII-текста сохранить только символы 0–9, затем вернуть последние четыре цифры или весь результат, если он короче. Ведущие нули в оставшейся части сохраняются; это строковая обработка, не преобразование в число. Пустой набор цифр даёт пустую строку.

Обе полные реализации выполняют один новый прикладной сценарий: процедурная задаёт алгоритм явно, функциональная использует общие операции ядра. Изменённые тексты требуют нового P0-прогона.

Сценарий расширен по замечанию автора: показана обработка данных и полезный итог, а не только вызов одной функции. Обе LMX-формы опубликованы и считаются независимо. Все определения, обработчики и ссылки на throws входят в полный размер. Выбор единственного LMX-варианта по длине не выполняется.

## LMX — процедурный

```lmx
Example:
    []char: text
    return: []char
    run:
        throws: copy(FxSeqPush\append\throws) copy(record\throws) copy(sys\resize\throws)
        []char: out []
        int: i 0
        while: i < length(text)
            if: text[i] >= '0' && text[i] <= '9'
                FxSeqPush\append(out; (text[i] record))
            i += 1
        int: drop length(out) - 4
        if: drop > 0
            i := 0
            while: i < 4
                out[i] := out[drop + i]
                i += 1
            sys\resize(out; 4)
        return: out
```

[Полный исходник](source/lmx/procedural/J22.lm3). 315 непробельных символов; 19 непустых строк. Все объявления и Throws включены.

## LMX — функциональный

```lmx
Example:
    []char: text
    return: []char
    run:
        throws: copy(compress\throws) copy(last\throws)
        []char: digits \compress(text; (text >= '0') * (text <= '9'))
        return: \last(digits; 4)
```

[Полный исходник](source/lmx/J22.lm3). 155 непробельных символов; 7 непустых строк. Все объявления и Throws включены.

## Julia

[Полный исходник](source/julia/J22.jl).

```julia
function example(text)
    digits = filter(c -> '0' <= c <= '9', text)
    last(digits, 4)
end
```

## Проверка

Изменённые LMX-исходники: parser/P0 **NOT_RUN**; прежний receipt не переносится на новый хэш. LMX и Julia runtime: **NOT_RUN** в этой сборке. Проверяются обе LMX-формы как текст и общий независимый oracle; это не языковое исполнение. Численные размеры пересчитаны по текущим полным исходникам.
