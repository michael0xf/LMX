# LMX и Perl: 24 характерных сценария

Дата: 2026-11-23. Самостоятельный набор дополняет текущие примеры архива. Реальный runtime: Perl 5.40.1 / List::Util 1.63. LMX не исполнен.

## Договор сравнения

Списки/map/grep, накопления, срезы, splice, сортировка, уникальность, хеши и автовивификация, текст/regex, замыкания, итератор и освобождение ресурса. В каждом файле одинаковая задача, поля данных, входы и результаты. Функции определений примера — часть листинга, не скрытая зависимость.

Клиенты Perl используют настоящие CORE/stdlib/List::Util. Полные сравнительные реализации лежат в library_comparisons и никогда ими не импортируются. LMX вызывает операции ядра напрямую. Новые sort/unique описаны в [CORE_PERL_EXAMPLES](../../LMX_Fn_Receivers/CORE_PERL_EXAMPLES.md).

## Статистика

Дополнительная колонка «Без сложного Throws» сохраняет заголовок и первый синтаксический аргумент Throws; только последующие аргументы исключены из дополнительного счётчика. copy(Throws) и прочие ссылки остаются полностью, общий банк считается один раз в зависимостях. Полные счётчики и исходники не меняются. Явный Throws/copy(Throws) — преимущество LMX: точный контракт отказов виден в коде; ради размера эти записи не сокращаются.

Метрика: Unicode code points, все символы и отдельно без whitespace, плюс непустые строки. Комментарии внутри выбранного кода входят в счётчик. Harness и объяснения не входят. Клиентские листинги и библиотечные реализации — две отдельные совокупности. Счётчик не измеряет скорость или объём runtime.

## Проверки и ограничения

- [Тесты клиентов Perl](validation/client_tests.json).
- [Тесты реализаций](validation/implementation_tests.json).
- [Покрытие core-функций](validation/library_coverage.json).
- [Проверки текста LMX](validation/source_checks.json).

LMX **NOT_RUN**: нет доступного исполнителя. Текстовая проверка не доказывает связывание имён, типы или работу ядра. Regex-клиенты используют ASCII и byteText; история повторных захватов, Unicode и все детали движка не объявляются автоматически эквивалентными. Различия uniq/unique, splice и пустого split описаны и проверены.

Все примеры синхронны. Чтобы асинхронно выполнить операцию целиком, достаточно post на метод владельца Message; собственный фоновый runtime в эти библиотеки не добавлен. Post отдельной работы не продлевает срок действия ресурса bracket.

## Воспроизведение

```sh
python tools/rebuild.py
python tools/validate.py
```

validate запускает клиентские и реализационные тесты Perl, проверяет completion-report и актуальность извлечённых LMX-исходников. При необходимости отдельный harness доступен как tools/test_implementations.pl.

Редактируются examples.json и канонические LMX-модули. Генератор обновляет источники, SHA-256, Markdown и статистику; PDF/XLSX строит общая сборка архива.
