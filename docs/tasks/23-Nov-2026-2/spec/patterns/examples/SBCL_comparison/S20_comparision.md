# S20. Макрос: вычислить форму ровно один раз

Полная пара в указанном ниже договоре.

## Общий договор

Связать результат producer один раз, использовать его дважды в теле и вернуть [двойное значение, число вызовов producer]. Макрос показывает синтаксическое связывание, но сравнение ограничено этим эффектом; это не реализация произвольного MACROEXPAND в LMX.

## Входы и ожидаемые наблюдения

```json
[
  {
    "args": [
      7
    ],
    "expected": [
      14,
      1
    ]
  },
  {
    "args": [
      0
    ],

      0,
      1
    ]
  },
  {
    "args": [
      -3
    ],
    "expected": [
      -6,
      1
    ]
  }
]
```

## Размер основного варианта

| Источник | Полный, без пробельных | Без сложного Throws | Все символы | Непустые строки |
| --- | ---: | ---: | ---: | ---: |
| LMX | 139 | 139 | 226 | 12 |
| Common Lisp / SBCL | 169 | — | 215 | 6 |

Учитывается полный основной листинг. Тестовый стенд и отдельные реализации ядра в него не входят; их файлы и размеры приведены отдельно.

## LMX

[Исходник](source/lmx/S20.lm3).

```lmx
Producer:
    return: int
    produce:
        calls += 1
        return: value

Example:
    int: value
    return: @
    run:
        int: calls 0
        int: saved Producer\produce()
        return: (saved + saved; calls)
```

## Common Lisp / SBCL

[Исходник](source/common-lisp/S20.lisp).

```common-lisp
(defmacro with-value ((name expression) &body body)
  `(let ((,name ,expression)) ,@body))

(defun example (value)
  (let ((calls 0))
    (list (with-value (x (progn (incf calls) value)) (+ x x))
          calls)))
```

## Почему эти варианты сопоставимы

Producer читает value и изменяет calls из текущего Example по динамическому связыванию. Значение вычисляется один раз, сохранённое saved используется дважды; лишняя формальная передача value удалена.

WITH-VALUE — локально определённый макрос данного примера, не функция библиотеки Common Lisp. Его полное определение входит в сравнение.

## Реализации используемых функций

Основной листинг использует базовые средства языка и полностью приведённые прикладные определения.
