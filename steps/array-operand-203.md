# FABLE-GROK-ARRAY-OPERAND-20260925-203 к.1

STARTED FABLE-GROK-ARRAY-OPERAND-20260925-203: grok/array-operand-203 база main feeeb7b. Read-only. Код следом, без отдельного «go». Ядро и `l2trans.lm1` в одной посадке: старая пара `holder, slot` и новая форма вместе не живут.

## Дыра

Роли уже есть и читают дескриптор только из слота Structure.

- `lmx_walk_array_desc` (`lmx_walk.lm1:548-571`) — child 1 держатель, child 2 слот, лист обязан быть `LMX_KIND_ARRAY`.
- `ELEM` 25 (`:1603`) — `[elem, holder, slot, index]`.
- `ELEMPUT` 26 (`:1641`) — `[elemput, holder, slot, index, value]`, write=1.
- `LENGTH` 27 (`:1705`) — `[length, holder, slot]`.

Транслятор корня для своего массива строит ту же пару: `l2_rw_elem` / `l2_rw_elemput` (`l2trans.lm1:17588`, `:17596`) зовут `l2_rw_cell` (держатель и слот, как AT). `length(...)` в корне отказывается целиком (`l2_rw_operand:17818-17819`, needle `an array`). Нативный `l2_emit_array_length` (`:15694`) — это C-чтение own-слота, не роль.

5b (`length(m\mainArgs)`, `m\mainArgs[1][0]`) поэтому root-pending: массив — поле Structure, которая есть только в ходе R0, либо элемент массива массивов. Фиксированный слот её не называет.

## Форма — одна

Операнд — узел, `lmx_walk_eval` которого даёт дескриптор. Классификация по арене: не `LMX_KIND_ARRAY` — `INVALID`. Чисел транслятора нет.

- `[elem, array, index]`
- `[elemput, array, index, value]`
- `[length, array]`

Выход `ELEM`: `\out` — числовая ячейка для скалярного элемента и **адрес внутреннего дескриптора** для элемента типа дескриптор или Lmx (`lmx_walk.lm1`, ветка `LMX_TYPE_DESC` / `LMX_TYPE_LMX`). Этот адрес и делает `ELEM(ELEM(…))` законным операндом, а не утечкой.

Индекс остаётся ячейкой `size`, которую транслятор кладёт из десятичного литерала. Динамический индекс own-массива (D-39, `l2_own_index_head` / `l2_own_index_tail`) эта посадка не трогает и не закрывает.

Новый арм не нужен. Узел, который уже отдаёт дескриптор:

1. Свой слот — `AT` (`:1178`): `slot[0]`, для own-массива это сам дескриптор. 5a становится `ELEM(AT(holder, slot), index)`.
2. Поле Structure-значения — `OF` (`:1202`) после `DEREF` (`:1187`): `DEREF(AT(0, m))` даёт Structure письма, `OF` того узла и индекса `mainArgs` даёт дескриптор. Цепочка уже есть у путей `m\f`.
3. Элемент массива массивов — значение внешнего `ELEM`, когда элемент `LMX_TYPE_DESC` / `LMX_TYPE_LMX` (`:1630-1636` отдаёт адрес внутреннего дескриптора). Второй `ELEM` принимает этот адрес как операнд. Внутренний массив ни в каком слоте Structure не лежит.

`lmx_walk_array_desc` после посадки не вызывается этими тремя ролями. Граница индекса та же: `index >= len` или `data = 0` — `INVALID` (`:1611`). Запись по-прежнему отказывает неизменяемому держателю: это свойство дескриптора (`lmx_walk_immutable` на адресе, который дал операнд), не отдельный режим.

## Транслятор, та же посадка

- `l2_rw_elem` / `l2_rw_elemput`: ширина 3 и 4; child 1 — узел `AT` своего поля (сегодняшний `l2_rw_cell`). Пять строк 5a — регрессионный пин, Entry не меняется.
- `length` в `l2_rw_operand` больше не отказ `an array`. Операнд — тот же узел: свой массив → `AT`; `m\mainArgs` → `OF(DEREF(AT(m)), слот)`. Роль `LENGTH`, результат `size_t`.
- `m\mainArgs[i]` — `ELEM` от того же узла, что и `length`. `m\mainArgs[i][j]` — `ELEM` от первого `ELEM`.
- `@ m\mainArgs[1][0]` — не этот тикет (класс Q7). Эти строки могут остаться root-pending с новым needle; факт — в RESULT.

## Селфтест и мутанты

Рядом с `tests/lmx_walk_array_elem_selftest.lm1`, узлы собраны вручную, без `l2trans`.

- Индекс `== len` через вычисленный операнд (не через слот) — `INVALID`, RED если границу снять.
- Массив массивов: внешний `ELEM` даёт внутренний дескриптор, второй `ELEM` читает его байт. Мутант «второй ELEM снова ищет слот держателя» — RED.

- `ELEMPUT` над дескриптором в immutable-профиле — `INVALID`. Мутант «не звать `lmx_walk_immutable` на адресе операнда» — запись проходит, RED.

## length в корне

`length` для массива положительного ранга — первая размерность (`docs/LMX_semantics.en.md` §17). В L2 это `descriptor.len`, `size_t`. `length(m\mainArgs)` в корне спрашивает таблицу own корня (`l2_rw_path`), не `l2_path_root`. Строка `entry_argc_if`: без лишних argv длина 1. Успех — `exit_code` 7, не 0 (правило «свидетель не может быть пустым», REVIEW 8f8ad3a). Отказ `length != 1` остаётся `exit_code` 1. `entry_index` и `entry_strcmp` доходят до массива и останавливаются на `c.puts` / `c.strcmp` — L2-операция вне метода. `length` в позиции `int` (`exit_code`, формал `plus_one`) — отказ конверсии `size_t` → `int`, это таблица §7, не этот пункт.
