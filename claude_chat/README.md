# Отдельные собеседники LMX

Вход: `python claude_chat/chat.py`. Каждый профиль имеет собственные настройки авторизации, историю, ID разговора и блокировку. Обмен идёт через stdin/stdout CLI, без почты и вотчеров.

Профили получателей: `grok`, `grok_bot`, `claude_code`. Это имена маршрутизации, а не выбор модели. По умолчанию Claude Code подключается к Anthropic; для другой модели нужен поддерживаемый провайдер и его настройки. Наличие профиля не означает успешную авторизацию.

## Настройка и использование

Из корня LMX:

```powershell
python claude_chat/chat.py init grok grok_bot claude_code
python claude_chat/chat.py list
python claude_chat/chat.py --profile claude_code status
python claude_chat/chat.py --profile claude_code login
python claude_chat/chat.py --profile claude_code ask "Запомни контрольное слово: маяк. Ответь кратко."
python claude_chat/chat.py --profile claude_code ask "Какое контрольное слово было в предыдущем сообщении?"
```

Для отдельного собеседника заменить `claude_code` его именем. Добавление N профилей: `init имя1 имя2 ...`. `login` выполняется отдельно для каждого профиля и требует входа пользователя в браузере. Это не создание N аккаунтов и не автоматическое получение доступа к провайдерам. Учётные данные не копируются из L1 или другого профиля.

Профиль выбирается перед командой. Если он не указан, используется `claude_code`. Прежний вход `python tools/claude_bridge.py` поддерживает те же команды, но теперь использует новые профили; старая `.claude-bridge/` оставлена нетронутой и больше не выбирается автоматически.

`--profile` обозначает адресата, а не отправителя. Например, Grok для разговора с собеседником Claude Code вызывает `--profile claude_code ask ...`. Любой разрешённый локальный агент может обратиться к тому же адресату и продолжить его контекст. Самостоятельное получение новых сообщений внешним агентом этим не обеспечивается: инициатор получает ответ прямо в выводе команды.

## Изоляция и состояние

Все личные данные находятся в `claude_chat/profiles/`, исключённой из Git. В каждом профиле CLI использует свой `config/`; разговор и журнал обменов находятся рядом. Не публиковать эту директорию. Изменение окружения выполняется только для дочернего процесса, общие настройки и работающие агенты L1 не изменяются.

Режим собеседников пока только для чтения и анализа LMX, без запуска команд и редактирования. Тайм-аут задаётся `ask --timeout 180`. Неопределённая доставка блокирует автоматический повтор: сначала исследовать локальную историю и состояние. Не снимать блокировки действующего запроса.

Проверено: 7 автоматических тестов, отдельные каталоги всех трёх профилей. Авторизация пока отсутствует во всех трёх; реальный обмен с моделями не проверен. Следующий шаг — выбор провайдера и интерактивный вход либо настройка его окружения без публикации секретов.
