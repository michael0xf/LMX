# J21. Первые уникальные значения

## Общий наблюдаемый договор

Оставить первое появление каждого целого, сохранив порядок. Вход не меняется.

Обе формы сохраняют один наблюдаемый договор; процедурная запись показывает управление и изменение данных, функциональная использует общие операции ядра.

unique(xs) использует обычное сравнение фактических значений; отдельный Equal не нужен. Для канонических целых этого сравнения отношение совпадает с isequal Julia. Общее LMX-определение сохраняет первый представитель, профиль массива и допускает явный same для иного отношения; рекурсивный режим определён для конечных ациклических последовательностей.

Обе LMX-формы опубликованы и считаются независимо. Все определения, обработчики и ссылки на throws входят в полный размер. Выбор единственного LMX-варианта по длине не выполняется.

## LMX — процедурный

```lmx
Example:
    int[]: xs
    return: @
    run:
        throws: copy(FxSeqPush\append\throws) copy(record\throws)
        int[]: out []
        int: i 0
        while: i < length(xs)
            int: j 0
            while: j < length(out) && out[j] != xs[i]
                j += 1
            if: j = length(out)
                FxSeqPush\append(out; (xs[i] record))
            i += 1
        return: out
```

[Полный исходник](source/lmx/procedural/J21.lm3). 227 непробельных символов; 15 непустых строк. Все объявления и Throws включены.

## LMX — функциональный

```lmx
Example:
    int[]: xs
    return: @
    run:
        throws: copy(unique\throws)
        return: unique(xs)
```

[Полный исходник](source/lmx/J21.lm3). 71 непробельных символов; 6 непустых строк. Все объявления и Throws включены.
