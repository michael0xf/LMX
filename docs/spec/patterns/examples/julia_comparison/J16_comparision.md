# J16. Количество чётных элементов

## Общий наблюдаемый договор

Посчитать чётные элементы; ноль и отрицательные чётные учитываются. Исходный массив сохраняется.

Обе формы сохраняют один наблюдаемый договор; процедурная запись показывает управление и изменение данных, функциональная использует общие операции ядра.

Поэлементное сравнение даёт маску int 0/1; общий вариативный + складывает её поля вместе с начальным 0. Это тот же счёт чистого предиката, без отдельного тела Even.

## Вход и ожидаемое наблюдение

```json
{
  "arguments": {
    "xs": [
      -2,
      -1,
      0,
      3,
      4
    ]
  },
  "result": 3
}
```

| Полный исходник | Непробельные символы | Все Unicode-символы | Непустые строки |
| --- | ---: | ---: | ---: |
| LMX процедурный | 100 | 214 | 11 |

Обе LMX-формы опубликованы и считаются независимо. Все определения, обработчики и ссылки на throws входят в полный размер. Выбор единственного LMX-варианта по длине не выполняется.

## LMX — процедурный

```lmx
Example:
    int[]: xs
    return: int
    run:
        int: count 0
        int: i 0
        while: i < length(xs)
            if: xs[i] % 2 = 0
                count += 1
            i += 1
        return: count
```

[Полный исходник](source/lmx/procedural/J16.lm3). 100 непробельных символов; 11 непустых строк. Все объявления и Throws включены.

## LMX — функциональный

```lmx
Example:
    int[]: xs
    return: int
    run:
        return: (+ 0 copy(xs % 2 = 0))
```

[Полный исходник](source/lmx/J16.lm3). 53 непробельных символов; 5 непустых строк. Все объявления и Throws включены.

## Общие библиотечные реализации

Используются базовые операции языка; предметные определения приведены целиком.

Тела библиотечного ядра сохранены в одном общем источнике и не размножаются для двух стилей. Иностранный клиент использует свои настоящие средства; соседние comparison-реализации он не импортирует.
