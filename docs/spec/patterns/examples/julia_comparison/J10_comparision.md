# J10. Слитное поэлементное выражение

## Общий наблюдаемый договор

Для двух целочисленных векторов одинаковой длины вернуть 2*x + y*y по позициям. Арифметика без переполнения, callbacks не имеют эффектов.

Обе формы сохраняют один наблюдаемый договор; процедурная запись показывает управление и изменение данных, функциональная использует общие операции ядра.

В обеих сторонах используется поэлементная арифметика существующего языка. Общий домен — одинаковые длины, целые без переполнения и чистые операции. Материализованный результат сохраняет порядок; отдельный Combine/zipWith не нужен.

Обе LMX-формы опубликованы и считаются независимо. Все определения, обработчики и ссылки на throws входят в полный размер. Выбор единственного LMX-варианта по длине не выполняется.

## LMX — процедурный

```lmx
Example:
    int[]: left
    int[]: right
    return: @
    run:
        throws: copy(sys\resize\throws) SequenceSize
        if: length(left) != length(right)
            throw: SequenceSize()
        int[]: out []
        sys\resize(out; length(left))
        int: i 0
        while: i < length(left)
            out[i] := 2 * left[i] + right[i] * right[i]
            i += 1
        return: out
```

[Полный исходник](source/lmx/procedural/J10.lm3). 247 непробельных символов; 15 непустых строк. Все объявления и Throws включены.

## LMX — функциональный

```lmx
Example:
    int[]: left
    int[]: right
    return: @
    run:
        return: 2 * left + right * right
```

[Полный исходник](source/lmx/J10.lm3). 66 непробельных символов; 6 непустых строк. Все объявления и Throws включены.

## Julia

[Полный исходник](source/julia/J10.jl).

```julia
example(left, right) = 2 .* left .+ right .* right
```

## Общие библиотечные реализации

Используются базовые операции языка; предметные определения приведены целиком.

Тела библиотечного ядра сохранены в одном общем источнике и не размножаются для двух стилей. Иностранный клиент использует свои настоящие средства; соседние comparison-реализации он не импортирует.

## Проверка

LMX и Julia: **NOT_RUN** в этой сборке. Проверяются обе LMX-формы как текст и общий независимый oracle; это не языковое исполнение.
