# J13. Хотя бы одно превышение

## Общий наблюдаемый договор

Вернуть логическую истину, если существует x > limit. Пустой вход даёт ложь; просмотр заканчивается после первого успеха.

Обе формы сохраняют один наблюдаемый договор; процедурная запись показывает управление и изменение данных, функциональная использует общие операции ядра.

limit разрешается в живом DATA вызывающего Example; исходник не копирует его в отдельную замкнутую структуру.

## Вход и ожидаемое наблюдение

```json
{
  "arguments": {
    "xs": [
      1,
      9,
      3
    ],
    "limit": 5
  },
  "result": true
}
```

## Размер полных клиентов

| Полный исходник | Непробельные символы | Все Unicode-символы | Непустые строки |
| --- | ---: | ---: | ---: |
| LMX процедурный | 97 | 203 | 11 |
| LMX функциональный | 150 | 226 | 12 |
| Julia | 36 | 45 | 1 |

Обе LMX-формы опубликованы и считаются независимо. Все определения, обработчики и ссылки на throws входят в полный размер. Выбор единственного LMX-варианта по длине не выполняется.

## LMX — процедурный

```lmx
Example:
    int[]: xs
    int: limit
    return: int
    run:
        int: i 0
        while: i < length(xs)
            if: xs[i] > limit
                return: 1
            i += 1
        return: 0
```

[Полный исходник](source/lmx/procedural/J13.lm3). 97 непробельных символов; 11 непустых строк. Все объявления и Throws включены.

## LMX — функциональный

```lmx
Above:
    int: value
    return: int
    accepts:
        return: value > limit

Example:
    int[]: xs
    int: limit
    return: int
    run:
        throws: copy(FxSeqAny\any\throws)
        return: any(xs; Above\accepts)
```

[Полный исходник](source/lmx/J13.lm3). 150 непробельных символов; 12 непустых строк. Все объявления и Throws включены.

## Julia

[Полный исходник](source/julia/J13.jl).

```julia
example(xs, limit) = any(x -> x > limit, xs)
```

## Общие библиотечные реализации

- `any`: [полная пара реализации](library_comparisons/JI01_comparision.md)

Тела библиотечного ядра сохранены в одном общем источнике и не размножаются для двух стилей. Иностранный клиент использует свои настоящие средства; соседние comparison-реализации он не импортирует.

## Проверка

LMX и Julia: **NOT_RUN** в этой сборке. Проверяются обе LMX-формы как текст и общий независимый oracle; это не языковое исполнение.
