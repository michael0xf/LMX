# Q25. Типизированное поле + `receiveMessage: m` — что держит `m`?

Контекст: письмо по дизайну почты — Structure с полями обёртки `(sender: @: LmxMsg; payload)`; модель пользователя описывает **payload**; `receiveMessage: m Model` — выборочный приём (K1: NO — письмо пропускается), `m` держит письмо, `m\payload` типизирован моделью, ответ — `sendMessage: m\sender …`.

Минимальная программа (18 строк harness’а сегодня: `Model: fresh` / `LongLetter: m` затем `receiveMessage: m`, чтение `m\mainArgs`):

```text
MainLetter: m
receiveMessage: m
c.puts: m\mainArgs[0]
```

Что означает **предварительно типизированное** `T: m` + `receiveMessage: m` (без модели в самой операции)?

Уже принято (2026-09-23, B2 = α): привязка нетипизированного графа к типизированной цели — runtime admission в точке привязки, отказ — неявный throw `implements` (строки `unit_admit_letter_not_model`, `unit_admit_letter_extra_field` пинуют Thrown 2 / Stopped). Это форма «взять следующее и потребовать тип», не выборочная.

Два чтения того, что держит `m` после приёма:

- **(i) письмо**: admission payload’а письма по `T`; `m` держит письмо целиком, чтения — `m\payload\mainArgs`, доступен `m\sender`. Минус: поле объявлено как `T`, а держит не `T` — объявление `T: m` пришлось бы читать по-особому («m — письмо, чей payload — T») только для receive.
- **(ii) payload**: admission payload’а по `T`; `m` держит сам payload (то, что говорит его тип), чтения — `m\mainArgs`, как в фикстурах сегодня; `m\sender` в этой форме недоступен (для ответа — формы `receiveMessage: m` без типа / `receiveMessage: m Model`, где `m` объявляет обёртка). Общее правило без особого случая: **поле держит то, что говорит его объявление** — объявлено обёрткой → письмо; объявлено пользователем как `T` → `T`.

Рекомендация: **(ii)**.

Побочная находка (Opus -178, к.3, измерено): нативный путь `l2_emit_admit` допускает по `T` **письмо целиком** (`sender; payload`), поэтому после -173 отказывает любому письму (поле `sender` vs `mainArgs`) — строки были root-pending, никто не видел → дефект D-57, чинится вместе с ответом.
