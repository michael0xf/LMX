## Статистика

- Все examples: [PDF](spec/patterns/examples/STATISTICS.pdf), [XLSX](spec/patterns/examples/STATISTICS.xlsx), [машинные данные](spec/patterns/examples/STATISTICS.json).
- Паттерны, GoF и варианты: [PDF](spec/patterns/STATISTICS_2026-11-22.pdf), [XLSX](spec/patterns/STATISTICS_2026-11-22.xlsx). Историческая дата имени файла сохранена; содержимое пересобрано 23 ноября.

Зелёным выделен минимум сопоставимой строки. Если LMX «без сложного Throws» меньше полного LMX и является минимумом, выделена дополнительная колонка. При равных LMX-счётчиках отмечается только полный. Ссылки `copy`, заголовки и первый написанный аргумент общего списка включены в дополнительный подсчёт. Полные исходники, конечные контракты и основные отношения размеров сохранены.

LMX runtime в комплект не входит и здесь не исполнялся. Отчёты отдельно фиксируют source checks, реальные проверки Perl/SBCL и подготовленные LMX acceptance cases со статусом NOT_RUN. Реализованные дополнения не выдаются за завершённый перенос всех стандартных библиотек: конкретные оставшиеся профили и необходимые интерфейсы перечислены в ТЗ.
