# Находка W2 закрыта: дефекта нет — место вызывающего записывается голым именем из тела обычной Structure, 2026-11-25

План [29.4](../../../next_core_tasks_v3.md#k2-20261125). Координаты Sol и Astra
(`CODER-K2-S2-WIDE-20261125-01-W2-ASTRA-ANSWER`): находка S2 не блокирует; в пробе три разных вещи; локализация —
отдельным срезом после публикации S2. `CF` = `build2/codex_fix250generationchain01`.

## Находка

Проба (`CF/k2s2-01/probe-ref/probe_scope.lm3`): тело обычной Structure `Add\add` — `Log\a := 1`, `b := 1`,
`node\c := 1`, вход `Main`; один ответ 3; после прогона `Log\a` 1, `b` 0, `c` 0. Чтение Sol: итог не показывает, какая
строка дала 3; `node\c` внутри `Add\add` адресует `Add`, где `c` нет, и отказ 3 на ней закономерен; запись `b := 1`
обязана менять живое место `Main.b` той же записи, и отказ ровно на ней был бы отдельным дефектом; запуск без входа
исполняет R0 — для настоящего R0 нужен написанный вызов после достигнутого объявления, корень без DATA и без родителя.

## Локализация: четыре пробы, ожидания записаны до прогонов (`CF/k2s2-01/w2`)

| Проба | Форма | Ожидание | Измерено на `coder-k2s2g` |
| --- | --- | --- | --- |
| `v1_bare` | вход `Main`; `b` — файловое данное `int: b 0`; в `Add\add` только `b := 1`; после возврата Main пишет `Log\seen := b` | успех, seen 1, файловое b 0 | успех, seen 1, b 0 |
| `v2_local` | Main сначала достигает локального `int: b 5` (одноимённого DATA нет); `Add` меняет его | успех, seen 1 | успех, seen 1; то же на S1 |
| `pair_node` | `c` объявлен внутри Add; в теле `node\c := 1` | `Add\c` 1, файловое c 0 | `Add\c` 1, c 0 |
| `r0_root` | настоящий R0 без входа: записи `@: Log (…)`, `@: Add (…)`, написанный вызов после объявлений | успех, seen 1, файловое b 0 | успех, seen 1, b 0; то же на S1 |

Первая форма пробы `r0_root` была написана блоками `Log:` и `Add:`; в корневом коде без входа такая запись — код, а не
объявление, и ответ 3 относился к форме программы, не к записи места. Проба переписана записями `@:`.

Вывод: запись места вызывающего голым именем из тела обычной Structure работает во всех трёх формах — файловое
данное входа, локальное место, достигнутое вызывающим, и место корня R0. Отказ 3 исходной пробы дала её третья строка
`node\c := 1`. Дефекта нет, ядро не менялось.
