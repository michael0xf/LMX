## 2. Нормы среза (решения автора 2026-11-10, архив LMX_blog/2026-11-10.md)

1. Круглые скобки разбираются как фигурные; все скобки — по одним правилам. Вызов — прилипание `(` к
   внешнему идентификатору (метка вызова). Внутри скобок, блока, короткой формы и `[]` — один разбор содержимого.
2. Заголовок «ГРУБАЯ ОШИБКА: снятие единственного непустого анонимного контейнера на этапе P0…» отменён — это не
   баг; не возвращать. Правило потребления Structure как аргументов разрешённого вызова остаётся.
3. Пустая короткая форма `short:` допустима; раскрытий в парсере нет. `short0:` / `short1:` / `short2:; short3:` /
   `short4:` — пять коротких Frame с нулём полей. `f(a:)` — присутствующий пустой Frame `a`. Пустой `short:` метки
   вызова не получает. Диагностика 32 для этого случая удалена, нормализаторы удалены.
4. Только при вызове функции транслятор или интерпретатор заполняют аргументы из единичной переданной
   структуры — не парсер.
5. `A:`, `A{}`, `A()` → пустая структура (`A()` с меткой вызова); `A: {}`, `A: ()` → одна пустая структура внутри.
   Старое равенство (`A: {}` = `A{}`) убрать из всех документов.
6. `A:` / `.` / `end: A` → пустая структура; `A: {}`, `B: {}; C: {}` → по одной пустой структуре внутри.
7. `A{{}}`, `A: {}` и `A: ()` дают одно и то же содержимое `A` — одну пустую структуру; показать явно в
   документации рядом; пустые тела `A:`, `A{}`, `A()` — отдельный пример.
