# Группы характерных сценариев Perl

## Списки

- [P01. Преобразование целого списка](P01_comparision.md): Вернуть новый список, умножив каждое целое число на 3; порядок и нули сохраняются. Вход не меняется.
- [P02. Отбор элементов через grep](P02_comparision.md): Сохранить только чётные целые числа, включая ноль и отрицательные; сохранить исходный порядок и повторы.
- [P03. Сумма с нейтральным значением](P03_comparision.md): Сумма конечного списка целых чисел; пустой список даёт 0. Примеры не выходят за диапазон машинного int LMX.
- [P04. Все промежуточные остатки счёта](P04_comparision.md): Из начального остатка и списка изменений получить начальный остаток и все последующие суммы, в том числе начальный элемент для пустого списка.
- [P05. Короткое замыкание any и all](P05_comparision.md): Вернуть два булевых int: существует ли отрицательный элемент; все ли элементы меньше 10. На пустом списке результат [0,1].
- [P13. Map с выдачей нескольких элементов](P13_comparision.md): Сплющить ровно один уровень списка списков, сохранив порядок. Пустые внутренние списки ничего не добавляют; более глубокие массивы остаются отдельными элементами.

## Массивы

- [P06. Срез с перестановкой и повторением](P06_comparision.md): Выбрать элементы по списку допустимых нулевых индексов; порядок индексов и повторы существенны. Результат — новый внешний массив, вложенные ссылки сохраняются.
- [P07. Изменение массива с возвратом удалённых](P07_comparision.md): Заменить диапазон [begin,end) и вернуть [тот же изменённый массив, новый список удалённых элементов]. Вставляемые значения читаются до изменения; пустые вставка и удаление допустимы.
- [P08. Стабильная сортировка записей](P08_comparision.md): Новый список записей по возрастанию priority; для равного priority сохранить прежний порядок. Все остальные поля, включая width, и идентичность записей сохраняются.
- [P09. Уникальные значения в порядке появления](P09_comparision.md): Удалить последующие повторы канонических целых чисел; сохранить первое вхождение и порядок. Вход не меняется.

## Хеши

- [P10. Частотная таблица с порядком первых вхождений](P10_comparision.md): Для списка целых кодов вернуть пары [код,число вхождений], расположенные по первому появлению кода, а не по произвольному порядку хеша.
- [P11. Автовивификация групп записей](P11_comparision.md): Сгруппировать целые записи по целому kind. Порядок групп — первое появление kind, порядок записей внутри группы — исходный. Никакие поля записи не удаляются.
- [P12. Наложение настроек с сохранением полей](P12_comparision.md): Объединить плоские настройки со скалярными и строковыми значениями: patch заменяет одноимённые совместимые поля base, новые добавляются. Ноль — значение, остальные поля, включая width/height/theme, сохраняются. Входы не меняются.

## Строки и regex

- [P14. Разделение строки без потери пустых полей](P14_comparision.md): Разделить ASCII-строку по запятым; сохранить начальные, промежуточные и конечные пустые поля. Пустая строка означает одно пустое поле.
- [P15. Проверка полного ASCII-идентификатора](P15_comparision.md): Принять целиком строку вида [A-Za-z][A-Za-z0-9_]* и вернуть 0/1. Пустая строка и конечный перевод строки не допускаются.
- [P16. Именованные группы с явным отсутствием](P16_comparision.md): Разобрать всю строку key=value, где key — непустые ASCII-буквы, value — непустые ASCII-цифры. Вернуть [1,key,value] либо [0,"",""]. Ведущие нули значения сохраняются.
- [P17. Глобальное извлечение слов](P17_comparision.md): Вернуть все максимальные неперекрывающиеся последовательности ASCII-букв слева направо. Цифры и знаки — разделители; отсутствие слов даёт пустой массив.
- [P18. Буквальная замена всех совпадений](P18_comparision.md): Заменить все неперекрывающиеся буквальные вхождения needle на replacement в ASCII-строке; исходная строка не меняется. Метасимволы needle не становятся regex. Пустой needle вставляет между символами и на концах.
- [P19. Вычисляемая замена с сохранением ширины](P19_comparision.md): Каждую максимальную последовательность ASCII-цифр заменить таким же количеством звёздочек. Длина строки и прочие символы сохраняются; callback вызывается один раз на выбранное совпадение.
- [P20. Обратная ссылка на одинаковое слово](P20_comparision.md): Принять ровно два одинаковых непустых ASCII-слова, разделённых одним пробелом; сравнение чувствительно к регистру, вся строка должна совпасть.

## Строки

- [P21. Транслитерация алфавита ДНК](P21_comparision.md): Вернуть новую строку с одновременной заменой A↔T и C↔G. Другие ASCII-символы и длина не меняются; уже заменённые символы повторно не обрабатываются.

## Состояние

- [P22. Независимые замыкания со своим счётчиком](P22_comparision.md): Создать два независимых счётчика: первый стартует с initial, второй со 100. Последовательно прибавить первому 1 и 3, второму 2, первому −2; вернуть все четыре результата.
- [P23. Ленивый итератор, в котором ноль не означает конец](P23_comparision.md): Итератор выдаёт квадраты 0..limit−1 по одному и завершается отдельно от значения. Собрать его в список; limit неотрицателен. Нулевой первый элемент нельзя потерять как false.

## Ресурсы

- [P24. Освобождение ресурса при успехе и исключении](P24_comparision.md): Ресурс содержит value=42 и width=8. Журнал: 1 acquire, 2 action, 3 release. mode=0 возвращает [50,123], mode=1 — отказ action и [0,123], mode=2 — отказ acquire и [0,1]. Release после успешного acquire выполняется ровно один раз.
