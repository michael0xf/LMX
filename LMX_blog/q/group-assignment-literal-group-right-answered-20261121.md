# Групповое присваивание: одна группа-литерал справа

Дата: 2026-11-21. Задаёт исполнитель (сессия fable_pc). Статус: **закрыт ответом автора в тот же день**:
действует чтение А для группы, записанной справа; результат функции не раскрывается.

## Что записано

- [Сообщение автора 2026-11-21](../2026-11-21.md#group-assign-one-element): правая сторона в скобках — один
  элемент; результат функции при присваивании группе мест можно раскрыть принудительно, чтобы запись совпала с
  `(a b c) := copy(Pair)`.
- [Требование об операндах](../../docs/spec/LMX_semantics.ru.md#operand-receiver), §3.2: контейнер
  остаётся одним операндом, его элементы автоматически не раскрываются.
- [Книга](../../docs/spec/LMX_semantics.ru.md#group-assign) и [грамматика](../../docs/spec/LMX_grammar.ru.md#structure)
  той же редакции: `(a b c) := (c, a, b)` присваивает по позициям — справа одна группа-литерал.

Сообщение называет результат функции; пример книги — литерал. Эти две записи расходятся в одном случае.

## Программа

В коде метода, `a`, `b`, `c` — объявленные там `int` со значениями 1, 2, 3:

```lmx
(a b c) := (c, a, b)
```

## Чтения

- **А.** Принудительно раскрывается любой единственный правый элемент, если он Structure, — и результат
  функции, и группа-литерал. После строки `a` равно 3, `b` равно 1, `c` равно 2; пример книги остаётся.
  Тогда же `(s) := (1, 2)` — отказ по числу: два значения на одно место.
- **Б.** Раскрывается только результат функции; написанная группа остаётся одним элементом. Строка — отказ
  по числу: три места и одно значение. Пример в книге, грамматике и плане переписывается `(a b c) := c a b`.

Вложенная группа слева отдельного вопроса не требует: при чтении А запись `((a b) c) := ((1 2) 3)` следует
из того же шага, применённого к позиции-группе; при чтении Б она отказывает по числу.

## Что есть сегодня

Запись с группой слева от `:=` отвергает разбор — ошибка на `:=` после скобки. В дереве по шагу 21.12 ничего
не менялось.

## Ответ автора 2026-11-21

Дословно — [журнал, раздел 3](../2026-11-21.md#group-assign-decision). Автор сначала назвал запись книги
ошибкой, затем правку удержал, а после обдумывания решение вернул: единственный аргумент операнда, если он
безымянная Structure, раскрывается. Значит, `(a b c) := (c, a, b)` верна и
присваивает по позициям — чтение А. В двух местах решение идёт дальше чтения А: поток полей справа пишется
внутри группы, `(a b c) := (copy(s))`, а запись без скобок — ошибка; Structure, возвращённую функцией, не
раскрывают. Следствия — [вопрос, закрыт 2026-11-22](operand-single-argument-consequences-answered-20261122.md).
