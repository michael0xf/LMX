# S16. DESTRUCTURING-BIND: вложенная форма

Полная пара в указанном ниже договоре.

## Общий договор

Получить структуру ровно [a,[b,c]] и вернуть a+b*c. Неподходящая форма находится вне этой пары; автоматическое рекурсивное раскрытие аргумента LMX не предполагается.

## Входы и ожидаемые наблюдения

```json
[
  {
    "args": [
      [
        2,
        [
          3,
          4
        ]
      ]
    ],
    "expected": 14
  },
  {
    "args": [
      [
        0,
        [
          0,
          8
        ]
      ]
    ],
    "expected": 0
  },
  {
    "args": [
      [
        -1,
        [
          2,
          -3
        ]
      ]
    ],
    "expected": -7
  }
]
```

## Размер основного варианта

| Источник | Полный, без пробельных | Без сложного Throws | Все символы | Непустые строки |
| --- | ---: | ---: | ---: | ---: |
| LMX | 75 | 75 | 118 | 6 |
| Common Lisp / SBCL | 60 | — | 79 | 3 |

Учитывается полный основной листинг. Тестовый стенд и отдельные реализации ядра в него не входят; их файлы и размеры приведены отдельно.

## LMX

[Исходник](source/lmx/S16.lm3).

```lmx
Example:
    @: tree
    return: int
    run:
        @: tail \tree[1]
        return: \tree[0] + \tail[0] * \tail[1]
```

## Common Lisp / SBCL

[Исходник](source/common-lisp/S16.lisp).

```common-lisp
(defun example (tree)
  (destructuring-bind (a (b c)) tree
    (+ a (* b c))))
```

## Почему эти варианты сопоставимы

Исходный полный вариант; нормы и конечные эффекты проверены.

tree передаётся целиком: запускать как Example/run(tree := форма), чтобы исключить CODE W/E для единственной структуры. Вложенность открывается явными индексами; recursive unwrapping отсутствует.

Средства Common Lisp/SBCL: `CL:DESTRUCTURING-BIND`.

## Реализации используемых функций

Основной листинг использует базовые средства языка и полностью приведённые прикладные определения.

Common Lisp-клиент не загружает сравнительные reference-реализации.

## Проверка

SBCL: [фактический отчёт](validation/common_lisp.json). LMX: **NOT_RUN**; структурная проверка текста не доказывает исполнение.
