# J06. Стабильный отбор нечётных

## Общий наблюдаемый договор

Сохранить все нечётные целые в исходном порядке, включая отрицательные.

Обе формы сохраняют один наблюдаемый договор; процедурная запись показывает управление и изменение данных, функциональная использует общие операции ядра.

Готовая поэлементная маска сохраняет прежний отбор чистого предиката, порядок и профиль. Отрицательные нечётные имеют ненулевой остаток независимо от его знака.

## Вход и ожидаемое наблюдение

```json
{
  "arguments": {
    "xs": [
      -3,
      -2,
      0,
      1,
      4,
      5
    ]
  },
  "result": [
    -3,
    1,
    5
  ]
}
```

## Размер полных клиентов

| Полный исходник | Непробельные символы | Все Unicode-символы | Непустые строки |
| --- | ---: | ---: | ---: |
| LMX процедурный | 180 | 305 | 12 |
| LMX функциональный | 83 | 126 | 6 |
| Julia | 28 | 32 | 1 |

Обе LMX-формы опубликованы и считаются независимо. Все определения, обработчики и ссылки на throws входят в полный размер. Выбор единственного LMX-варианта по длине не выполняется.

## LMX — процедурный

```lmx
Example:
    int[]: xs
    return: @
    run:
        throws: copy(FxSeqPush\append\throws) copy(record\throws)
        int[]: out []
        int: i 0
        while: i < length(xs)
            if: xs[i] % 2 != 0
                FxSeqPush\append(out; (xs[i] record))
            i += 1
        return: out
```

[Полный исходник](source/lmx/procedural/J06.lm3). 180 непробельных символов; 12 непустых строк. Все объявления и Throws включены.

## LMX — функциональный

```lmx
Example:
    int[]: xs
    return: @
    run:
        throws: copy(compress\throws)
        return: compress(xs; xs % 2 != 0)
```

[Полный исходник](source/lmx/J06.lm3). 83 непробельных символов; 6 непустых строк. Все объявления и Throws включены.
