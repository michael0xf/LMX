# J16. Доля годных измерений в промилле

## Общий наблюдаемый договор

Посчитать значения в включённом интервале [lo,hi] и вернуть целую долю годных на тысячу: floor(1000*accepted/length). Для пустого входа вернуть 0. Источник сохраняется; произведение 1000*length помещается в int.

Обе полные реализации выполняют один новый прикладной сценарий: процедурная задаёт алгоритм явно, функциональная использует общие операции ядра. Изменённые тексты требуют нового P0-прогона.

Сценарий расширен по замечанию автора: показана обработка данных и полезный итог, а не только вызов одной функции. ## LMX — процедурный

```lmx
Example:
    int[]: xs
    int: lo
    int: hi
    return: int
    run:
        int: n length(xs)
        if: n = 0
            return: 0
        int: accepted 0
        int: i 0
        while: i < n
            if: xs[i] >= lo && xs[i] <= hi
                accepted += 1
            i += 1
        int: scaled 1000 * accepted
        return: (scaled - scaled % n) / n
```

[Полный исходник](source/lmx/procedural/J16.lm3). 186 непробельных символов; 17 непустых строк. Все объявления и Throws включены.

## LMX — функциональный

```lmx
Example:
    int[]: xs
    int: lo
    int: hi
    return: int
    run:
        throws: copy(sum\throws)
        int: n length(xs)
        if: n = 0
            return: 0
        int: accepted \sum((xs >= lo) * (xs <= hi))
        int: scaled 1000 * accepted
        return: (scaled - scaled % n) / n
```

[Полный исходник](source/lmx/J16.lm3). 178 непробельных символов; 13 непустых строк. Все объявления и Throws включены.

## Julia

[Полный исходник](source/julia/J16.jl).

```julia
function example(xs, lo, hi)
    isempty(xs) && return 0
    accepted = count(x -> lo <= x <= hi, xs)
    1000 * accepted ÷ length(xs)
end
```
