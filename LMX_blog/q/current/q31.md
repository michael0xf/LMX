# Q31. Адрес и нечисловой вход в корне

Состояние: 2026-09-26, открыт. В `grok_next.md` этот класс назван «Q7 (адреса в корне)». Это не Q7 из `q.md`: тот закрыт ответом «Q7 -- P1» (путь `\field` на значении `c.*` — сырой доступ к члену C).

## Факт

Корень `.lm2` — Structure. Транслятор отказывает на операции L2 в корне фразой «L2 operation outside a method body» (`l2_rw_l2`). Туда попадают:

- `c.puts: @ m\mainArgs[1][0]` — `dev/l2src_sandbox/tests/entry_index.lm2`
- `c.strcmp(@ m\mainArgs[1][0], "ok")` — `dev/l2src_sandbox/tests/entry_strcmp.lm2`
- вызов с корня, у которого вход не число (`run(@ m\mainArgs[1][0])`) — «a call with an input that is not a number»; `printTree.lm2` из-за этого держит разбор в методе `run`

Элемент `mainArgs` — char Array точной длины, без NUL (D-20). Дверь `c.puts` / `c.strcmp` хочет C-строку: явная копия с NUL, без тихого каста. Это D-81. Сегодня не сажается, потому что сами вызовы стоят в корне.

## Вопрос

Может ли корень передать адрес (элемент char Array, указатель) в `c.*` и в вызов, или такая операция живёт только в методе?

- **A.** Корень передаёт адрес. Отказ «L2 operation outside a method body» для этой двери — дефект. Тогда D-81 сажается: явная копия с NUL, без тихого каста. `entry_index` и `entry_strcmp` уходят из root-pending.
- **B.** Корень остаётся без адресов. `c.*` и вызов с нечисловым входом — в методе. Отказ — норма. D-81 ждёт, пока эти строки стоят в корне.

Рекомендация: **A**. Фраза отказа — ограничение транслятора, не отдельная норма про адрес. Копия для `c.*` явная (D-81).

Ответить можно строкой `Q31 A` или `Q31 B`.
