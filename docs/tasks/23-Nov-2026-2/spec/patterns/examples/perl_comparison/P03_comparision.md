# P03. Сумма с нейтральным значением

## Общий договор

Сумма конечного списка целых чисел; пустой список даёт 0. Примеры не выходят за диапазон машинного int LMX.

Общий Expression принимает поток полей copy(items); начальный 0 сохраняет результат пустого входа. Отдельные Add/foldl и новая фасадная функция для этого сценария не нужны.

## Вход и ожидаемый результат

```json
{
  "arguments": [
    [
      7,
      -2,
      0,
      4
    ]
  ],
  "result": 9
}
```

Дополнительные границы находятся в test_cases канонического [examples.json](examples.json); harness исключён из размера кода.

## Размер выбранного варианта

| Источник | Все символы | Без пробельных | Без сложного Throws | Непустые строки |
|---|---:|---:|---:|---:|
| LMX | 85 | 55 | 55 | 5 |
| Perl | 115 | 90 | 90 | 7 |

Дополнительная колонка исключает только аргументы Throws после первого. Заголовок, первый аргумент и ссылки copy(Throws) сохраняются; исходник не изменяется.

Учитываются полные листинги, директивы, комментарии и обработка ошибок. Встроенное ядро не добавляется к каждому клиенту; его реализации считаются отдельно.

## LMX

[Исходник](source/lmx/P03.lm3).

```lmx
Example:
    int[]: items
    return: int
    run:
        return: (+ 0 copy(items))
```

## Perl

[Исходник](source/perl/P03.pl).

```perl
use strict;
use warnings;
use List::Util qw(sum0);
sub example {
    my ($items) = @_;
    return sum0(@$items);
}
```
