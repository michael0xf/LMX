## 5. Как отвечать fable так же

Ответ — строки сразу под записью, в том же коммите, что правка, если правка есть:

```text
ANSWER <sha>-<n>: сделано. <что изменилось, свидетель, мутант>
ANSWER <sha>-<n>: не согласен: <почему, место в коде>
```

Перед правкой журнала снова `git fetch`: fable дописывает его часто. Конфликт в `LMX_blog/` решать сохранением обеих сторон. Конфликт в книге не решать за fable: оставить его текст и сказать в ANSWER.

## 6. Гейт одной посадки

Один тяжёлый `gcc` за раз.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools\build_l2src.ps1 -Run -OutDir C:\Nyasha_Planet\LMX\build\l2src\<имя>
powershell -NoProfile -ExecutionPolicy Bypass -File tools\l2_harness.ps1 -OutDir C:\Nyasha_Planet\LMX\build\l2_harness\<имя>
python tools\run_l3_selftest.py
python tools\check_docs.py
git diff --check
```

`-OutDir` harness — абсолютный. Относительный кладёт логи внутрь `src\` и падает. Успех ядра — exit 0. Успех eternal-runs — ненулевая буква Entry, не молчаливый 0. Мутант: копия под `build/` или `%TEMP%`, RED, откат, GREEN. Мутант в живых исходниках не оставлять. Четыре числа — в сообщении коммита.

Коммит и push в том же ходе, вместе с документами этой посадки (`steps/`, ответы, тикет, блог, если реплика автора). `l2_driver_launch.err`, `build/`, `%TEMP%` не коммитить. Сообщение коммита — UTF-8 без BOM, файл в `%TEMP%`, `git commit -F`.

Если push отвергнут, потому что fable успел пушить: `git fetch`, `git merge origin/main`, конфликт блога — обе стороны, затем снова `git push origin HEAD:main`. Ветку не заводить.

## 7. Ловушки, на которых уже обожглись

- PowerShell ломает обратные кавычки в `python -c`. Скрипт писать файлом в `%TEMP%`.
- `git checkout -B` от `origin/main` ставит upstream на `origin/main`. Пушить явно: `git push origin HEAD:main`.
- Два ревизии в одном `git rev-parse` на этой машине иногда падают. Смотреть по одной.
- `build_l2src.ps1` меняет cwd. После него вернуться в `C:\Nyasha_Planet\LMX`.
- Harness судит перевод по появлению файла L1, не по коду выхода. Код выхода смотреть у `$LASTEXITCODE`, не у `cmd echo EXIT`.
- `convert.lm2` ищется как `convert.lm2` от cwd перевода. Без копии в каталоге harness все разноимённые примитивы отказывают.
- Свидетель с Entry 0 не доказывает успех.
- Не чинить модель по тому, что сегодня делает нативный путь, если `CORE.md` §3 и §3 «Модель» говорят иное (так возник D-79).
