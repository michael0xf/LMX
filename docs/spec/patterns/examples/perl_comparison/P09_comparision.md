# P09. Уникальные значения в порядке появления

## Общий наблюдаемый договор

Удалить последующие повторы канонических целых чисел; сохранить первое вхождение и порядок. Вход не меняется.

Обе формы сохраняют один наблюдаемый договор; процедурная запись показывает управление и изменение данных, функциональная использует общие операции ядра.

Клиент использует unique(items) без локального Same. Сравнение с uniq Perl ограничено каноническими целыми: Perl сравнивает строковые представления и отдельно обрабатывает undef. Общая LMX-функция допускает обычное равенство и явный same; дополнительная реализационная пара показывает выбранный пользовательский comparator, не сужая публичный контракт unique.

## LMX — процедурный

```lmx
Example:
    int[]: items
    return: @
    run:
        throws: copy(FxSeqPush\append\throws) copy(FxRecordOperands\record\throws)
        int[]: out []
        int: i 0
        while: i < length(items)
            int: j 0
            while: j < length(out) && out[j] != items[i]
                j += 1
            if: j = length(out)
                FxSeqPush\append(out; (items[i] record))
            i += 1
        return: out
```

[Полный исходник](source/lmx/procedural/P09.lm3). 256 непробельных символов; 15 непустых строк. Все объявления и Throws включены.

## LMX — функциональный

```lmx
Example:
    int[]: items
    return: @
    run:
        throws: copy(FxUnique\unique\throws)
        return: unique(items)
```

[Полный исходник](source/lmx/P09.lm3). 86 непробельных символов; 6 непустых строк. Все объявления и Throws включены.

## Perl

[Полный исходник](source/perl/P09.pl).

```perl
use strict;
use warnings;
use List::Util qw(uniq);
sub example {
    my ($items) = @_;
    return [uniq @$items];
}
```
