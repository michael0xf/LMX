# Рендеры текущих публикаций

Эти изображения относятся к финальным PDF/XLSX и перечислены с SHA-256 в [artifact_review_20261123.json](../artifact_review_20261123.json). В `pdf` находятся девять контактных листов всех 35 PDF-страниц; в `xlsx` — 28 уникальных рендеров диапазонов листов; в `xlsx_contacts` — семь контактных листов этих рендеров. Зеркальная книга и PDF `STATISTICS` имеют те же байты, что и именованная сводка всех примеров.

Изображения служат проверкой оформления. Значения, формулы, численные минимумы и их выделение проверены отдельно в [publication_checks.json](../publication_checks.json). Рендеры не являются запуском LMX или нативного Excel.
