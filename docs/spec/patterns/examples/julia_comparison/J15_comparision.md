# J15. Первый найденный индекс без sentinel

## Общий наблюдаемый договор

Вернуть первый нулевой индекс x > limit либо отсутствие результата. Настоящий индекс 0 не смешивается с отсутствием.

Обе формы сохраняют один наблюдаемый договор; процедурная запись показывает управление и изменение данных, функциональная использует общие операции ядра.

LMX Maybe.present/value сопоставляется с Julia nothing/Int. Вычитание единицы применяется только к найденному индексу.

## Вход и ожидаемое наблюдение

```json
{
  "arguments": {
    "xs": [
      2,
      8,
      9
    ],
    "limit": 5
  },
  "result": {
    "present": true,
    "value": 1
  }
}
```

## LMX — процедурный

```lmx
Example:
    int[]: xs
    int: limit
    return: @
    run:
        throws: copy(some\throws) copy(none\throws)
        int: i 0
        while: i < length(xs)
            if: xs[i] > limit
                return: some(i)
            i += 1
        return: none()
```

[Полный исходник](source/lmx/procedural/J15.lm3). 147 непробельных символов; 12 непустых строк. Все объявления и Throws включены.

## LMX — функциональный

```lmx
Above:
    int: value
    return: int
    accepts:
        return: value > limit

Example:
    int[]: xs
    int: limit
    return: @
    run:
        throws: copy(index\throws)
        return: index(xs; Above\accepts)
```

[Полный исходник](source/lmx/J15.lm3). 143 непробельных символов; 12 непустых строк. Все объявления и Throws включены.

## Julia

[Полный исходник](source/julia/J15.jl).

```julia
function example(xs, limit)
    found = findfirst(x -> x > limit, xs)
    isnothing(found) ? nothing : found - 1
end
```
