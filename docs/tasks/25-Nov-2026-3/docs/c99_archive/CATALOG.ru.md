# Каталог возможностей компактного C99-архива

**155 компонентных позиций; каждый ID приведён ровно один раз.** Категории отражают практические задачи. Число компонентов не равно числу CMake-целей или статических библиотек.

Версии, лицензии и upstream-ссылки взяты из [SOURCES.json](../../third_party/lmx_c99_compact/SOURCES.json). Имя библиотеки ведёт к её локальным исходникам; лицензия — к сохранённому уведомлению. Полные commit/hash и состав дополнительных notices остаются в реестре. Собственная реализация LMX отмечена явно, без выдуманного upstream.

Краткая роль относится к выбранному профилю сборки. Подробные направления чтения/записи и ограничения внешних форматов вынесены в отдельную матрицу форматов; наличие парсера не делает его синтаксисом или моделью данных LMX. Лицензионный статус двух исторических позиций оставлен без подмены подтверждённой permissive-лицензией.
