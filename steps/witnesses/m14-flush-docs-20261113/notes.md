# M14: публикация без журнала и flush() — документальный срез

База — `e61f428a4d679c90b4492b77edbf2ed7b9f094ef`, основное дерево `C:/Nyasha_Planet/LMX`.
Подготовленные план и журнал — Astra по решениям автора; согласование и проверка — Codex (Sol).

Единый контракт публикации не требует универсального журнала каждого присваивания. Native по возможности
определяет нужные записи и условия статически; динамическим местам нужен только необходимый учёт изменений
существующего кадра. Сохраняются вычисления, проверки, эффекты, чтения через алиасы и момент публикации.

Обычный не объявляющий flush() без аргументов и результата публикует готовые dirty-изменения текущего
кадра и продолжает исполнение. Вложенные if/циклы используют тот же кадр; новая активация, выход, yield
и публикация Message не происходят. Успех очищает dirty, повтор без изменений ничего не пишет и не
повторяет вычисления, допуск или перечитывание кэша. Голый атом не вызывает, в data это обычная Structure.
Кодовая реализация M14/flush остаётся OPEN. Существующий lmx_graph_work_flush — внутренний помощник
публикации поддержанного подмножества рабочих мест, не готовый языковой ресивер.

Обновлены источник семантики, ручные RU/EN пары, руководство, CORE, заметки и dirty.md.
Грамматика и код ядра этим срезом не меняются. Штатные render/check выполнены последовательно принятым
boot-m8-values-01/g3/tool/lmxtool-tool.exe; обе команды завершились с кодом 0.
