# P01. Калибровка измерений и итог пакета

## Общий наблюдаемый договор

Калибровать целочисленные измерения множителем 3; вернуть пару (новый список измерений, их сумма). Порядок, нули и знак сохраняются, пустой пакет даёт ([],0). Вход не меняется. Все промежуточные значения и сумма входят в общий точный диапазон int LMX и Perl.

Обе формы решают полный прикладной сценарий. Процедурная показывает алгоритм циклами и ветвлениями, функциональная использует общие операции; все поля, порядок, ошибки и полезный результат сохраняются.

Сценарий возвращает и откалиброванные измерения, и итог для передачи следующему этапу. Процедурный проход одновременно заполняет массив и копит сумму; функциональная форма использует арифметику массивов и общую свёртку Expression.

## LMX — процедурный

```lmx
Example:
    []int: items
    return: @
    run:
        throws: copy(sys\resize\throws)
        []int: out []
        sys\resize(out; length(items))
        int: total 0
        int: i 0
        while: i < length(items)
            out[i] := items[i] * 3
            total += out[i]
            i += 1
        return: (out; total)
```

[Полный исходник](source/lmx/procedural/P01.lm3). 191 непробельных символов; 14 непустых строк. Все объявления и Throws включены.

## LMX — функциональный

```lmx
Example:
    []int: items
    return: @
    run:
        @: calibrated items * 3
        return: (calibrated; (+ 0 copy(calibrated)))
```

[Полный исходник](source/lmx/P01.lm3). 90 непробельных символов; 6 непустых строк. Все объявления и Throws включены.

## Perl

[Полный исходник](source/perl/P01.pl).

```perl
use strict;
use warnings;
use List::Util qw(sum0);
sub example {
    my ($items) = @_;
    my @calibrated = map { $_ * 3 } @$items;
    return [\@calibrated, sum0(@calibrated)];
}
```

## Общие библиотечные реализации

Используются базовые операции языка; предметные определения приведены целиком.

Тела библиотечного ядра сохранены в одном общем источнике и не размножаются для двух стилей. Иностранный клиент использует свои настоящие средства; соседние comparison-реализации он не импортирует.
