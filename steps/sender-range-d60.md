## Что делает код сейчас (main 81ff2ed)

Три посадки после той трассы меняют путь, и копир до адреса Message не доходит.

1. Приём. `lmx_walk_mail_take` (`lmx_thread.lm1:928`) берёт письмо через `lmx_thread_mail_take` (`:396`) → `lmx_post_take_owned` → `lmx_post_take_inbox`. Там `lmx_arena_attach` (`lmx_post.lm1:460`, тело `lmx_arena.lm1:266`) вливает интервалы арены письма в арену получателя. В арене письма лежат граф, payload и ячейка-указатель слота 0. Message хоста там не выделялся.

2. Слот 0 — ячейка, не адрес Message. Хост кладёт `lmx_pointer_new_owned` + `lmx_pointer_store_known` (`lmx_root.lm1:1103`, Q26.2): прямой адрес сделал бы Message ребёнком графа. `lmx_pointer_store_known` арену не спрашивает.

3. Копир. `lmx_copy_is_terminal_profiles` считает `MSG_RECORD` терминалом только если `lmx_range_classify` это видит (`lmx_graph_copy_owned.lm1:390`). `LMX_KIND_NONE` по-прежнему отказ (`:478`). Ветка указателя (`:563`, -186) копирует ячейку и кладёт тот же pointee, не спускаясь в него и не классифицируя его. После attach ячейка в арене программы — `LMX_KIND_PRIMITIVE`, и эта ветка берёт её раньше `:478`.

`MainLetter: m` — это `lmx_walk_merge_model`: копируется модель, не соседние поля unit. `present(raw)` и `m: raw` — `lmx_walk_admit_letter`: решается payload, слот 1, не sender. После attach payload классифицируется как Structure.

Импорта диапазона Message на пути почты нет. Единственный боевой `lmx_range_import*` вне тестов — профиль ребёнка в `lmx_child.lm1`. Арена Message остаётся ареной хоста. Указатель её не называет, и `lmx_range_classify` ищет только в переданной арене.

## Два варианта

**Копир считает sender терминалом.** Уже так для адреса, который арена видит как `MSG_RECORD` (`:390`). Расширять это на `KIND_NONE` значит удерживать любой чужой указатель. Отдельная ветка «слот 0 письма» — спец-случай. Оба против доктрины §0. Не рекомендовать.

**Получатель получает диапазон отправителя явным актом доставки.** Это форма дефекта и плана -195. Attach уже делает это для арены письма. Арена Message в этот акт не передаётся: `lmx_service_post` несёт только `letter_arena`. Найти её по голому адресу можно только обходом арен — скрытый реестр. Без имени арены на post импорт не из чего собрать.
