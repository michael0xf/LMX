# P02. Отбор допустимых размеров и суммарная нагрузка

## Общий наблюдаемый договор

Из списка целых размеров отобрать неотрицательные чётные значения, сохранив порядок и повторы; вернуть (принятые размеры, сумма принятой нагрузки). Ноль допустим, отрицательные и нечётные значения отбрасываются. Пустой результат имеет сумму 0. Вход не меняется; арифметика остаётся в общем точном диапазоне.

Обе формы решают полный прикладной сценарий. Процедурная показывает алгоритм циклами и ветвлениями, функциональная использует общие операции; все поля, порядок, ошибки и полезный результат сохраняются.

Проверка знака и чётности задаёт прикладной допуск. В функциональной маске используется поэлементное умножение двух int-масок, без предположения о short-circuit операторах над Array. Итог считается только по принятым значениям.

## LMX — процедурный

```lmx
Example:
    int[]: items
    return: @
    run:
        throws: copy(FxSeqPush\append\throws) copy(record\throws)
        int[]: out []
        int: total 0
        int: i 0
        while: i < length(items)
            if: items[i] >= 0 && items[i] % 2 = 0
                FxSeqPush\append(out; (items[i] record))
                total += items[i]
            i += 1
        return: (out; total)
```

[Полный исходник](source/lmx/procedural/P02.lm3). 237 непробельных символов; 14 непустых строк. Все объявления и Throws включены.

## LMX — функциональный

```lmx
Example:
    int[]: items
    return: @
    run:
        throws: copy(compress\throws)
        @: accepted compress(items; (items >= 0) * (items % 2 = 0))
        return: (accepted; (+ 0 copy(accepted)))
```

[Полный исходник](source/lmx/P02.lm3). 143 непробельных символов; 7 непустых строк. Все объявления и Throws включены.

## Perl

[Полный исходник](source/perl/P02.pl).

```perl
use strict;
use warnings;
use List::Util qw(sum0);
sub example {
    my ($items) = @_;
    my @accepted = grep { $_ >= 0 && $_ % 2 == 0 } @$items;
    return [\@accepted, sum0(@accepted)];
}
```
