# J19. Транспонирование прямоугольной матрицы

## Общий договор

Вернуть транспонированные значения без сопряжения и без изменения входа. Общий домен: непустые прямоугольные матрицы с положительной шириной и отдельно матрица 0x0.

Julia получает родную Matrix; LMX — массив строк. Конвертация тестовых данных не включена в алгоритмы. LMX без отдельной метаинформации не различает все формы 0xn, поэтому такие формы не объявлены равнозначными.

Вход:

```json
{
  "rows": [
    [
      1,
      2,
      3
    ],
    [
      4,
      5,
      6
    ]
  ]
}
```

Ожидаемое наблюдение:

```json
[
  [
    1,
    4
  ],
  [
    2,
    5
  ],
  [
    3,
    6
  ]
]
```

## LMX

```lmx
Example:
    @: rows
    return: @
    run:
        throws: FxKernelFailure FxShape FxTypeToken ReceiverIndex SequenceSize
        return: transpose(rows)
```

## Julia

```julia
example(matrix) = permutedims(matrix)
```

## Размер полного клиента

| Язык | Без пробельных символов | Без сложного Throws | Непустые строки | Все Unicode-символы |
| --- | ---: | ---: | ---: | ---: |
| LMX | 113 | 70 | 6 | 155 |
| Julia | 35 | 35 | 1 | 38 |

Дополнительная колонка оставляет заголовок и первый аргумент Throws; copy(Throws) сохраняется целиком. Полный исходник и его основной счёт не изменяются.

## Реализации использованного ядра

- `transpose`: [полная пара реализации](library_comparisons/JI02_comparision.md)

Julia-клиент использует реальные Base/пакет; реализации из library_comparisons он не импортирует. [Общие зависимости и границы](library_comparisons/README.md) учитываются отдельно. Код проверен как текст и по договорам; исполнение LMX/Julia здесь не заявлено.
