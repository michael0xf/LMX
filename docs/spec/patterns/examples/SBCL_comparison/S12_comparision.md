# S12. Ключевые аргументы и значение по умолчанию

Полное сравнение на указанном домене.

## Общий договор

Функция area имеет width=1 и height=1 по умолчанию. Вернуть [area с явно переданными width,height в обратном порядке; area только с width]. Нулевые размеры не равны отсутствию аргумента.

## Входы и ожидаемые наблюдения

```json
[
  {
    "args": [
      4,
      3
    ],
    "expected": [
      12,
      4
    ]
  },
  {
    "args": [
      0,
      3
    ],
    "expected": [
      0,
      0
    ]
  },
  {
    "args": [
      2,
      0
    ],
    "expected": [
      0,
      2
    ]
  }
]
```

## Размер полных вариантов

| Источник | Без пробельных | Все символы | Непустые строки |
| --- | ---: | ---: | ---: |
| LMX — процедурный | 170 | 251 | 12 |
| LMX — функциональный | 170 | 251 | 12 |
| Common Lisp / SBCL | 128 | 164 | 5 |

Оба стиля LMX сравниваются независимо по одному договору. Все объявления, вспомогательные определения и Throws входят в размер. Реализация общих библиотечных операций учитывается отдельно один раз.

## LMX — общая минимальная форма обоих стилей

Оба стиля сохраняют непосредственные именованные actuals, их обратный порядок и отсутствие height во втором вызове. Это уже минимальная форма проверки default/omission; позиционный адаптер изменил бы демонстрируемый договор.

```lmx
Area:
    int: width 1
    int: height 1
    return: int
    area:
        return: width * height

Example:
    int: width
    int: height
    return: @
    run:
        return: (Area\area(height := height; width := width); Area\area(width := width))
```

[Общий полный исходник](source/lmx/S12.lm3). Оба стилевых столбца учитывают этот текст целиком: 170 непробельных символов; 12 непустых строк.

## Common Lisp / SBCL

[Полный исходник](source/common-lisp/S12.lisp).

```common-lisp
(defun area (&key (width 1) (height 1))
  (* width height))

(defun example (width height)
  (list (area :height height :width width)
        (area :width width)))
```

## Соответствие стилей договору

Оба стиля сохраняют непосредственные именованные actuals, их обратный порядок и отсутствие height во втором вызове. Это уже минимальная форма проверки default/omission; позиционный адаптер изменил бы демонстрируемый договор.

После именования height не на текущей позиции второй аргумент также именован. Собственное значение height=1 не заменяется одноимённым полем caller; явно переданный 0 не является пропуском.

## Общие операции и реализации

Общий договор выражен базовыми средствами языка и приведёнными прикладными определениями.

Common Lisp-клиент использует указанные native/standard средства и не импортирует сравнительные реализации.
