# Step P2, slice C5: an explicit `L2:` runs anywhere in code; its arguments are taken as written

Written 2026-11-18 by Fable (fable_pc), the single writer/build of main. The code, the fixtures, the component builds
and the mutants are by the peer session sonnet under the pipeline token. Fable set the order, sent the first delivery
back, took the decisions and re-ran the witnesses. Base: `9284a581` (slice C1); the commits between it and this one
are documents only.

## The norm

The author's order of 2026-11-18 (`LMX_blog/2026-11-18.md#interpreter-runs-l2`): the interpreter executes L2 with the
same checks as L3. Plan, #one-graph-plan, step P2. The author's decision of the same day
(`#two-kinds-of-receivers`): the level records L1, L2, L3 take their arguments as data -- a sole Structure argument is
not unwrapped, the record receives exactly what is written.

## What changed

- `lmx_graph_run.lm2`:
  - `lmx_graph_code_argument` answers the role code 4 for the record `L2`: a container whose own fields are code, taken
    as written. `else` and `finally` keep the role code 3, whose sole written argument group is selected once. The
    new predicate `lmx_graph_role_code` (3 or 4) is asked in the four places that need the meaning «the fields are
    code»: the lexical parent of a body, the scan of the work rows, the preflight and the construction walk.
  - `lmx_graph_block_body` runs the fields of the record in place, in the same activation, as it runs the body of an
    `else`. Names of the enclosing code are seen and written inside; a name declared inside ends with the record.
  - The space of `node` passes through a record nested in the code of a call. The record that is the whole body of
    its file still stops the space.
- `l2_graph_tool.lm2`: the emitter emits the fields of the record in the same call.
- Eight new fixtures `level2_record_*`. No new state in the graph or in the kernel, no new export.

Before this slice an explicit `L2:` that was not the whole file was applied as a call of an unknown name: the run
answered 3.

## The first delivery was not accepted

Sonnet's first build put `L2` into the role code 3 of `else` and `finally`. The body selection of that role takes
the sole written argument group as the body, so `L2: (a; b)` ran both records -- the sole Structure argument was
unwrapped. The author's decision on the two kinds of receivers came while that build was running. Fable found the
difference by reading `lmx_graph_code_body` and by a probe, and sent the slice back for a role code of its own, two
fixtures and a mutant. On the accepted build a record `L2` with one Structure argument, written after the colon or
as a block holding one anonymous Structure, runs nothing, exactly as an anonymous Structure written as a line of a
method body does; the three forms with two records as arguments run both.

## Correction, written the same day

The two fixtures with one Structure argument pin a gap of the implementation, not the norm. By the author's
decision of 2026-11-16 (`LMX_blog/2026-11-16.md#unnamed-structure-executes`) an unnamed Structure in code is
not a call of a head with arguments, but its records are executed in place. A record `L2` receives its
argument as written, so the sole Structure is one field of it; the fields of the record are code, and the
unnamed Structure among them executes its records: the observed fields become 5 and 6. The clean graph still
leaves an unnamed Structure in code inert -- an open item of the plan -- and the fixtures were accepted with
0 and 0. Fable gave sonnet that expectation from a probe of the tool without reading the rule; the answer
of the first delivery, 5 and 6, agreed with the norm, though it came from selecting the sole group as the
body. The code of the accepted delivery is right and stays. The expectations of the two fixtures are
corrected to 5 and 6 right after slice C2; the rows then stay red until the clean graph executes an unnamed
Structure in place. The mutant «the role code returned to 3» is therefore not a witness of the norm.

  the chain, and they have none.

  slice C8.
