# LMX `dev/` — разработка, не стабильный корень

Как в L1: **корень репозитория — стабильный снимок**; здесь — рабочая копия и новые механизмы, пока они не приняты в корень.

| путь | роль |
| --- | --- |
| `l1src/`, `l2src/` в корне LMX | стабильная версия (после миграции и зеркала песочницы L1) |
| `dev/l2src_sandbox/` | рабочая копия `l2src/` для правок ядра и интерпретатора |
| `dev/graph_interp/` | интерпретатор того же графа, что исполняет нативный код |
| `build/` под `dev/` | артефакты, в git не входят |

Не править корневые `l1src/` / `l2src/` «чтобы попробовать». Сборка песочницы — в `dev/l2src_sandbox/build` (игнорируется).
