# Объявление, поданное входу по имени: пример D-03 регрессионного набора

Записано 2026-11-23 исполнителем fable_pc после уточнения автора
([журнал](../2026-11-23.md#declaration-argument-is-a-structure)): имя переданного объявления среди входов не
ищется, объявление — Structure на своей позиции, адресата называет обычное `name := значение`. Статус: **закрыт
ответом автора в тот же день**; ответ — в конце.

## Пример автора

[Регрессионный набор, D-03](../../docs/spec/patterns/LMX_regression_examples.to_fable.en.md) стоит на
снятом случае найденного имени:

```lmx
Producer:
    int: calls 0
    return: int
    make:
        node\calls += 1
        return: 7

Receiver:
    int: first
    int: second
    return: int
    ignore:
        return: 4
    read:
        return: second + second
```

| Вызов | Ожидание примера | Вызовов `make` |
| --- | --- | --- |
| `Receiver\ignore(int: second Producer\make())` | 4 | 0 |
| `Receiver\read(int: second Producer\make())` | 14 | 1 |
| `Receiver\ignore(second := Producer\make())` | 4 | 1 |

По уточнению объявление в первых двух вызовах идёт на первую позицию, в `first`, а не описывает `second`.
Третья строка не меняется.

## Вопрос

Что получает вход `int: second`, когда объявление подано ему по имени:

```lmx
Receiver\read(second := int(second Producer\make()))
```

- (а) Вход хранит форму и вычисляет её при первом чтении: `read` даёт 14, `make` вызван один раз; `ignore` даёт
  4 без вызова. Тогда D-03 переписывается на эту запись с прежними числами.
- (б) Объявление — Structure, а вход объявлен `int`: обычный допуск отказывает, как для любой Structure. Тогда
  D-03 показывает отказ, а отложенное вычисление входа пишется иначе или снимается.

Тот же ответ определяет первую позицию: `Receiver\ignore(int: second Producer\make())` подаёт объявление в
`int: first` — при (б) это отказ допуска.

## Ответ автора, 2026-11-23

> б - отказ, в твоем примере структура "int: second Producer\make()", ее никакой int не принимамет в качестве
> значения хоть указывай имя хоть не указывый

Следствия — чтение исполнителя. Объявление, поданное входу `int`, отказывает обычным допуском: Structure входу
`int` не значение, назван адресат или нет. Пример D-03 переписан: оба вызова с объявлением показывают отказ без
вызова `make`, третья строка с обычным вызовом не изменилась. В разделе книги об объявлениях-аргументах к записи
`g(b := int(b producer()))` добавлено: принимает ли переменная объявление, решает её обычный допуск, и
вход-примитив Structure объявления не принимает.
