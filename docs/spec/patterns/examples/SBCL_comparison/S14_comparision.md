# S14. LABELS: локальная рекурсия

Полная пара в указанном ниже договоре.

## Общий договор

Вычислить n! для целого 0<=n<=12. Локальный рекурсивный helper принадлежит вызову example; нет глобального изменяемого счётчика.

## LMX

[Исходник](source/lmx/S14.lm3).

```lmx
Example:
    int: n
    return: int
    Factorial:
        int: k
        return: int
        compute:
            if: k = 0
                return: 1
            return: k * compute(k - 1)
    ---
    run:
        return: Factorial\compute(n)
```

## Common Lisp / SBCL

[Исходник](source/common-lisp/S14.lisp).

```common-lisp
(defun example (n)
  (labels ((fact (k)
             (if (zerop k) 1 (* k (fact (1- k))))))
    (fact n)))
```

## Почему эти варианты сопоставимы

Исходный полный вариант; нормы и конечные эффекты проверены.

Вложенный helper принадлежит Example. Сравнивается результат на 0..12 и область имени, не идентичность создаваемого LABELS function object.

Средства Common Lisp/SBCL: `CL:LABELS`.

## Реализации используемых функций

Основной листинг использует базовые средства языка и полностью приведённые прикладные определения.

Common Lisp-клиент не загружает сравнительные reference-реализации.
