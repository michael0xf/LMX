# M14: общий native, кадры и публикация — документальный срез

База — `cde574b8772a5b08f1190618c67446762968bd9e`, основное дерево `C:/Nyasha_Planet/LMX`.
Подготовленный пакет плана и журнала — Astra по решениям автора; согласование и проверка — Codex (Sol).

Приняты M14, его чек-лист, передача и технические реплики автора. Источник семантики и ручные RU/EN
пары согласованы: обычная C и методы используют общий выпуск тела, допуск, карту мест и кадр без data = code.
Dirty данных и исполняемого кода публикуется на стандартных границах; native и обходчик должны совпадать
по продолжению, в том числе после вложенного вызова. Инвалидация не заменяет уже работающие машинные
инструкции и не повторяет эффекты. M13/descriptor адресует настоящие поля, публикацию ведёт общий кадр.

Чтением main подтверждена граница: lm_graph_collect_methods отбирает результаты fn/sub, корень выпускается
отдельно; lm_graph_emit_methods устанавливает адрес на объявлении, lmx_graph_fn_make переносит decl.native
в made.native. Это не компиляция в fn и не готовая реализация native произвольной вложенной Structure.
Код ядра и грамматика не менялись. Реализация M14 остаётся OPEN; очередь M8 → M11 сохраняется.
Зависимость общего исполнения внесена в основной v3, включая M8, M11, N4-U и K10/K11.

Штатные docs render semantics и docs check выполнены последовательно принятым инструментом
boot-m8-values-01/g3/tool/lmxtool-tool.exe. Обе команды завершились с кодом 0.

выдержки, 615 импортов, ссылки, точное начало семантики и LF индекса для 27 043 файлов
(дословные импорты исключены из требования LF). git diff --check и проверка индекса — код 0.
